# 非居住者の日本株課税と租税条約

海外投資家（非居住者・外国法人）が日本株から得る所得への課税は「配当には源泉徴収、譲渡益は原則非課税」という構造を持ち、源泉税率は国内法（原則20.42%、上場株式は15.315%、2025年時点）から租税条約により10%等へ軽減される。本稿は非居住者側から見た日本の課税ルール、条約適用の届出実務、事業譲渡類似株式など譲渡益課税の例外を整理し、日本居住者による米国株投資の外国税額控除との対比で二重課税調整の全体像を示す。国内投資家の税制は [株式税制と新NISA](taxation-and-nisa.md)、投資経路と常任代理人の実務は [海外から日本株に投資する手段](../market-structure/foreign-investor-access-channels.md) を参照。

## 1. 配当への源泉徴収：国内法と租税条約の二層構造

### 1.1 国内法の税率（2025年時点）

非居住者・外国法人が受け取る日本株の配当は国内源泉所得として**源泉徴収のみで課税が完結**する（源泉分離。恒久的施設＝PEに帰属する場合を除く）。国内法の税率は次の通り。

| 区分 | 源泉税率（国内法） |
|---|---|
| 非上場株式の配当（原則） | 20.42%（所得税20% × 復興特別所得税1.021） |
| 上場株式等の配当 | 15.315%（租税特別措置法による軽減） |
| 上場株式でも発行済株式の3%以上を保有する個人大口株主 | 20.42% |

非居住者には住民税5%が課されない点が居住者（合計20.315%）との構造的な違いである。復興特別所得税の上乗せは居住者と同じ計算で、$20\% \times 1.021 = 20.42\%$、$15\% \times 1.021 = 15.315\%$ となる。

### 1.2 租税条約による軽減

日本が締結する租税条約（2025年時点で80超の国・地域に適用）は、源泉地国（日本）の配当課税に上限を設ける。国内法と条約の税率は**低い方が適用**される（プリザベーション原則により条約が不利になることはない）。代表例：

| 条約 | ポートフォリオ配当 | 親子間配当 | 特記事項 |
|---|---|---|---|
| 日米租税条約 | **10%** | 5%（議決権10%以上）、**0%**（議決権50%超・保有期間等の要件） | 一定の年金基金は0%。特典制限条項（LOB）あり |
| 日英租税条約 | 10% | 0%（議決権10%以上） | |
| 日豪・日仏・日蘭など | 10% | 5%または0% | 条約ごとに保有比率・期間要件が異なる |
| 条約非締結国（例：一部タックスヘイブン） | 軽減なし（15.315% / 20.42%） | — | |

米国の個人投資家が東証上場株を保有する典型例では、国内法15.315%が条約により**10%**まで下がる。グロス配当 $D$ に対する手取りは $D \times (1 - 0.10)$ で、軽減の有無は配当利回りに直接効く：条約適用漏れなら $15.315\% - 10\% = 5.315\%$ ポイント分を取り損ねる。

なお条約の適用には、条約漁り（treaty shopping）を防ぐ**特典制限条項（LOB）**や、BEPS防止措置実施条約（MLI）による**主要目的テスト（PPT）**を満たす必要があり、単に締約国に導管会社を置くだけでは軽減を受けられない（2025年時点）。

## 2. 譲渡益：原則として日本では課税されない

非居住者が日本株を売却して得るキャピタルゲインは、**原則として日本の国内源泉所得に該当せず課税されない**（居住地国でのみ課税）。海外投資家が東証売買代金の約6割を占める市場構造（詳細は [投資家構成と投資部門別売買動向](../market-structure/investor-composition-and-flows.md)）は、この「譲渡益は源泉地国非課税」という国際課税の標準ルールに支えられている。

ただし国内法には例外があり（2025年時点）、主なものは：

1. **事業譲渡類似株式の譲渡**：譲渡年以前3年内のいずれかの時点で内国法人の発行済株式の**25%以上**を保有し（特殊関係株主グループで判定）、かつその年に**5%以上**を譲渡した場合（いわゆる25%/5%ルール）。実質的な事業売却を株式譲渡の形式で行うケースを捕捉する。
2. **不動産関連法人株式の譲渡**：総資産の50%以上が国内不動産で構成される法人の株式を一定割合超譲渡した場合。
3. **PE帰属**：日本国内の恒久的施設に帰属する株式の譲渡益。
4. その他、ゴルフ場利用株式等、日本滞在中の売却など特殊類型。

さらに租税条約が国内法に優先するため、多くの条約（日米条約を含む）では譲渡益は**居住地国課税**とされ、上記1のような国内法上の課税権すら制限されることがある（不動産関連法人株式は多くの条約で源泉地国課税が留保される）。したがって通常のポートフォリオ投資家にとって、日本株の実務上の税コストは配当源泉税にほぼ集約される。

## 3. 租税条約の届出実務

条約の軽減税率は自動適用ではなく、**「租税条約に関する届出書」**を配当支払前に、支払者（発行会社・支払の取扱者）経由で税務署へ提出する必要がある。上場株式の実務では：

- 非居住者株主は国内の**常任代理人**（実務上はサブカストディアンが兼務）を置き、届出はカストディチェーン経由で処理される。米国ADRなら預託銀行が一括して手続きする（[海外から日本株に投資する手段](../market-structure/foreign-investor-access-channels.md) 参照）。
- 日米条約など LOB 付き条約では「特典条項に関する付表」と居住者証明書の添付が求められる。
- 届出が間に合わず国内法税率で源泉徴収された場合は、**「租税条約に関する源泉徴収税額の還付請求書」**により差額の還付を受けられる（更正の請求とは別の条約固有の手続き）。

機関投資家のグローバル・カストディアンにとって、この源泉税の軽減・還付（tax reclaim）は運用リターンに直結するオペレーションであり、条約適用漏れはトラッキングエラーの一因になる。

## 4. 逆方向との対比：日本居住者の米国株投資と外国税額控除

方向を逆にすると二重課税調整の全体像が見える。日本の居住者が米国株の配当を受ける場合（2025年時点）：

1. 米国で日米条約の10%が源泉徴収される（証券会社経由で **W-8BEN** を提出して軽減適用。日本の届出書に相当）。
2. 残額に日本で20.315%が課税される。
3. 二重課税は確定申告の**外国税額控除**で調整する。控除限度額は

$$
\text{控除限度額} = \text{所得税額} \times \frac{\text{国外所得総額}}{\text{所得総額}}
$$

で、限度内で米国源泉税10%分を国内税額から差し引ける（完全に取り戻せるとは限らない）。

つまり「源泉地国で条約上限まで源泉徴収 → 居住地国で全世界所得課税 → 居住地国側の外国税額控除で調整」という同じ骨格が双方向に働く。非居住者から見た日本の配当源泉税10%は、相手国側の外国税額控除で調整されることが多く、最終的な税負担は投資家の居住地国税制に依存する。

## 5. NISA は非居住者には使えない

NISA 口座の開設・保有は**国内に住所を有する居住者**（および恒久的施設を有する一定の者）に限られ、海外投資家は利用できない（2025年時点）。また日本居住者が出国して非居住者になる場合も原則として NISA 口座は廃止され、金融機関によっては「継続適用届出書」の提出で最長5年間の保有継続（新規買付は不可）が認められるにとどまる。なお有価証券等の含み益が1億円以上ある居住者の出国には**国外転出時課税（出国税）**が別途適用される点も、クロスボーダーの実務では重要である。制度の詳細は [株式税制と新NISA](taxation-and-nisa.md) を参照。
