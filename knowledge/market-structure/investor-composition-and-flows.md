# 投資家構成と投資部門別売買動向

日本株の保有構造は、戦後の金融機関・事業法人中心の「持ち合い構造」から、海外投資家が保有・売買の双方で最大勢力を占める構造へと大きく転換した。本稿では、主要投資部門（海外投資家・個人・信託銀行・事業法人・金融機関）の保有シェアの変遷と行動特性を整理し、東証が毎週公表する「投資部門別売買状況」を需給分析に応用する方法を解説する。政策としての日銀ETF買いの詳細は別稿（macro/boj-and-equities）に譲り、ここではフロー分析の観点に集中する。

## 1. 保有構造の変遷 — 持ち合い解消と外国人化

東証等が公表する「株式分布状況調査」（金額ベース）によれば、日本株の保有構造は過去30年で劇的に変化した。概観すると以下の通りである（各年度末時点の概数）。

| 部門 | 1990年度頃 | 2023年度頃 |
|---|---|---|
| 外国法人等（海外投資家） | 約5% | 約32%（過去最高圏） |
| 事業法人等 | 約30% | 約19% |
| 都銀・地銀等＋生損保（金融機関） | 約30%超 | 約10%前後 |
| 個人・その他 | 約20% | 約17% |
| 信託銀行 | 約10% | 約22%（年金・投信・日銀ETFの受け皿を含む） |

この変化を駆動したのが**持ち合い解消**である。銀行・生保・事業法人が相互に株式を保有し合う政策保有は、1990年代のバブル崩壊で含み損リスクとして顕在化し、2001年施行の銀行等株式保有制限法、時価会計の導入（2000年代初頭）で売却が加速した。さらに2015年適用開始のコーポレートガバナンス・コード（2018年・2021年改訂）が政策保有株式の保有意義の開示と縮減を求め、2023年以降は東証の「資本コストや株価を意識した経営」要請や、損保業界の政策保有株ゼロ方針（2024年時点の各社公表）が解消をさらに後押しした。持ち合い解消は構造的な**売り圧力**であると同時に、浮動株比率の上昇を通じて流動性とガバナンス圧力を高める効果を持つ。

信託銀行のシェア上昇は、年金基金（GPIF等）の株式運用、投資信託、日銀ETFの信託財産がいずれも信託銀行名義で計上されるためであり、「信託銀行」という部門は実質的に複数の最終投資家の合成である点に注意が必要である。

## 2. 東証「投資部門別売買状況」の読み方

東京証券取引所は毎週（原則木曜午後）、前週分の**投資部門別売買状況**を公表する。二市場（プライム・スタンダード等の現物）ベースで、各部門の売り・買いの金額と株数が示される。分析上の基本量は**差引（ネット買越額）**である。

$$\text{ネット買越額}_i = \text{買い金額}_i - \text{売り金額}_i$$

市場全体では自己（証券会社の自己勘定）と委託を合わせるとネットはほぼゼロに近づくため（誰かの買いは誰かの売り）、意味を持つのは**どの部門が買い越し、どの部門が売り越したかという構図**である。実務上のポイントは以下の通り。

- **現物と先物を合算して見る**。海外投資家は先物（日経225・TOPIX先物）でエクスポージャーを機動的に調整するため、大阪取引所公表の先物手口と合算した「現先合計」が実勢を表す。現物買い越しでも先物で大幅売り越しなら、実質は弱気と読める。
- **海外投資家が売買代金の6〜7割**（2020年代の東証プライム委託売買代金ベースの概数）を占めるため、株価の方向性は海外勢のフローとの相関が最も高い。歴史的にも、2013年のアベノミクス初年に海外投資家は現物を年間約15兆円買い越し（過去最大級、2013年時点）、日経平均の急騰を主導した。
- **週次データは2営業日程度のラグ**があるため、足元の需給を推定するには先物手口や裁定残高（裁定買い残の増減は実質的に海外勢の先物買いを映す）で補完する。

## 3. 各部門の行動特性

**海外投資家**：トレンドフォロー（順張り）傾向が強く、グローバルなリスクオン・オフ、円相場、日本の構造改革期待に反応する。売買代金シェアの大きさゆえ、短期の株価変動の主因となる。マクロ系ヘッジファンド（先物中心・回転が速い）と、年金・SWF等の長期資金（現物中心・遅い）が混在している点に注意。

**個人投資家**：一貫して**逆張り**傾向を示す。株価下落局面で買い越し、上昇局面で利益確定の売り越しに回るパターンが投資部門別データで繰り返し観測される。背景には、高値づかみした塩漬け株の「やれやれ売り」（戻り局面での売却）や、値ごろ感に基づく押し目買いの文化がある。2024年開始の新NISA（成長投資枠年240万円・つみたて投資枠年120万円、非課税保有限度額1,800万円、2024年時点の制度）は、個人の積立型の恒常的買いフローを生む一方、資金の相当部分は外国株投信に向かっており、日本株需給への寄与は限定的との指摘もある（2024〜2025年時点の議論）。

**信託銀行**：年金勢の売買を映す。GPIF（年金積立金管理運用独立行政法人）の基本ポートフォリオは2020年4月以降、**国内株式25%・外国株式25%・国内債券25%・外国債券25%**（乖離許容幅は国内株式±8%等、2020年時点）であり、株価が急騰して国内株のウェイトが上限に近づくと**リバランス売り**、急落時には**リバランス買い**が発生する。したがって信託銀行のフローは典型的な逆張り（機械的リバランス）となり、市場の変動を減衰させる緩衝材として機能する。株価変化率を $r$、目標ウェイトを $w^*$ とすると、リバランス必要額は概ね資産総額 × $(w - w^*)$ に比例し、$w$ は $r$ の増加関数なので、上昇局面ほど売り需要が生じる。

**事業法人**：近年は**自社株買い**の主体として最大級の買い手である。東証データ上、事業法人の買い越しの大半は自己株式取得を反映しており、2023〜2024年度には日本企業の自社株買い設定額が年間15兆円超（2024年度時点の概数）と過去最高を更新した。自社株買いは発行済株式数の減少を通じてEPSを押し上げる恒常的な需給の下支えである。一方、持ち合い解消の売りも同じ「事業法人・金融機関」のフローに現れるため、ネットで読む必要がある。

**都銀・地銀・生損保**：政策保有株の縮減により構造的な売り越し主体。売却は市場インパクトを抑えるため立会外や自社株買いへの応募で処理されることも多い。

**日銀（ETF経由）**：2010年開始のETF買入れにより、日銀は簿価約37兆円・時価約70兆円超（2024〜2025年時点の概数）のETFを保有する事実上の最大級の株主となった。2024年3月に新規買入れは終了し、2025年には売却（処分）方針が議論・決定に向かったが、市場への影響を抑えるため極めて長期（単純計算で100年規模との試算もある）にわたる緩慢な売却が想定されている（2025年時点）。需給分析上は「巨大な固定保有＝浮動株の減少」として機能してきた点と、処分開始が心理的な上値抑制要因になり得る点の両面を押さえておく。

## 4. 需給分析への応用

投資部門別売買状況を使った実践的な読み方の例。

1. **上昇局面の持続性判定**：海外投資家の現先合計の買い越しが続いているか。個人の売り越し（逆張り売り）を海外勢の買いが吸収している構図は健全な上昇とされることが多い。
2. **底入れシグナル**：急落後に個人と信託銀行（年金リバランス）の買い越しが観測され、海外勢の売りが細る局面は、需給の転換点として注目される。
3. **裁定買い残との併用**：裁定買い残の急増は先物主導の投機的買いの蓄積を意味し、巻き戻し（裁定解消売り）リスクの指標になる。
4. **構造フローの分離**：自社株買い（恒常的買い）、持ち合い解消（恒常的売り）、新NISA積立（恒常的買い）といった価格非感応的なフローと、海外短期筋の価格感応的フローを分けて考えることで、水準感とモメンタムを区別できる。

なお、部門別データはあくまで市場全体の集計であり、個別銘柄の需給は大株主異動、空売り残高（0.5%以上の残高報告、2013年導入の制度、2013年時点）、信用取引残高などで補完する必要がある。
