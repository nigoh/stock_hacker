# 会計品質の分析と粉飾決算の検出

決算書は「正しい」前提で読む基礎編（reading-japanese-financials）に対し、本稿は「疑って読む」応用編である。利益の質をアクルーアル分析やBeneish M-Scoreで定量評価する手法、オリンパス・東芝・カネボウに代表される日本の会計不正の手口の類型、そして監査意見・継続企業の前提・内部統制報告書という制度的な警報装置の読み方を整理する。粉飾は事後には自明だが、事前には「利益とキャッシュの乖離」という形で兆候が現れることが多い。

## 利益の質：アクルーアル分析

会計上の純利益は、現金収支（キャッシュフロー）と、会計上の見積り・期間配分による調整（アクルーアル＝会計発生高）に分解できる。

$$\text{純利益} = \text{営業キャッシュフロー} + \text{アクルーアル}$$

したがって実務上最も簡便なアクルーアルの定義は次の通りで、総資産で基準化して企業間比較する。

$$\text{Accruals}_t = \frac{NI_t - CFO_t}{\left(TA_t + TA_{t-1}\right)/2}$$

ここで $NI$ は純利益、$CFO$ は営業CF、$TA$ は総資産。直感的には「利益のうち、まだ現金で裏付けられていない部分の割合」である。売掛金の積み上げ、棚卸資産の膨張、費用の資産化（開発費・のれん等）はいずれもアクルーアルを押し上げる。Sloan（1996年）の実証研究以来、**アクルーアルが高い企業の将来リターンは低い**（アクルーアル・アノマリー）ことが知られており、これは高アクルーアル利益の持続性が低い（平均回帰しやすい）にもかかわらず市場が利益の額面を過大評価するためと解釈される。

チェックの実務は単年ではなく時系列で行う。**純利益は増えているのに営業CFが数期連続で純利益を下回る**、あるいは**売上高の伸び率を売上債権・棚卸資産の伸び率が大きく上回る**（押し込み販売・架空売上・滞留在庫の兆候）パターンが典型的な危険信号である。日本基準の間接法CF計算書では、営業CFの内訳に「売上債権の増減」「たな卸資産の増減」が明示されるため、乖離の原因科目まで遡って特定できる。

## Beneish M-Score

Beneish（1999年）は、利益操作企業を判別する8変数モデルを提案した。

$$M = -4.84 + 0.92\,DSRI + 0.528\,GMI + 0.404\,AQI + 0.892\,SGI + 0.115\,DEPI - 0.172\,SGAI + 4.679\,TATA - 0.327\,LVGI$$

| 変数 | 内容 | 直感 |
|---|---|---|
| DSRI | 売上債権回転日数の前年比 | 上昇＝架空売上・押し込みの疑い |
| GMI | 売上総利益率の前年比（前年/当年） | 粗利悪化企業ほど操作誘因が強い |
| AQI | 資産の質（固定資産・流動資産以外の「その他資産」比率）の変化 | 費用の資産化の疑い |
| SGI | 売上高成長率 | 高成長企業ほど成長維持のプレッシャー |
| DEPI | 減価償却率の低下 | 耐用年数延長による利益かさ上げ |
| SGAI | 販管費率の変化 | — |
| TATA | 総アクルーアル/総資産 | 係数最大。上記アクルーアルと同旨 |
| LVGI | レバレッジの変化 | 財務制限条項回避の誘因 |

$M > -1.78$ が操作企業の疑いの目安とされる。米国データで推定されたモデルであり、のれん規則償却や引当金慣行が異なる日本企業にそのまま適用すると偽陽性が出やすいが、**時系列での悪化方向**と**同業比較**に使えば有効なスクリーニングになる。銀行・保険等の金融業には適用しない。

## 日本の代表的会計不正と手口の類型

| 事例 | 発覚 | 手口の類型 |
|---|---|---|
| カネボウ | 2004〜2005年 | 債務超過隠し。赤字子会社の**連結外し**、押し込み販売による架空売上。約2,000億円超の粉飾で2005年上場廃止。監査法人（中央青山）の関与が問われ解体につながった |
| オリンパス | 2011年 | バブル期の財テク損失の**「飛ばし」**（簿外ファンドへの含み損移転）を約20年隠蔽し、実態と乖離した**M&A手数料・のれん**で穴埋め・償却処理。約1,100億円超の損失先送り |
| 東芝 | 2015年 | **工事進行基準**の原価総額の過少見積り、部品の**バイセル取引**を利用した利益前倒し、経費計上の先送り。経営トップの「チャレンジ」という利益目標のプレッシャーが動機。利益修正額は約2,200億円超 |
| ライブドア | 2006年 | 自社株売却益の売上計上、投資事業組合を介した**連結外しと還流**による架空利益 |

類型としては、(1) 収益の前倒し・架空計上（東芝の工事進行基準、カネボウの押し込み）、(2) 費用・損失の隠蔽（オリンパスの飛ばし）、(3) 連結範囲の操作（カネボウ、ライブドア）に大別できる。共通するのは、**単一の巨額の嘘ではなく、見積り項目（工事原価、のれん、引当金、連結範囲）という監査人と経営者の裁量の余地が大きい領域が使われる**ことである。東芝事件を契機に「不正リスク対応基準」の運用強化や監査法人のローテーション議論が進み、2020年3月期からは有報で**KAM（監査上の主要な検討事項）**の記載が求められるようになった（2020年時点）。KAMは監査人が何を重点リスクと見たかを開示するもので、疑って読む際の出発点として有用である。

## 制度的な警報装置の読み方

- **監査意見**：無限定適正／限定付適正／不適正／意見不表明の4段階。限定付適正以下は極めて稀で、出た時点で重大シグナル。意見不表明は東証の上場廃止基準に関わる。過年度訂正の際は「訂正有価証券報告書」が提出される。
- **継続企業の前提（GC）**：疑義が生じ、対応策を講じてもなお**重要な不確実性が残る**場合に財務諸表への注記となる。注記に至らない段階でも、有報の「事業等のリスク」等に**重要事象等**の記載が入ることがあり、この「注記の一歩手前」の記載変化を追う価値が高い。
- **内部統制報告書（J-SOX）**：2008年4月以後開始年度から経営者による内部統制の有効性評価と監査人の検証が義務化（2008年時点）。**「開示すべき重要な不備」**の記載や、評価範囲の限定・提出遅延は不正発覚の随伴事象として頻出する。
- **その他の適時開示**：監査法人の期中交代（特に大手から中小への交代）、決算発表の延期、第三者委員会の設置は、いずれも統計的に不正・訂正と関連が深いイベントである。

## 粉飾兆候チェックリスト

- 純利益と営業CFの乖離が2期以上継続（$CFO < NI$ が常態化）
- 売上債権回転日数・棚卸資産回転日数の趨勢的な悪化（売上成長との不整合）
- 売上総利益率の急変（同業比で説明のつかない改善は特に注意）
- のれん・無形資産・「その他」資産の膨張（費用の資産化）
- 監査法人の交代・監査報酬の不自然な低さ・決算発表の延期
- 連結子会社（特に海外・非上場）の増減が激しい、持分法適用の出入り
- 経営者の交代拒否・創業家支配・過度に野心的な中期計画（動機とプレッシャー）
- 第4四半期に利益が集中する季節性の説明がつかないパターン

定量指標は単独では偽陽性が多い。**動機（業績プレッシャー・財務制限条項）、機会（統治の弱さ・見積り裁量の大きい事業）、正当化**という不正のトライアングルの文脈と重ねて初めて解釈できる点に留意したい。
