# 日本株のセクター構造と業種分析

日本株の業種分類は東証33業種とTOPIX-17に大別され、時価総額構成は高度成長期の重厚長大産業から金融バブル、そして電機・自動車・情報通信中心へと大きく変遷してきた。本稿では主要セクターの収益構造の特性、景気敏感／ディフェンシブ・外需／内需という二軸の整理、およびセクターローテーションの考え方をまとめる。銘柄選択の前提となる「地図」としての業種理解を目的とする。

## 1. 業種分類の枠組み：東証33業種とTOPIX-17

日本株の業種分類の標準は、証券コード協議会が定める**東証33業種**（水産・農林業、鉱業、建設業、食料品、…、銀行業、保険業、その他金融業、不動産業、サービス業）である。1990年代から使われている歴史ある分類だが、粒度の偏りが問題として指摘されてきた。例えば「輸送用機器」にはトヨタもデンソーも含まれる一方、繊維製品や鉱業のように時価総額比率が1%に満たない業種も独立に存在する（2025年時点）。また東レ（炭素繊維）が「繊維製品」、富士フイルムが「化学」に分類されるなど、祖業ベースの分類が実態と乖離する例も多い。

この粗密を均すために2011年に導入されたのが**TOPIX-17シリーズ**で、33業種を17グループ（食品、エネルギー資源、建設・資材、素材・化学、医薬品、自動車・輸送機、鉄鋼・非鉄、機械、電機・精密、情報通信・サービスその他、電力・ガス、運輸・物流、商社・卸売、小売、銀行、金融（除く銀行）、不動産）に集約した。セクターETF（NEXT FUNDS等）はこの17分類ベースで組成されており、実務のセクター配分ではTOPIX-17、個別の業種比較では33業種、という使い分けが一般的である。なお外国人投資家はGICS（世界産業分類基準）で日本株を見ることが多く、33業種とGICSの対応のずれ（例：33業種の「その他製品」に任天堂が入る等）は認識しておく価値がある。

## 2. 時価総額構成の変遷

- **1980年代末（バブル期）**：銀行・証券・不動産で東証時価総額の3割超を占め、1989年時点で世界時価総額上位を邦銀が独占した。
- **1990〜2000年代**：金融セクターの崩落と不良債権処理で銀行のウェイトが急低下。代わって電機（ソニー、松下）、自動車（トヨタ）、通信（NTT、NTTドコモ）が主役に。
- **2010年代以降**：円安と海外生産比率上昇で輸送用機器が最大級の業種に定着。情報通信（ソフトバンクG、リクルート等をサービス業と合わせて）、半導体関連（東京エレクトロン、アドバンテスト等＝「電気機器」）、総合商社の存在感が拡大。2020年代半ば時点では、電気機器・輸送用機器・情報通信業・銀行業・卸売業（商社）あたりが時価総額上位業種である（2025年時点）。

この変遷が示す教訓は、**指数の業種構成は固定的でなく、10〜20年単位で主役が入れ替わる**こと、そして日本の場合その転換が「金融→製造業輸出→半導体・商社」という円と世界景気の関数として起きてきたことである。

## 3. 主要セクターの特性

| セクター | 代表企業 | 主な収益ドライバー | 特性 |
|---|---|---|---|
| 自動車（輸送用機器） | トヨタ、ホンダ、デンソー | 世界販売台数、為替（円安=増益）、原材料 | 外需・景気敏感。系列部品メーカーまで裾野が広い |
| 電機・精密 | ソニーG、日立、東エレク | 半導体サイクル、設備投資、AI需要 | 外需・景気敏感。シリコンサイクルの影響大 |
| 総合商社（卸売業） | 三菱商事、伊藤忠 | 資源価格、事業投資の持分利益 | 資源市況＋非資源のハイブリッド。低PBRが是正されつつある局面が話題に（2020年代） |
| 銀行 | 三菱UFJ、三井住友 | 利ざや（金利水準）、与信費用 | 金利上昇の恩恵。長年のゼロ金利で抑圧され、2024年のマイナス金利解除以降に再評価（2025年時点） |
| 医薬品 | 武田、第一三共 | パイプライン、薬価改定 | ディフェンシブだが個別R&Dリスク大。薬価は2年に1度（近年は毎年）改定される制度リスクあり（2025年時点） |
| 食品・小売・電力ガス | 味の素、セブン&アイ、東電 | 国内消費、コスト転嫁力 | 内需・ディフェンシブ。ただし電力は燃料費と規制で振れる |
| 不動産 | 三井不動産、三菱地所 | 賃料・地価、金利 | 金利敏感。含み益（簿価と時価の差）の評価が論点 |

## 4. 二つの分析軸：景気敏感 vs ディフェンシブ、外需 vs 内需

日本株のセクター分析では、次の2軸のマトリクスで整理すると見通しがよい。

- **景気敏感（シクリカル）**：機械、鉄鋼、化学、海運、自動車、電機。利益が景気循環で大きく振れるため、PERは**好況期に低く不況期に高く見える**（ピーク益で割ると割安に見える）逆張り的な読み方が必要。
- **ディフェンシブ**：食品、医薬品、通信、電力ガス、鉄道。利益変動が小さくβが低い。
- **外需**：自動車、電機、機械、海運。円安と世界PMIに感応。輸出企業の想定為替レートと実勢の乖離が業績修正の源泉になる。
- **内需**：銀行、小売、不動産、建設、サービス。国内金利・賃金・消費に感応。

為替感応度の目安として、**円安1円（対ドル）でトヨタの営業利益は年間数百億円規模で押し上げられる**とされてきた（会社側公表の感応度は年度により変動、2025年時点）。日本市場全体でも「円安=株高」の相関が長く観測されてきたが、輸入コスト増が内需企業を圧迫するため、円安の恩恵は外需セクターに偏る点に注意する。

## 5. セクターローテーション

景気循環の局面ごとに優位なセクターが入れ替わるという経験則がセクターローテーションである。教科書的な循環は次の通り。

1. **金融相場（不況末期・金融緩和）**：金利低下 → 不動産、銀行以外の金融、素材・市況株の先回り買い
2. **業績相場（回復〜好況）**：機械、電機、自動車など景気敏感・外需株
3. **逆金融相場（金融引き締め）**：利上げ → 銀行・保険（利ざや拡大）、資源
4. **逆業績相場（後退期）**：食品、医薬品、通信などディフェンシブへ退避

日本固有の修正点として、(1) 日本の金利サイクルは日銀の政策に強く規定され、米国と位相がずれることがある（2024年のマイナス金利解除は世界の利下げ局面と逆行した、2025年時点）、(2) 外需比率が高いため「日本の景気」より「米中の景気と為替」でローテーションが駆動されやすい、の2点が重要である。

相対強度（レラティブ・ストレングス）でローテーションを定量化する場合、セクター指数 $S_t$ と市場指数 $M_t$ の比

$$RS_t = \frac{S_t / S_{t-n}}{M_t / M_{t-n}}$$

を用いる。$RS_t > 1$ なら当該セクターが過去 $n$ 期間で市場をアウトパフォームしたことを意味し、この系列の水準と変化率（モメンタム）を2軸にプロットするのがRRG（レラティブ・ローテーション・グラフ）の考え方である。またセクターの市場感応度は回帰

$$r_{sector,t} = \alpha + \beta \, r_{TOPIX,t} + \varepsilon_t$$

の $\beta$ で測り、景気敏感セクターは $\beta > 1$、ディフェンシブは $\beta < 1$ となるのが典型である。直感的には、$\beta$ は「市場が1%動いたときにそのセクターが何%動くか」の平均的な連動倍率であり、利益の景気感応度と財務レバレッジの両方を反映する。

## 6. 実務上の留意点

- 33業種の**業種間バリュエーション比較は無意味に近い**（銀行のPBR0.5倍と情報通信のPBR3倍は資本構造・成長率の差の反映）。比較は同一業種内、または時系列の自セクター比で行う。
- 東証の「資本コストや株価を意識した経営」要請（2023年〜）以降、低PBRセクター（銀行、鉄鋼、商社等）の是正買いという制度起点のセクター物色が生じた（2025年時点）。制度イベントがローテーションの起点になり得る点は日本市場の特徴である。
- 同一業種でも事業ポートフォリオの多角化（ソニー＝電機×金融×エンタメ、富士フイルム＝化学×医薬）で業種ラベルと実態が乖離するため、最終的にはセグメント情報での確認が不可欠である。
