# グローバル・ポートフォリオの中の日本株

海外のアセットアロケーターにとって日本株は「世界株ポートフォリオの約5%を占める一構成要素」であり、その配分判断は日本国内の投資家とはまったく異なる座標系で行われる。本稿は ACWI・EAFE の中での日本のウエイト、市場時価総額比を基準としたオーバーウエイト/アンダーウエイトの判断枠組み、米国株との相関と円の逆相関がもたらす分散効果、CAPE・PBR の国際バリュエーション比較を「外国株としての日本株」の視点から整理する。ドル建てリターンの分解とヘッジ実務は [ドル建て日本株リターンと為替ヘッジの実務](../macro/usd-based-returns-and-currency-hedging.md)、投資手段（ADR・ETF・先物）は [海外から日本株に投資する手段](../market-structure/foreign-investor-access-channels.md) に譲る。

## 1. 世界株インデックスの中の日本：約5%という現実

グローバル運用の出発点は MSCI ACWI や FTSE Global All Cap のような世界株指数であり、各国のウエイトは浮動株調整後時価総額比で決まる。2025年時点の ACWI のおおよその国別構成は次の通り（概数）。

| 国・地域 | ACWI ウエイト（2025年時点、概数） |
|---|---|
| 米国 | 約 64〜66% |
| **日本** | **約 5%** |
| 英国 | 約 3% |
| 中国 | 約 3% |
| その他先進国・新興国 | 約 23〜25% |

日本は**米国に次ぐ単一国として第2位**のウエイトを持つが、それでも米国の1/13程度にすぎない。1980年代末には MSCI World の4割超を日本が占めた時期があり（[1980年代バブルとその崩壊](../history/bubble-economy-and-collapse.md)）、現在の約5%はその長期的な縮小の帰結である。オルカン（ACWI連動投信）を買う日本の個人が「自国株を5%しか持たない」ことに驚くのと対称的に、海外投資家にとってはこの5%が中立点（ニュートラル・ウエイト）となる。

先進国株から米国を除いた **MSCI EAFE**（Europe, Australasia, Far East）では日本は**単一国として最大の約 21〜23%**（2025年時点、概数）を占める。米国の年金・401(k) の「国際株式（International Equity）」枠は EAFE 型マンデートが多いため、EAFE ファンドのマネージャーにとって日本の判断はポートフォリオの成否を左右する最大の単一国判断になる。日本だけを機動的に外せる **EAFE ex-Japan** という商品カテゴリが存在すること自体、日本が「個別判断の対象となる唯一のアジア先進国大型市場」であることの証左である。

## 2. 配分判断の枠組み：中立ウエイトからの乖離として

グローバル・アロケーターの意思決定は「日本株を買うか買わないか」ではなく「時価総額ウエイト $w_{bench}$ に対してどれだけ乖離させるか」である。アクティブ・ウエイトを $\Delta w = w_{port} - w_{bench}$ とすると、期待される付加価値と引き受けるトラッキングエラーは

$$\alpha_{active} \approx \Delta w \cdot (r_{JP} - r_{ACWI}), \qquad TE \approx |\Delta w| \cdot \sigma(r_{JP} - r_{ACWI})$$

に比例する。日本の相対リターンの年率ボラティリティは概ね10%超あるため、±2〜3%ポイントの傾け（ウエイト5%を3〜8%にする程度）でも国別判断としては大きなアクティブリスクになる。判断の時間軸は通常、(1) 戦略的配分（SAA）＝時価総額比かそれに準じる固定比率、(2) 戦術的配分（TAA）＝6ヶ月〜2年でのオーバー/アンダーウエイト、の二層で行われ、日本が議論されるのはほぼ後者である。

この枠組みの含意として、**海外勢の「日本買い」はベンチマーク比+数%の調整でも円換算では巨額のフロー**になる。ACWI 連動資産の裾野を考えれば、グローバル投資家が日本を1%ポイント引き上げるだけで数十兆円規模の資金シフトに相当し、海外投資家が売買代金の6〜7割を占める東京市場の株価を動かすには十分である（フローの実証は [海外投資家の日本株投資テーマ史](foreign-investor-themes-history.md)）。

## 3. 分散効果：相関と「円」という内蔵ヘッジ

### 3.1 米国株との相関

日米株式の日次〜月次リターン相関はグローバル化とともに上昇し、2000年代以降は概ね 0.6〜0.7（ドル建て月次、2025年時点の概数）で推移する。分散効果は昔ほどではないが、ポートフォリオ分散の一般式

$$\sigma_p^2 = \sum_i \sum_j w_i w_j \rho_{ij} \sigma_i \sigma_j$$

において $\rho < 1$ である限り分散便益は残る（[ポートフォリオ理論とCAPM](../math/portfolio-theory.md)）。加えて日本株は、米国が「一握りの超大型テック」に集中するのと対照的に製造業・資本財の比重が高く、**セクター構成の補完性**が国レベルの相関数値以上の分散を与える（[日本株のセクター構造と業種分析](../fundamental/sector-structure-japan.md)）。

### 3.2 円の逆相関によるドル建てボラ低減

海外投資家に固有の分散効果が**円のリスクオフ特性**である。アンヘッジのドル建てリターン $r_{USD} \approx r_{JPY} + r_{FX}$ の分散は

$$\sigma_{USD}^2 \approx \sigma_{JPY}^2 + \sigma_{FX}^2 + 2\rho_{JPY,FX}\,\sigma_{JPY}\sigma_{FX}$$

であり、株安局面で円高（$r_{FX}>0$）になりやすい日本では $\rho_{JPY,FX} < 0$、すなわち**アンヘッジ日本株のドル建てボラティリティは円建てより低くなり得る**。株式部分が下がるとき通貨部分が緩衝材として働くこの「自然ヘッジ」は、米国株にもドル建て他国株にも無い日本株固有の性質である（詳細と2024年以降の変質は [ドル建て日本株リターンと為替ヘッジの実務](../macro/usd-based-returns-and-currency-hedging.md)、円高メカニズムは [海外市場との連動と日本株のグローバル要因](../macro/global-markets-and-japan-linkage.md)）。逆に言えば、ヘッジ付き（DXJ 型）を選ぶ投資家はこの内蔵ヘッジを手放して金利差キャリーを取る取引をしている。

## 4. バリュエーションの国際比較：CAPE と PBR

国別 TAA の実証で最も広く使われるのが Shiller の CAPE（景気循環調整後PER）

$$CAPE = \frac{P}{\overline{E}_{10yr,\ real}}$$

である。10年平均実質利益を分母に取ることで一時的な利益変動を均し、国際比較と長期リターン予測（CAPE の逆数 ≒ 長期実質リターンの目安）に使う。2025年時点の概観：

| 市場 | CAPE（概数） | PBR（概数） |
|---|---|---|
| 米国（S&P 500） | 35前後 | 5倍前後 |
| **日本（TOPIX）** | **20台前半〜半ば** | **1.5倍前後** |
| 欧州 | 20前後 | 2倍前後 |
| 新興国 | 15前後 | 2倍弱 |

日本は先進国の中で欧州と並ぶ低バリュエーション圏にあり、対米国では歴史的に大きなディスカウントにある。ただし海外投資家はこの数字を機械的には使わない。注意点は三つ。(1) 日本の CAPE は1980年代バブル期に 90 前後まで達した経緯があり、分母の10年利益にデフレ期・危機期が入るかで水準が大きく振れる。(2) 低 PBR は政策保有株・過剰現金・低 ROE の反映でもあり、「安い」と「収益性が低い」の分離が必要（PBR = PER × ROE の分解は [バリュエーション指標と日本株特有の論点](../fundamental/valuation-metrics.md)）。(3) バリュエーション・ギャップは何年も解消しないことがあり、CAPE 単独の国別ローテーションはタイミングを教えてくれない。だからこそ海外勢は**割安さそのものではなく「割安を解消するカタリスト」**——2023年以降なら東証の資本コスト経営要請とガバナンス改革——を重視する（[コーポレートガバナンス改革と株主還元](../regulation-tax/corporate-governance.md)）。

## 5. オーバーウエイト/アンダーウエイトの判断材料

海外アロケーターの日本判断で繰り返し登場する変数を整理する。

| 判断材料 | オーバーウエイト方向 | アンダーウエイト方向 |
|---|---|---|
| バリュエーション | 対米 CAPE/PBR ディスカウント拡大 | ギャップ縮小・出尽くし |
| 企業改革 | 自社株買い・還元の加速、PBR 1倍割れ解消の進展 | 改革の停滞・「今回も竜頭蛇尾」 |
| EPS モメンタム | 円安による上方修正サイクル | 円高反転・世界景気減速（外需比率の高さが逆回転） |
| 金融政策 | 緩和的（実質金利マイナス） | 拙速な引き締め・円急騰 |
| 為替 | 円が割安（実質実効レートの歴史的低水準） | 円高がドル建てリターンを支える一方、円建て EPS を毀損する両義性 |
| ポジショニング | 海外勢の持ち高が軽い（失望売り後） | 「Japan is back」合意形成後の混雑 |

重要なのは、これらが**しばしば互いに逆向きに働く**ことである。円安は輸出企業の EPS を押し上げるがドル建て指数リターンを削り、円高はその逆になる（[為替と日本株](../macro/fx-and-japanese-stocks.md)）。つまり海外投資家の日本判断は「株の見通し」と「円の見通し」の連立方程式であり、株に強気・円にも強気（円高予想）のときに最も強いアンヘッジ買いが入る。また海外勢の期待は歴史的に「構造改革テーマへの集中買い→失望→撤退」を繰り返しており、現在の強気論を過去のサイクルに照らして相対化する視点が欠かせない（[海外投資家の日本株投資テーマ史](foreign-investor-themes-history.md)）。

## 6. ホームバイアスの裏返し：外国株としての日本株

自国株を時価総額比以上に持つホームバイアスは世界共通の現象であり、米国投資家の典型的な株式配分は米国 70〜80% と、ACWI の米国比率をさらに上回る。その裏返しとして、**日本株は海外投資家にとって「無くても困らない 5%」**である——保有ゼロでもトラッキングエラーは限定的で、調査コスト（言語・開示・時差）を考えれば「EAFE ファンドでまとめて持つ」か「指数先物・ETF で済ませる」のが合理的な既定解になる。この構造は二つの含意を持つ。第一に、日本株への資金流入は個別銘柄の精査よりも**国・指数単位の判断で動く**ため、フローは先物・大型株・指数採用銘柄に集中しやすい。第二に、カバレッジの薄い中小型株には海外勢の目が届かず、ミスプライシングが残存しやすい（[中小型株・グロース株投資の実務](small-cap-growth-investing.md)）。日本の投資家が自国市場で持つ情報・言語の優位は、海外勢のこの「合理的な無関心」の裏側にこそある。

なお、非居住者の配当課税（租税条約で軽減）や外為法の事前届出など、海外投資家固有の制度コストも配分判断の周辺条件になる（[非居住者の日本株課税と租税条約](../regulation-tax/nonresident-taxation-and-treaties.md)、[外資規制と対内直接投資審査](../regulation-tax/foreign-ownership-restrictions.md)）。
