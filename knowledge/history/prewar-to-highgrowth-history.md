# 戦前から高度成長期までの日本株市場史

本稿は、1878年の東京株式取引所設立から1970年前後の高度成長期末期までの日本株式市場の歩みを整理する。戦前の清算取引中心の市場構造、戦時統制と1945年の取引所閉鎖、1949年の取引所再開と財閥解体による「株式民主化」、そして高度成長期における株価上昇と資本市場の制度発展を、当時の制度・数値とともに解説する。

## 1. 東京株式取引所の設立（1878年）と黎明期

明治政府は殖産興業のための資金調達インフラとして証券市場の整備を急ぎ、1878年（明治11年）に「株式取引所条例」を公布した。同年5月に**東京株式取引所（東株）**が渋沢栄一らの尽力で兜町に設立され、6月1日に売買を開始した。数か月遅れて**大阪株式取引所（大株）**も北浜に開設され、以後「兜町」「北浜」は日本の証券市場の代名詞となる。

初期の上場銘柄は、皮肉なことに株式よりも**秩禄処分に伴い発行された金禄公債などの公債**が売買の中心であった。株式では、東京株式取引所自身の株式（いわゆる「東株」）が長く代表的な投機銘柄となったことが特徴的である。

## 2. 戦前市場の構造 — 清算取引の時代

戦前の日本市場を理解する鍵は、現物取引ではなく**清算取引（定期取引）**が売買の主流だった点にある。清算取引は3か月以内の期限（限月）を定め、期日に差金決済または受渡しを行う先物類似の制度で、少ない証拠金で大きな建玉を持てるため投機色が強かった。当時の市場は今日でいうデリバティブ市場に近い性格を持ち、「取引所は投機の場、事業資金の調達は銀行借入と縁故募集」という役割分担が戦前日本の金融構造（間接金融優位の原型）を形づくった。

戦前市場の主な画期は以下のとおり。

| 年 | 出来事 |
|---|---|
| 1878 | 東京株式取引所・大阪株式取引所設立 |
| 1894–95 / 1904–05 | 日清・日露戦争後の企業勃興ブームと反動恐慌 |
| 1914–18 | 第一次大戦ブーム（大戦景気）。船成金・鉄成金が続出し株価急騰 |
| 1920 | 戦後恐慌で株価暴落。以後、昭和金融恐慌（1927）へ続く不安定期 |
| 1923 | 関東大震災。東株は一時立会停止 |
| 1930–31 | 金解禁・昭和恐慌で株価低迷、1931年末の金輸出再禁止で反騰 |

なお、戦前の株式は**額面株式（多くは額面50円）で分割払込制**が一般的だった。株主は未払込部分の追加払込義務を負っており、恐慌時にはこの払込請求が株主を直撃した。この仕組みは戦後の商法改正（1950年）で全額払込制に改められる。

## 3. 戦時統制と取引所の閉鎖

日中戦争の本格化以降、市場は急速に統制色を強める。

- **1943年**：「日本証券取引所法」により全国11か所の株式取引所を統合し、半官半民の特殊法人**日本証券取引所（日証）**が発足。自由な価格形成は事実上失われ、価格維持機関として1941年設立の日本共同証券とは別系統の**戦時金融金庫**や日本証券取引所自身による買い支えが行われた。
- **1945年8月**：敗戦直前の8月10日に立会停止。日本証券取引所は事実上機能を停止し、1947年に閉鎖機関として解散した。

取引所閉鎖後も株式売買の需要は消えず、証券業者の店頭や街頭で**集団売買（店頭市場）**が自然発生的に続いた。1945〜49年の約4年間、日本の株式流通はこの非公式市場が担っており、後の店頭市場・証券会社仲介文化の源流の一つとなった。

## 4. 財閥解体と「証券民主化運動」

GHQ占領下の経済民主化政策は、株式市場の所有構造を根本から変えた。

1. **財閥解体（1946〜）**：持株会社整理委員会（HCLC）が三井・三菱・住友・安田など財閥本社の保有株式を接収。
2. **株式の放出**：接収された株式は、従業員・地域住民への優先売出しなどを通じて広く一般に売却された。これが**「証券民主化運動」**であり、「株式を国民のものに」というスローガンの下、1948〜49年頃に大規模な個人への株式分散が実現した。
3. **独占禁止法（1947年制定）**：持株会社の設立禁止（当時）により、戦前型のピラミッド型企業支配は制度的に封じられた。

この結果、**1949年度の個人株主の持株比率は約69%**（東証統計、1949年時点）に達し、日本の株式市場史上もっとも「個人の市場」に近い状態が出現した。もっとも、この個人優位は長続きせず、1950〜60年代を通じて金融機関・事業法人の持株比率が上昇し、いわゆる**株式持ち合い**（安定株主工作）へと逆流していく。1964年のOECD加盟に伴う資本自由化を控え、外資による乗っ取りへの防衛策として持ち合いが加速した点は、その後の日本市場のガバナンス問題を考えるうえで重要な伏線である。

## 5. 取引所再開（1949年）と証券取引法体制

1948年に米国の1933年証券法・1934年証券取引所法をモデルとする**証券取引法**（現・金融商品取引法の前身）が制定され、1949年4月に会員組織の**東京証券取引所**が設立、**5月16日に売買立会を再開**した。大阪・名古屋も同時期に再開している。再開にあたりGHQが示した原則は**「取引所三原則」**と呼ばれる。

- 取引は取引所に集中すること（市場集中原則）
- 売買は時間優先・価格優先で公正に執行すること
- **先物類似の清算取引を復活させないこと**（現物取引主義）

戦前の投機市場からの決別を意図したこの三原則、特に現物取引主義は、その後長く日本市場の性格を規定した（株価指数先物の再登場は1980年代後半まで待つことになる）。また証券取引法65条（1948年制定時）により**銀行と証券の分離**（日本版グラス・スティーガル）が導入され、証券会社が流通市場の担い手として制度的に確立した。

なお、現在の**日経平均株価は1949年5月16日の再開初日を起点**とし、当日の単純平均176円21銭から算出が始まっている（当初は東証算出の修正平均株価、後に日本経済新聞社へ移管）。TOPIXは**1968年1月4日の東証一部時価総額を基準値100**として1969年に算出が開始された時価総額加重指数であり、修正平均型の日経平均とは設計思想が異なる。

## 6. 高度成長期の株価と資本市場の発展

### 6.1 株価の推移

1950年の朝鮮戦争特需を契機に株価は本格的な上昇局面に入り、1950年代後半の「神武景気」「岩戸景気」で大相場を演じた。投資信託の急拡大（「銀行よさようなら、証券よこんにちは」の流行語は1961年頃）が個人資金を株式市場へ動員し、日経平均は1961年7月に当時の高値1,829円をつけた。

しかし1961年をピークに市場は長い調整に入る。**1965年の証券不況**では山一證券が経営危機に陥り、日銀法25条に基づく**日銀特融**（1965年）で救済される事態となった。株価下支えのため、銀行団出資の**日本共同証券（1964年設立）**と証券業界出資の**日本証券保有組合（1965年設立）**が大量の株式を買い上げて市場から凍結した。この官民一体の株価維持策（PKOの原型）と、1965年に戦後初めて発行された**赤字国債**を伴う財政出動により市場は底入れし、いざなぎ景気（1965–70年）とともに再び上昇軌道へ戻った。

株価上昇の背景を定量的に見ると、高度成長期の名目GDP成長率は年率およそ15%前後（1955–70年平均、名目）であり、株価の長期期待リターンを配当割引モデルで近似すれば

$$ P = \frac{D_1}{r - g} \quad\Longrightarrow\quad r = \frac{D_1}{P} + g $$

となる。ここで $P$ は株価、$D_1$ は次期配当、$r$ は要求収益率、$g$ は配当成長率である。成長率 $g$ が極めて高い経済では、配当利回り $D_1/P$ が低くても高い株式リターンが正当化される。実際、1950年代までは「利回り革命」以前で株式利回りが債券利回りを上回っていたが、成長期待の高まりとともに1960年前後に逆転（利回り革命、日本では1959–61年頃）し、株式が「利回り商品」から「成長を買う商品」へと性格を変えた。

### 6.2 制度・市場構造の発展

- **1950年（商法改正）**：授権資本制度・無額面株式の導入、取締役会制度の整備。
- **1951年**：証券投資信託法により契約型投資信託が制度化。高度成長期の個人マネー動員装置となった。
- **1961年10月**：東証に**市場第二部**を創設。中堅企業の上場の受け皿を整備し、一部・二部の指定替え制度が始まった（2022年の市場区分再編まで続く枠組みの原型）。
- **1965年（改正は1965年、施行1968年）**：証券会社を登録制から**免許制**へ移行。証券不況で露呈した業者の経営脆弱性への対応であり、四大証券（野村・大和・日興・山一）体制が制度的に固まった。
- **時価発行増資の萌芽**：戦後長らく続いた**額面（50円）での株主割当増資**は、株価が額面を大きく上回るなかで発行企業に不利であり、1960年代末から時価発行公募増資への移行が始まる（本格化は1970年代）。額面発行では1株を50円で既存株主に割り当てるため、時価 $P$ との差額 $(P-50)$ は既存株主への値引きに等しく、資本コストを歪めていた。

### 6.3 この時代が残したもの

高度成長期までに形成された「間接金融優位・メインバンク制・株式持ち合い・市場集中原則・現物主義」という枠組みは、1980年代のバブル、1990年代以降の金融ビッグバンによる解体まで日本市場の基本構造であり続けた。現在の東証の制度（値幅制限、呼値、単元株制度の源流である額面・単位株の歴史など）の多くは、この時代の制度設計にルーツを持つ。
