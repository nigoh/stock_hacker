# テクニカル指標と一目均衡表

テクニカル指標は価格・出来高の時系列から計算される統計量であり、トレンドの方向やモメンタムの過熱を可視化する道具である。本稿では移動平均、RSI、MACD、ボリンジャーバンド、ストキャスティクスの計算と解釈を整理し、日本発の一目均衡表の5線を詳述する。あわせて、各指標が数理的に何をしているのか、そしてどこに限界があるのかを明確にする。

## 移動平均とゴールデンクロス

単純移動平均（SMA）は直近 $n$ 日の終値 $P_t$ の算術平均である。

$$\mathrm{SMA}_n(t) = \frac{1}{n}\sum_{i=0}^{n-1} P_{t-i}$$

指数移動平均（EMA）は平滑化係数 $\alpha = \frac{2}{n+1}$ を用いた再帰式

$$\mathrm{EMA}_t = \alpha P_t + (1-\alpha)\,\mathrm{EMA}_{t-1}$$

で定義され、直近の価格に大きな重みを置く。数理的にはどちらも**ローパスフィルタ**であり、高周波ノイズを除去してトレンド成分を抽出する。その代償として必然的に**位相遅れ（ラグ）**が生じ、SMA の遅れは概ね $\frac{n-1}{2}$ 日である。

日本市場では日足で 5日（週）・25日（月）・75日（四半期）・200日線が慣習的に使われる。短期線が長期線を下から上に抜くのが**ゴールデンクロス**、逆が**デッドクロス**である。クロスは「短期平均が長期平均を上回った」という事後的な事実確認にすぎず、遅れの大きさゆえにレンジ相場では騙し（ホイップソー）が頻発する点に注意したい。日経平均株価の25日・75日クロスは市況記事でも常套句となっており、多くの参加者が意識すること自体が自己成就的な短期需給を生む場合がある。

## RSI（相対力指数）

J. W. ワイルダーが1978年に考案した RSI は、期間 $n$（通常14）における値上がり幅の平均 $A$ と値下がり幅の平均 $B$ から

$$\mathrm{RSI} = 100 \times \frac{A}{A+B} = 100 - \frac{100}{1+RS}, \quad RS = \frac{A}{B}$$

と計算される（ワイルダー流では $A,B$ に修正移動平均を用いる）。値域は $[0,100]$ に正規化され、慣習的に 70〜80 以上で「買われすぎ」、20〜30 以下で「売られすぎ」と読む。ただし強いトレンド中は RSI が高位・低位に**張り付く**ため、逆張りシグナルとしての有効性はレンジ相場に限られる。価格が高値を更新しても RSI が高値を切り下げる**ダイバージェンス**は、モメンタム減衰の兆候として重視される。

## MACD

MACD は短期 EMA と長期 EMA の差で、標準パラメータは (12, 26, 9)。

$$\mathrm{MACD}_t = \mathrm{EMA}_{12}(t) - \mathrm{EMA}_{26}(t)$$

これを9期間 EMA で平滑化したものが**シグナル線**、両者の差が**ヒストグラム**である。数理的には2つのローパスフィルタの差、すなわち**バンドパスフィルタ**であり、特定の周期帯の変動（トレンドの加速・減速）を抽出している。MACD がシグナル線を上抜けば買い、下抜けば売りと読むのが基本だが、EMA を基礎とする以上ラグは避けられず、もみ合いでは機能しにくい。

## ボリンジャーバンド

ジョン・ボリンジャーが1980年代に考案。期間 $n$（通常20）の SMA を中心線 $\mu_t$ とし、同期間の標準偏差 $\sigma_t$ を用いて

$$\text{バンド} = \mu_t \pm k\sigma_t \quad (k = 1, 2, 3)$$

を描く。もし収益率が独立な正規分布に従うなら $\pm2\sigma$ 内に約95.4%が収まるはずだが、実際の株価収益率は**ファットテール**（裾の厚い分布）かつ自己相関を持つため、この確率解釈は成立しない。むしろバンド幅の収縮（スクイーズ）はボラティリティ・クラスタリングの静穏期を示し、その後の拡大（エクスパンション）と価格がバンドに沿って走る**バンドウォーク**はトレンド発生のサインとして順張りに使われる。「$\pm2\sigma$ タッチで逆張り」という単純な読みは、指標の設計思想（ボリンジャー自身は順張り併用を推奨）と統計的性質の双方から危うい。

## ストキャスティクス

ジョージ・レーンが考案したオシレータで、期間 $n$（通常5〜14）の高値 $H_n$・安値 $L_n$ に対する現在値の相対位置を測る。

$$\%K = 100 \times \frac{P_t - L_n}{H_n - L_n}, \qquad \%D = \%K \text{ の3期間 SMA}$$

$\%D$ をさらに平滑化した Slow\%D を使う「スロー・ストキャスティクス」が実務では一般的。80以上・20以下での $\%K$ と $\%D$ のクロスを逆張りシグナルとするが、RSI 同様、トレンド相場では張り付きが起こる。RSI が「変化幅の比率」を測るのに対し、ストキャスティクスは「レンジ内の位置」を測る点が本質的な違いである。

## 一目均衡表 — 日本発の時間論

一目均衡表は、都新聞の商況部長であった細田悟一（ペンネーム：一目山人）が1936年（昭和11年）に発表した日本独自のチャート理論である。「相場は買い手と売り手の均衡が破れた方向に動き、その帰結は一目瞭然」という思想に基づき、価格だけでなく**時間**を主役に置く点が西洋のテクニカル分析と一線を画す。5本の線は以下のように計算される。

| 線 | 計算式 | 意味 |
|---|---|---|
| 転換線 | $\dfrac{\max(H_9) + \min(L_9)}{2}$ | 過去9日の値幅の中心（短期の均衡点） |
| 基準線 | $\dfrac{\max(H_{26}) + \min(L_{26})}{2}$ | 過去26日の値幅の中心（中期の均衡点） |
| 先行スパン1 | $\dfrac{\text{転換線} + \text{基準線}}{2}$ を **26日先**に描画 | 雲の一辺 |
| 先行スパン2 | $\dfrac{\max(H_{52}) + \min(L_{52})}{2}$ を **26日先**に描画 | 雲のもう一辺 |
| 遅行スパン | 当日終値を **26日前**に描画 | 現在値と過去の価格の比較 |

移動平均が「終値の平均」であるのに対し、転換線・基準線は「期間中の**高値と安値の中点**」であり、レンジの中心＝売買勢力の均衡点を表す。先行スパン1・2に挟まれた領域が**雲（抵抗帯）**で、価格が雲の上なら強気、雲の中は均衡、雲の下なら弱気と読む。雲の厚みは過去の値動きが将来に投影された支持・抵抗の厚みであり、雲のねじれ（スパン1と2の交差）は相場の転換点候補とされる。

代表的な強気シグナルは、(1) 転換線が基準線を上抜く、(2) 遅行スパンが26日前の価格を上抜く、(3) 価格が雲を上抜く——の3つが揃う**三役好転**（逆は三役逆転）である。また一目均衡表は 9・17・26 を「基本数値」とする独自の時間論（対等数値・変化日）を持ち、原著（『一目均衡表』全7巻など）ではむしろ時間論・波動論・値幅観測論が本体で、5線は入口にすぎないとされる。パラメータの 9・26 は週6日制（土曜半休）時代の約1.5週・1か月に由来するため、週5日制の現代（1989年の東証土曜立会全廃以降）にそのまま妥当かは議論があるが、実務では原典の数値のまま使うのが主流である。海外でも "Ichimoku Cloud" として広く実装されており、日本発のテクニカル理論として最も国際的に普及した例といえる。

## 数理的性質と限界の整理

- **ラグとノイズのトレードオフ**: 平滑化を強めるほどノイズは減るが遅れが増す。移動平均・MACD・一目の各線はすべてこの制約下にある。シグナルは常に「事後確認」である。
- **正規性の仮定の崩れ**: ボリンジャーバンドの $\sigma$ 解釈は正規分布・独立性を前提とするが、実際の収益率はファットテールでボラティリティが時変（クラスタリング）する。
- **有界オシレータの張り付き**: RSI・ストキャスティクスは値域が有界ゆえ、強トレンドでは飽和して逆張りシグナルを乱発する。相場環境（トレンド／レンジ）の判定が先決となる。
- **データマイニング・バイアス**: パラメータ（14日、(12,26,9) 等）は歴史的慣習であり、最適化しすぎればカーブフィッティングに陥る。効率的市場仮説の弱形が成り立つ限り、価格系列のみから恒常的な超過収益を得るのは理論上困難であり、テクニカル指標は「優位性の源泉」ではなく「状況認識と執行の規律を与える言語」と捉えるのが穏当である。
- **自己成就性**: 多数の参加者が同じ水準（25日線、雲の上限など）を意識することで短期的に機能する局面があるが、それは恒常的な法則ではない。
