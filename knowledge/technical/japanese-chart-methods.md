# 時間を捨てるチャート：練行足・カギ足・新値足・ポイント&フィギュア

時間軸ではなく値動きの大きさで足を刻むチャート手法——練行足（レンガ足／Renko）・カギ足・新値足（新値三本足）・ポイント&フィギュア（P&F）——の作図ルールを数式と擬似コードで整理する。
ノイズ除去とトレンド抽出の効果、パラメータ（値幅・転換基準）依存で見え方が一変すること、確定していない足が後から変わる**再描画（リペイント）によるルックアヘッドの危険**を扱う。
時間情報を失う代償（イベントとの対応付け・保有期間・年率換算が定義できない）も明示する。

## 1. 「時間を捨てる」という発想

通常の日足・分足は、経過時間が一定量に達するたびに新しい足を作る。これに対し本稿の手法群は、**価格が一定量動くたびに**新しい足を作る。刻みの基準を時間 $\Delta t$ から値幅 $\Delta P$ に置き換えるわけである。

この置換の狙いは明快で、値動きの乏しい時間（昼休み直後の膠着、閑散日）が場所を占有しなくなり、チャート上の「1目盛り」が常に同じ値幅の情報を持つようになる。統計的に言えば、時間サンプリングを**イベント（価格変動）サンプリング**に変えることで、リターン系列の分散の時間的不均一（ボラティリティ・クラスタリング）をある程度均す効果がある。ティックバー・ボリュームバー・ドルバーといった現代的な代替サンプリングと同じ系譜にある発想である。

練行足・カギ足・新値足は日本の相場実務で古くから使われてきた手法で、Steve Nison の *Beyond Candlesticks*（1994年）によって Renko / Kagi / Three-Line Break として欧米へ紹介された。ポイント&フィギュアは19世紀末の米国に起源を持ち、A.W. Cohen らによって1950年代前後に3枠転換法が標準化された、独立に発達した同系統の手法である。

## 2. 練行足（レンガ足／Renko）

レンガ幅 $b$ を決め、価格が直前のレンガから $b$ 以上動いたときだけレンガを1個追加する。参照価格は伝統的に終値 $C_t$ を使う。直近レンガの上端を $U$、下端を $D$（$U - D = b$）とすると、

$$
n_{\text{up}} = \left\lfloor \frac{C_t - U}{b} \right\rfloor,\qquad
n_{\text{down}} = \left\lfloor \frac{D - C_t}{b} \right\rfloor
$$

個の陽（陰）レンガをまとめて追加する。トレンド継続方向は $b$ 動けば1個、逆方向への転換には流派により $b$ または $2b$（直近レンガを跨ぐ必要があるため）を要求する。擬似コードは次の通り。

```
for t in days:
    while C[t] >= U + b:        # 上方向
        emit_brick(up, low=U, high=U+b); D = U; U = U + b
    while C[t] <= D - b:        # 下方向
        emit_brick(down, low=D-b, high=D); U = D; D = D - b
```

$b$ の決め方は「固定円（例: 100円）」「価格比（例: 1%）」「$\mathrm{ATR}_{14}$ 連動」の3系統がある。**ATR 連動は後述するリペイント問題を最も強く引き起こす**ため、検証用途では固定値を使うのが安全である。

## 3. カギ足

カギ足は縦線と短い横線をつなぐ折れ線で、転換値幅 $r$（固定円または直近終値比 $r = \rho \cdot C$、$\rho$ は例えば4%）を1つのパラメータとして持つ。

- 上昇中は、終値が更新されるたびに縦線を上へ伸ばす。
- 終値が直近の極値から $r$ 以上逆行したら、横線を1本引いてから反対方向へ縦線を引き始める。
- 線の太さ（陽転・陰転）は値幅ではなく**構造**で決まる。直前の「肩」（前回の高値の横線水準）を上抜けたら陽線（太線）、直前の「腰」（前回の安値水準）を下抜けたら陰線（細線）に切り替わる。

太細の切り替えが売買シグナルとして語られるが、切り替えは肩・腰の突破後にしか確定しない。すなわち**シグナルは常に事後的**であり、これは遅行性としてのコストである（線の太さが「今どちらか」を将来の値動きが決める、という誤読をしないこと）。

## 4. 新値足（新値三本足）

新値足は、直近 $N$ 本（標準は $N=3$。新値二本足・新値五本足もある）の反対方向の足を基準に転換を判定する。上昇局面において、

- **継続**: $C_t >$ 直近の陽足の高値 → 新しい陽足を追加。
- **転換**: $C_t <$ 直近 $N$ 本の陽足の**最安値** → 陰足へ転換。

$N$ が大きいほど転換に必要な逆行が大きくなり、ダマシは減るが遅れる。$N$ は「本数」であって値幅ではないため、**転換に要する値幅が局面ごとに変動する**点が練行足・P&F との構造的な違いである（トレンドが急なほど直近3本の値幅が広がり、転換閾値も自動的に広がる）。

## 5. ポイント&フィギュア（P&F）

枠値（box size）$b$ と転換枠数 $n$（標準は $n=3$、いわゆる3枠転換）の2パラメータで定義される。上昇列を $\times$、下降列を $\bigcirc$ で表す。

- 現在が $\times$ 列で列の最高枠が $M$ のとき、価格が $M + b$ 以上に達すれば同じ列に $\times$ を積む。
- 価格が $M - n\,b$ 以下に下落したら、右隣に新しい $\bigcirc$ 列を始める（1枠分ずらして描き始める）。
- 判定に日中の高値・安値を使う流儀と終値のみを使う流儀があり、結果は一致しない。

目標値の推計には**縦目標**（列の枠数 $L$ を用いて $\text{目標} = \text{起点} \pm L \cdot b \cdot n$）と**横目標**（保ち合いの列数から幅を投影）が伝統的に使われるが、いずれも測定移動（measured move）と同種のヒューリスティックであり、理論的裏付けはない。P&F の利点は、支持抵抗の水平線とトレンドの45度線が**格子の上で一意に引ける**こと——前掲文書で論じた作図の恣意性が、パラメータ $(b, n)$ の選択という1点に集約されることである。裏を返せば、恣意性が消えたのではなく移動しただけである。

## 6. パラメータ依存性——見え方は一変する

これら4手法に共通する最大の実務的注意は、**パラメータを変えるとチャートの形そのものが変わる**ことである。

| 手法 | 主パラメータ | 小さくすると | 大きくすると |
|---|---|---|---|
| 練行足 | レンガ幅 $b$ | 足数が増え、ノイズが残る | 足数が激減し、大きなトレンドのみ残る |
| カギ足 | 転換値幅 $r$ | 転換が頻発 | 転換が稀になり遅行 |
| 新値足 | 本数 $N$ | 早い転換・ダマシ増 | 遅い転換・大トレンドのみ |
| P&F | 枠値 $b$・転換枠数 $n$ | 列が増え細かい | 列が減り粗い |

練行足では、$b$ を2倍にすると足数はおおむね $1/2 \sim 1/4$ に減る（変動が独立なら価格が $b$ 動くまでの期待時間は $b^2$ に比例するため、足数は $b^{-2}$ のオーダーで減る）。**足数が減るほど、バックテストの標本数が減って統計的信頼性が落ちる**。「$b$ を調整したらきれいなトレンドが見えた」は、多くの場合パラメータ探索による過剰適合の入口である。$b$ を数十通り試して最良を選ぶ行為は多重比較そのものであり、`../math/backtesting-and-statistics.md` の議論がそのまま当てはまる。

## 7. 再描画（リペイント）とルックアヘッド——最重要の落とし穴

本リポジトリはバックテストのルックアヘッド混入を厳しく戒めている。時間を捨てるチャートは、この混入が**構造的に起きやすい**。危険は少なくとも3種類ある。

**(1) 未確定の足を確定したものとして扱う。** 練行足の「現在のレンガ」は、価格が $b$ 動くまで確定しない。ある足が「いつ確定したか」のタイムスタンプを持たずに `brick[i]` の並びだけで売買判定すると、実際には未来に起きた値動きで確定した足を、その足の始点時刻で使ってしまう。カギ足の太細、新値足の転換、P&F の列転換も同様に、条件を満たした瞬間まで確定しない。

**(2) 足の始値と終値で約定したと仮定する。** 練行足の各レンガは定義上ちょうど $b$ の値幅を持つ。したがって「レンガ始値で買い、レンガ終値で売る」というバックテストは、1本ごとに確実に $b$ の利益を生む——実市場では実現不可能な、恒等式が生む架空の利益である。資産曲線が不自然に滑らかで単調な右肩上がりになったら、まずこの混入を疑うべきである。約定価格は必ず**時間軸に戻した実際の市場価格**（例: 条件成立の翌営業日始値）に置き換える必要がある。

**(3) 全期間再計算によるパラメータのリペイント。** ATR 連動のレンガ幅のように、パラメータ自体を系列から推定する場合、後日データを追加してチャートを引き直すと**過去のレンガの配置まで変わる**。全期間の ATR で $b$ を決めるのは全標本情報の使用であり、明確なルックアヘッドである。使うなら、各時点で利用可能な情報のみからパラメータを決める（拡張窓／ローリング窓）実装が必須である。

安全な実装の原則は一つに集約される——**足の確定時刻を明示的に記録し、シグナルの発生時刻と約定時刻を時間軸上で分離すること**。実装イメージは次の通り。

```
bricks = build_renko(close, b)   # 各要素に confirmed_at（確定した実際の日付）を持たせる
for br in bricks:
    if signal(br):               # br.confirmed_at 以前の情報のみで判定
        fill_date = next_trading_day(br.confirmed_at)
        fill_price = open[fill_date]     # 実在の市場価格で約定
```

なお TradingView 等の一部プラットフォームでは、非標準チャート（練行足・カギ足・P&F 等）上でのストラテジー検証が非現実的な成績を出すことが知られており、公式ドキュメントやコミュニティ FAQ でも注意喚起されている。「バックテストの成績が良すぎる」ときは手法の優位性ではなく実装の欠陥を疑うのが健全である。

## 8. 時間情報を失う代償

ノイズ除去と引き換えに失うものも大きい。

- **イベントとの対応付けができない**: 1本の足が1日に対応しないため、「この転換は決算発表の翌日か、日銀会合の日か」を答えられない。イベントスタディ、権利落ち、需給イベントとの照合には時間軸への逆写像が必須になる。
- **保有期間・年率換算が定義できない**: 「10本保有」は暦日で何日か決まらない。年率リターン $\left(\prod (1+r_i)\right)^{252/n}$ のような換算は、$n$ が営業日数であることを前提にしており、足数に対して適用すると無意味な数字になる。シャープレシオやドローダウンの継続日数も同様に、時間軸へ戻してから計算する必要がある。
- **出来高が接続しにくい**: 1本の足が複数日にまたがったり、逆に1日で複数本生じたりするため、出来高の配分が一意に決まらない。
- **ボラティリティ推定が歪む**: 値幅で刻む以上、各足のリターンは設計上ほぼ一定であり、標準偏差はほとんど情報を持たない。リスク指標は必ず元の時間軸系列で計算する。
- **日本株の制度的歪みが吸収されない**: ストップ高・ストップ安による窓や連続ストップ後の飛びは、練行足では単に「レンガが一度に何個も積まれた」として表現され、その異常性が視覚的に消える（制度の詳細は `../market-structure/trading-mechanics.md`）。分割・併合の調整漏れがあると、1回の見かけの急落が大量のレンガを生む点にも注意が必要である。

## 9. 実務上の位置づけ

これらの手法にトレンドフォロー的な発想を可視化する道具としての価値はあるが、**予測力を実証した頑健な研究は乏しく、パラメータ依存性と再描画の問題が検証を難しくしている**。使うのであれば、(a) パラメータは事前に固定して探索しない、(b) 足の確定時刻を持ち、約定は必ず時間軸上の実在価格で行う、(c) 成績評価（年率・ドローダウン・シャープ）は元の日足系列に戻して計算する、という3点を最低限の規律とするのが妥当である。本稿は手法の整理であって、特定の売買手法を推奨するものではない。
