# 株価の時系列モデル

株価はランダムウォークに近い一方、リターンの分散（ボラティリティ）には強い時間構造がある——これが実証ファイナンスの基本認識である。本稿では単位根検定・ARIMA・GARCH族という標準的な時系列モデルの数理を整理し、日経平均株価への適用例と、実務で直面する限界をまとめる。

## 1. ランダムウォークと効率的市場仮説

株価 $P_t$ の対数を $p_t = \ln P_t$ とすると、最も基本的なモデルはドリフト付きランダムウォークである。

$$p_t = \mu + p_{t-1} + \varepsilon_t, \quad \varepsilon_t \sim \text{i.i.d.}(0, \sigma^2)$$

このとき対数リターン $r_t = p_t - p_{t-1} = \mu + \varepsilon_t$ は予測不可能となる。これはFama（1970年）の効率的市場仮説（EMH）の「ウィーク型」——過去の価格系列から超過収益は得られない——と整合する。直感的には、もし価格に予測可能なパターンがあれば裁定取引がそれを消費し尽くし、残るのは予測不能な部分だけになる、という論理である。

ただし厳密には「効率的市場 ⇒ ランダムウォーク」ではない。EMHが要求するのはリターンがマルチンゲール差分（$E[r_{t+1}|\mathcal{F}_t] = \mu$）であることまでで、分散の時間変動（後述のGARCH効果）は効率性と矛盾しない。

## 2. 単位根検定 — 水準は非定常、リターンは定常

時系列分析の出発点は定常性の確認である。AR(1)モデル $p_t = \phi p_{t-1} + \varepsilon_t$ において $\phi = 1$（単位根）なら非定常、$|\phi| < 1$ なら定常となる。標準的なADF（拡張ディッキー・フラー）検定は

$$\Delta p_t = \alpha + \beta t + \gamma p_{t-1} + \sum_{i=1}^{k} \delta_i \Delta p_{t-i} + \varepsilon_t$$

を推定し、帰無仮説 $H_0: \gamma = 0$（単位根あり）を検定する。$\gamma$ のt統計量は帰無の下で通常のt分布に従わず、ディッキー・フラー分布の臨界値（片側・左裾）を使う点が要注意である。

日経平均の日次データにADF検定をかけると、典型的には次の結果になる。

| 系列 | ADF検定の典型的結果 | 解釈 |
|---|---|---|
| 対数価格 $p_t$ | 棄却できない | 単位根あり＝非定常。I(1)過程 |
| 対数リターン $r_t$ | 強く棄却 | 定常。モデリングはこちらで行う |

つまり日経平均は「1回差分をとれば定常になる」I(1)過程として扱うのが標準である。補完的にKPSS検定（帰無仮説が「定常」）を併用し、両検定の結論が整合するか確認する作法が定着している。

## 3. ARIMA — 平均（一次モーメント）のモデル

定常化したリターンに対し、ARMA(p, q)モデル

$$r_t = c + \sum_{i=1}^{p} \phi_i r_{t-i} + \varepsilon_t + \sum_{j=1}^{q} \theta_j \varepsilon_{t-j}$$

を当てはめる（原系列で見ればARIMA(p,1,q)）。次数選択はAIC/BICで行い、残差がホワイトノイズか（Ljung-Box検定）を確認する。

しかし日経平均の日次リターンの自己相関はごく弱い。一次の自己相関係数は概ね $|\hat\rho_1| < 0.05$ 程度で、統計的に有意でも取引コスト（2024年時点の売買委託手数料はネット証券で実質ゼロに近いが、スプレッドと市場インパクトは残る）を考慮すると経済的に意味のある予測力にはなりにくい。ARIMAが有効なのはむしろ、出来高や裁定残、信用残といった「価格以外の」系列のモデリングである。

## 4. GARCH族 — 分散（二次モーメント）のモデル

リターン自体は予測困難でも、$r_t^2$ や $|r_t|$ には強い正の自己相関がある。「荒れた日の翌日は荒れやすい」というボラティリティ・クラスタリングである。Bollerslev（1986年）のGARCH(1,1)は条件付き分散 $\sigma_t^2$ を

$$r_t = \mu + \varepsilon_t, \quad \varepsilon_t = \sigma_t z_t, \quad \sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2$$

と定式化する（$z_t \sim \text{i.i.d.}(0,1)$）。$\alpha + \beta$ が持続性を表し、日経平均の日次データでは 0.95〜0.99 と1に近い値が推定されるのが通例である。これは「ボラティリティ・ショックの半減期が数週間〜数か月」に相当し、長期平均分散 $\bar\sigma^2 = \omega / (1 - \alpha - \beta)$ への回帰は非常に遅い。

株式市場では下落時にボラティリティがより大きく上昇する**レバレッジ効果**（非対称性）が顕著で、これを捉える拡張が使われる。

- **EGARCH**（Nelson, 1991年）: $\ln \sigma_t^2$ をモデル化し、正負のショックに非対称な反応を許す。
- **GJR-GARCH**（1993年）: $\sigma_t^2 = \omega + (\alpha + \gamma \mathbf{1}_{\{\varepsilon_{t-1}<0\}})\varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2$。日経平均では $\gamma > 0$ が明確に検出される。

また残差 $z_t$ は正規分布よりも裾が厚く、t分布を仮定した準最尤推定が実務標準である。GARCH予測は日経平均VI（ボラティリティ・インデックス、大阪取引所が2010年から算出）と比較検証でき、日経VIはリスク中立測度下のインプライド・ボラティリティなので、GARCHの実測度予測に対しリスクプレミアム分だけ高めに出る傾向が知られている。

## 5. 自己相関と平均回帰の検出

平均回帰（ミーンリバージョン）の検出には次の道具が使われる。

- **Ljung-Box統計量**: $Q = T(T+2)\sum_{k=1}^{m} \hat\rho_k^2/(T-k)$ で複数ラグの自己相関を一括検定。
- **分散比検定**（Lo-MacKinlay, 1988年）: ランダムウォークなら $k$ 期間リターンの分散は1期間の $k$ 倍。$VR(k) = \text{Var}(r_t^{(k)})/(k \cdot \text{Var}(r_t))$ が1未満なら平均回帰、1超ならモメンタムを示唆する。
- **ハースト指数**: $H = 0.5$ がランダムウォーク、$H < 0.5$ が平均回帰的。
- **ペア/バスケットの共和分検定**（Engle-Granger, Johansen）: 個別株価は非定常でも、その線形結合（スプレッド）が定常なら統計的裁定の候補になる。

日本市場固有の文脈では、短期の指数リターンに現れる微弱な自己相関が、裁定取引（先物と現物のベーシス取引）や、2010年代の日銀ETF買い（後場の下落時に買いが入るとされた需給要因、買入方針は2021年以降縮小）といった制度・需給要因で説明される部分がある点に留意したい。統計的パターンの背後にある経済メカニズムを特定しないまま外挿するのは危険である。

## 6. 日経平均への適用上の限界

1. **構造変化**: バブル崩壊（1990年前後）、リーマンショック（2008年）、東日本大震災（2011年）、アベノミクス開始（2012年末）など、レジームが変わるとパラメータは不安定になる。単一モデルの全期間推定はほぼ確実に誤特定であり、ローリング推定やレジームスイッチング（マルコフ転換モデル）が必要になる。
2. **裾の厚さとジャンプ**: 1987年10月のブラックマンデーでは日経平均が1日で約14.9%下落した。GARCH＋t分布でも極端事象は捉えきれず、極値理論（EVT）やジャンプ拡散の併用が検討される。
3. **日次データの制度要因**: 東証の取引時間（2024年11月から15:30まで延長、それ以前は15:00まで）の外で米国市場のニュースが織り込まれるため、日経平均の日次リターンにはオーバーナイト効果が強い。日中と夜間を分けた分析や、CME日経先物との併用が実務では一般的である。
4. **指数固有の癖**: 日経平均は株価平均型（除数修正方式）で、値がさ株の寄与が大きい。TOPIX（時価総額加重）とは統計的性質が微妙に異なり、モデルの結論を相互に外挿できない。
5. **予測力と実行可能性の乖離**: 統計的に有意なパターンでも、取引コスト・空売り規制・流動性を考慮すると収益化できないことが多い。インサンプルの当てはまりとアウトオブサンプルの予測力は別物であり、ルックアヘッド・バイアスを排した検証が不可欠である。

要するに、時系列モデルの実用上の主戦場は「リターンの方向予測」ではなく「ボラティリティ予測とリスク管理」（VaR算出、オプション評価、ポジションサイジング）にある。この役割分担を理解することが、モデルの過信を避ける第一歩である。
