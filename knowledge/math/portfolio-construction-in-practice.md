# 実務のポートフォリオ構築技術

平均分散最適化は理論的に美しいが、そのまま実務に使うと「推定誤差の最大化装置」になる。本稿では共分散行列のLedoit-Wolf縮小推定とBarra型ファクターリスクモデルによる次元削減、Black-Littermanモデルによる期待リターンの安定化、リスクパリティ等のリスクベース配分、回転率・業種中立などの制約付き最適化とリバランス設計を、TOPIXユニバースでの適用論点とともに整理する。

## 1. 共分散行列の推定問題

$n$ 銘柄の標本共分散行列 $S = \frac{1}{T}\sum_{t=1}^{T}(\mathbf{r}_t - \bar{\mathbf{r}})(\mathbf{r}_t - \bar{\mathbf{r}})^\top$ は推定すべきパラメータが $n(n+1)/2$ 個ある。TOPIX500なら約12.5万個で、日次5年（$T \approx 1250$）でも $T < n$ に近く、$T \le n$ では $S$ は特異（逆行列が存在しない）になる。仮に正則でも、最適化 $\mathbf{w}^* \propto \Sigma^{-1}\boldsymbol{\mu}$ は $S$ の**最小固有値方向**（＝最も推定が不安定な方向）に賭けを集中させる。これがMichaud（1989年）の言う「誤差最大化」である。

### Ledoit-Wolf縮小推定

Ledoit-Wolf（2004年）は、標本共分散を構造化されたターゲット $F$（例：全銘柄の相関を平均相関で置き換えた constant-correlation モデルや単位行列のスカラー倍）へ「縮小」する。

$$\hat{\Sigma} = \delta^* F + (1-\delta^*)\, S, \qquad 0 \le \delta^* \le 1$$

最適縮小強度 $\delta^*$ は期待二乗損失 $E\|\hat{\Sigma}-\Sigma\|_F^2$ を最小化するよう閉形式で求まり、直感的には「$S$ の推定誤差が大きい（$T$ が小さい・$n$ が大きい）ほど $F$ に強く寄せる」バイアス・バリアンストレードオフである。縮小後の $\hat{\Sigma}$ は常に正定値で、極端な相関推定値が中央に引き戻されるため最適化ウェイトが安定する。scikit-learn の `LedoitWolf` で1行で計算できる。

### ファクターリスクモデル（Barra型）

もう一つの次元削減はリターンの構造仮定である。銘柄リターンを $K$ 個（$K \ll n$）の共通ファクターで説明する。

$$\mathbf{r} = B\,\mathbf{f} + \boldsymbol{\varepsilon}, \qquad \Sigma = B\,\Sigma_f\,B^\top + D$$

ここで $B$ は $n \times K$ のファクターエクスポージャ行列、$\Sigma_f$ はファクター共分散（$K \times K$）、$D$ は固有リスクの対角行列。推定パラメータは $nK + K(K+1)/2 + n$ 個に激減する。Barra型（クロスセクショナル回帰型）では、各時点でスタイル指標（バリュー、モメンタム、サイズ、ベータ等）と業種ダミーを説明変数に横断回帰し、ファクターリターン $\mathbf{f}_t$ を推定する。日本株ではMSCI Barraの日本モデル（JPE系）が機関投資家の事実上の標準で、東証33業種分類（またはTOPIX-17）を業種ファクターに使う構成が一般的である。ファクターモデルの副産物として、ポートフォリオのリスクを「ファクター寄与＋固有寄与」に分解でき、業種中立化やスタイル管理が自然に行える。

## 2. Black-Littermanモデル

平均分散のもう一つの弱点は期待リターン $\boldsymbol{\mu}$ の推定で、最適解は $\boldsymbol{\mu}$ の微小変化に極めて敏感である。Black-Litterman（1992年）は**市場均衡を事前分布、投資家のビューを観測とするベイズ更新**でこれを解決する。

まず逆最適化により、市場時価総額ウェイト $\mathbf{w}_{mkt}$（日本株ならTOPIXの浮動株調整後ウェイト）を最適解とする均衡期待超過リターンを求める。

$$\boldsymbol{\pi} = \lambda\, \Sigma\, \mathbf{w}_{mkt}$$

（$\lambda$ はリスク回避度で、市場のシャープレシオから較正する。）投資家のビューは $P\boldsymbol{\mu} = \mathbf{q} + \boldsymbol{\eta}$, $\boldsymbol{\eta} \sim N(\mathbf{0}, \Omega)$ の形で表現する。$P$ の各行が1つのビュー（例：「トヨタは電機セクター平均を年率2%上回る」なら該当銘柄に $+1$、電機各社に時価ウェイトで $-1$）。事前 $\boldsymbol{\mu} \sim N(\boldsymbol{\pi}, \tau\Sigma)$ とのベイズ結合により事後平均は

$$\boldsymbol{\mu}_{BL} = \left[(\tau\Sigma)^{-1} + P^\top \Omega^{-1} P\right]^{-1}\left[(\tau\Sigma)^{-1}\boldsymbol{\pi} + P^\top \Omega^{-1}\mathbf{q}\right]$$

となる。これは均衡リターンとビューの**確信度加重平均**であり、ビューを持たない銘柄のウェイトは市場ウェイトから乖離しない。「何も意見がなければ市場ポートフォリオ」という保守的な既定値を持つ点が実務上の最大の利点である。$\tau$ は0.01〜0.05程度の小さい値、$\Omega$ は $\mathrm{diag}(P\tau\Sigma P^\top)$ を確信度でスケールする実装（Idzorek 2005年の方法）が広く使われる。

## 3. リスクベース配分

期待リターン推定を放棄し、リスク情報のみで配分する手法群。推定誤差に頑健で、検証でも意外に強い。

| 手法 | 定義 | 特徴 |
|---|---|---|
| 等ウェイト（1/N） | $w_i = 1/n$ | 推定不要。DeMiguel他（2009年）が多くの最適化手法に勝ると報告。小型株・流動性リスクに偏る |
| 最小分散 | $\min \mathbf{w}^\top\Sigma\mathbf{w}$ | $\boldsymbol{\mu}$ 不要。低ボラティリティ・アノマリーを暗黙に捕捉。低ベータ銘柄（日本では食品・医薬・鉄道等）に集中しやすく銘柄数上限が必須 |
| リスクパリティ | 各銘柄のリスク寄与 $w_i(\Sigma\mathbf{w})_i / \sigma_p$ を均等化 | 1/Nと最小分散の中間。凸最適化 $\min \mathbf{w}^\top\Sigma\mathbf{w} - c\sum_i \ln w_i$ の解として得られる |
| 最大分散化 | 分散化比率 $\frac{\mathbf{w}^\top\boldsymbol{\sigma}}{\sqrt{\mathbf{w}^\top\Sigma\mathbf{w}}}$ を最大化 | 相関の低い銘柄群を選好 |

リスク寄与の均等化がリスクパリティの本質で、$\sigma_p = \sum_i w_i \frac{\partial \sigma_p}{\partial w_i}$（オイラーの定理）という分解に基づく。日本ではスマートベータの文脈で、GPIFが2010年代以降パッシブ運用の多様化として最小分散型・リスク効率型指数を採用した経緯がある（〜2025年時点）。

## 4. 制約付き最適化とリバランス設計

実務の最適化は制約の設計がすべてと言ってよい。典型形は

$$\max_{\mathbf{w}} \ \boldsymbol{\alpha}^\top\mathbf{w} - \lambda\,\mathbf{w}^\top\Sigma\,\mathbf{w} - c\,\|\mathbf{w}-\mathbf{w}_{old}\|_1$$

- **回転率制約／取引コスト項**：$\|\mathbf{w}-\mathbf{w}_{old}\|_1 \le \theta$ または上式のL1ペナルティ。日本の売買コストは委託手数料よりマーケットインパクトが支配的で、小型株では往復1%を超えることも珍しくない。コスト項の $c$ を現実的に置くだけでリバランスは自然に抑制される。
- **業種中立制約**：$|\,\mathbf{w}^\top \mathbf{d}_s - \mathbf{w}_{bench}^\top \mathbf{d}_s\,| \le \epsilon_s$（$\mathbf{d}_s$ は業種 $s$ のダミー）。東証33業種またはTOPIX-17でベンチマーク比±1〜2%に抑えるのが典型。銀行・自動車など指数ウェイトの大きい業種の偶発的ベットを防ぐ。
- **銘柄数・ウェイト上限**：個別上限 $w_i \le 3\%$ 等は線形制約で容易だが、銘柄数上限（カーディナリティ制約）は混合整数計画になり非凸。実務ではウェイト下限で足切りする近似が多い。
- **流動性制約**：保有額を「平均日次売買代金の $k$ 日分以内」に制限する。東証グロース・スタンダードの小型株や、プライムでも売買代金下位の銘柄は日次リターンに非同期取引由来の見せかけの低相関（Scholes-Williams的なバイアス）が生じ、共分散を過小推定して最適化が過大配分しがちなので、週次リターンでの推定やNewey-West型調整を併用する。

**リバランス頻度**は「推定情報の鮮度」と「取引コスト」のトレードオフである。カレンダー方式（月次・四半期）より、乖離が閾値を超えたときだけ戻すノーコリドー／バンド方式（例：目標±20%相対乖離）の方がコスト効率が良いという実証が多い。月次リバランスなら権利落ち日や配当・優待に絡む3月末・9月末の需給、TOPIX浮動株比率見直し（東証は2022年以降段階的にウェイト基準を改定、〜2025年時点）などのイベント日を避ける設計も行われる。

**実装ツール**：凸最適化は `cvxpy`（ソルバーはOSQP/ECOS/Clarabel）、縮小推定は `scikit-learn`、統合的には `PyPortfolioOpt` や `Riskfolio-Lib` がBlack-Litterman・リスクパリティ・階層的リスクパリティ（HRP）まで揃う。日本株データではJ-Quants API等から調整後株価を取得し、株式分割・併合の調整と上場廃止銘柄を含む生存バイアス処理を済ませてから推定に入るのが前提となる。
