# 確率過程と伊藤計算の基礎

オプション価格理論やボラティリティモデルの数学的土台である連続時間確率過程を自己完結的に解説する。ブラウン運動から伊藤の補題、確率微分方程式（SDE）、ギルサノフの定理によるリスク中立測度への変換、ジャンプ拡散までを、日経225オプションなど日本市場での応用文脈とともに整理する。数値シミュレーション（オイラー・丸山法）のPythonコードも収録する。

## 1. ブラウン運動（ウィーナー過程）

標準ブラウン運動 $W_t$ は次の性質で特徴づけられる確率過程である。

| 性質 | 内容 |
|---|---|
| 初期値 | $W_0 = 0$ |
| 独立増分 | $W_t - W_s$（$s<t$）は過去 $\mathcal{F}_s$ と独立 |
| 正規増分 | $W_t - W_s \sim N(0,\, t-s)$ |
| 連続性 | 見本経路は連続だが、至るところ微分不可能 |

株式収益率のモデルにブラウン運動を使う直感は「微小時間の値動きは無数の独立な売買注文の集積であり、中心極限定理により正規分布に近づく」というものである。決定的に重要なのは**2次変分**の性質

$$\langle W \rangle_t = \lim_{\|\Pi\|\to 0} \sum_i (W_{t_{i+1}} - W_{t_i})^2 = t$$

であり、記号的に $(dW_t)^2 = dt$、$dW_t\, dt = 0$、$(dt)^2 = 0$ と書かれる。通常の関数なら2次変分はゼロだが、ブラウン運動は経路が激しく振動するためゼロにならない。これが伊藤計算と通常の微積分の分岐点である。

## 2. 確率積分と伊藤の補題

$\int_0^t \sigma_s\, dW_s$ という積分は、被積分関数を**区間の左端**で評価するリーマン和の極限（伊藤積分）として定義される。左端評価は「保有株数はその時点までの情報で決める（先読みしない）」という取引の非先読み性に対応し、その結果、伊藤積分はマルチンゲール（期待値が現在値に留まる過程）になる。

**伊藤の補題**：$X_t$ が $dX_t = \mu_t\, dt + \sigma_t\, dW_t$ に従うとき、滑らかな関数 $f(t,x)$ に対して

$$df(t, X_t) = \left( \frac{\partial f}{\partial t} + \mu_t \frac{\partial f}{\partial x} + \frac{1}{2}\sigma_t^2 \frac{\partial^2 f}{\partial x^2} \right) dt + \sigma_t \frac{\partial f}{\partial x}\, dW_t$$

テイラー展開の2次項 $\frac{1}{2}f_{xx}(dX_t)^2$ が $(dW_t)^2 = dt$ により生き残る点が本質である。この補正項 $\frac{1}{2}\sigma^2 f_{xx}$ こそがオプションのガンマ（凸性）の収益源泉を数学的に表現しており、ブラック–ショールズ偏微分方程式の $\frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2}$ 項の由来である。なお伊藤清（1915–2008年）が第二次大戦中の日本で確率積分の理論を構築した歴史的経緯から、この分野は「伊藤解析」と呼ばれ、2006年に第1回ガウス賞を受賞している。

## 3. 代表的な確率微分方程式

### 幾何ブラウン運動（GBM）

株価 $S_t$ の標準モデル。

$$dS_t = \mu S_t\, dt + \sigma S_t\, dW_t$$

$f(x) = \ln x$ に伊藤の補題を適用すると $d\ln S_t = (\mu - \tfrac{1}{2}\sigma^2)dt + \sigma\, dW_t$ となり、解は

$$S_t = S_0 \exp\left( (\mu - \tfrac{1}{2}\sigma^2)t + \sigma W_t \right)$$

対数収益率のドリフトが $\mu$ ではなく $\mu - \frac{1}{2}\sigma^2$ になる点（ボラティリティ・ドラッグ）に注意。株価は対数正規分布に従い、負にならない。日経225オプション（大阪取引所上場）の理論価格算出の出発点はこのモデルである。

### オルンシュタイン–ウーレンベック（OU）過程

$$dX_t = \kappa(\theta - X_t)\, dt + \sigma\, dW_t$$

長期水準 $\theta$ への**平均回帰**を持つ。金利（Vasicekモデル）、ボラティリティの対数、ペアトレーディングにおけるスプレッド（例：トヨタとホンダの価格比の対数）のモデル化に使われる。定常分布は $N(\theta, \sigma^2/2\kappa)$。日経VI（日経平均ボラティリティー・インデックス）のような指標が急騰後に長期水準へ戻る挙動は、平均回帰過程の典型例として引用される。

## 4. マルチンゲールとリスク中立測度（ギルサノフの定理）

オプション価格理論の核心は「現実の確率測度 $\mathbb{P}$ での期待収益率 $\mu$ は価格式に現れない」ことである。**ギルサノフの定理**により、

$$\tilde{W}_t = W_t + \int_0^t \lambda_s\, ds, \quad \lambda_t = \frac{\mu - r}{\sigma}\ (\text{市場価格リスク})$$

が新しい測度 $\mathbb{Q}$（リスク中立測度）の下でブラウン運動になるよう、ラドン–ニコディム微分

$$\frac{d\mathbb{Q}}{d\mathbb{P}}\Big|_{\mathcal{F}_T} = \exp\left( -\int_0^T \lambda_s\, dW_s - \frac{1}{2}\int_0^T \lambda_s^2\, ds \right)$$

で測度変換できる。$\mathbb{Q}$ の下では $dS_t = r S_t\, dt + \sigma S_t\, d\tilde{W}_t$ となり、割引株価 $e^{-rt}S_t$ はマルチンゲールになる。デリバティブ価格は

$$V_0 = e^{-rT}\, \mathbb{E}^{\mathbb{Q}}[\text{ペイオフ}]$$

と表される（リスク中立評価）。ここで $r$ は無リスク金利であり、日本では長らくゼロ近傍〜マイナス（2016〜2024年のマイナス金利政策）だったため、$e^{-rT}$ の割引効果がほぼ無視できるという実務上の特殊事情があった（2024年3月のマイナス金利解除以降は正の金利で割り引く）。

## 5. ジャンプ拡散過程

連続経路のGBMでは、決算発表・ストップ高安・海外市場ショックのような**不連続な価格変動**を表現できない。マートンのジャンプ拡散モデル（1976年）は

$$\frac{dS_t}{S_{t-}} = \mu\, dt + \sigma\, dW_t + (e^{J} - 1)\, dN_t$$

とする。$N_t$ は強度 $\lambda$ のポアソン過程（単位時間あたり平均 $\lambda$ 回ジャンプ）、$J$ はジャンプサイズの対数で例えば $N(\mu_J, \sigma_J^2)$。ジャンプの存在は、日経225オプション市場で観測される急峻なボラティリティ・スマイル（特に短期限・アウトオブザマネーのプット）の説明要因となる。東証には値幅制限（ストップ高・ストップ安）や特別気配の制度があるため、日本株の日次リターンでは「翌日に持ち越されるギャップ」としてジャンプが現れやすい点も実証上の特徴である。

## 6. 数値シミュレーション：オイラー・丸山法

SDE $dX_t = a(X_t)dt + b(X_t)dW_t$ を時間刻み $\Delta t$ で離散化する最も基本的な方法。

$$X_{t+\Delta t} = X_t + a(X_t)\Delta t + b(X_t)\sqrt{\Delta t}\, Z, \quad Z \sim N(0,1)$$

丸山儀四郎（1954年に収束性を証明した日本の数学者）の名を冠する。強収束次数は0.5で、精度を上げたい場合はミルシュタイン法（次数1.0）を使う。

```python
import numpy as np

rng = np.random.default_rng(42)

def euler_maruyama_gbm(S0, mu, sigma, T, n_steps, n_paths):
    """幾何ブラウン運動のオイラー・丸山シミュレーション"""
    dt = T / n_steps
    S = np.full(n_paths, S0, dtype=float)
    for _ in range(n_steps):
        Z = rng.standard_normal(n_paths)
        S += mu * S * dt + sigma * S * np.sqrt(dt) * Z
    return S

def euler_maruyama_ou(X0, kappa, theta, sigma, T, n_steps, n_paths):
    """OU過程（平均回帰）のシミュレーション"""
    dt = T / n_steps
    X = np.full(n_paths, X0, dtype=float)
    for _ in range(n_steps):
        Z = rng.standard_normal(n_paths)
        X += kappa * (theta - X) * dt + sigma * np.sqrt(dt) * Z
    return X

# 例：日経平均 39,000円、年率ボラ20%、リスク中立ドリフトr=0.5%で1年後をモンテカルロ
S_T = euler_maruyama_gbm(S0=39000, mu=0.005, sigma=0.20,
                         T=1.0, n_steps=252, n_paths=100_000)
K = 40000  # 権利行使価格
call_price = np.exp(-0.005 * 1.0) * np.maximum(S_T - K, 0).mean()
print(f"コール理論価格の推定: {call_price:,.0f} 円")
```

GBMは厳密解を持つため、実務では対数を離散化した厳密スキーム $S_{t+\Delta t} = S_t \exp((\mu - \tfrac{1}{2}\sigma^2)\Delta t + \sigma\sqrt{\Delta t}Z)$ の方が離散化誤差なしで望ましい。オイラー・丸山法が真価を発揮するのは、Hestonモデルのような厳密解のないSDE系である。日本株のシミュレーションでは、営業日ベース（年間約245日、2025年時点の東証営業日数目安）で $\Delta t = 1/245$ とするか、暦年ベース $1/365$ とするかで年率換算が変わる点に注意する。
