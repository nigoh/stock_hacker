# マーケットマイクロストラクチャー理論と高頻度データ分析

株価は「情報」だけでなく「取引の仕組み」によっても動く——ビッド・アスク・スプレッド、板の厚み、注文の到着過程が価格形成を規定するという視点がマーケットマイクロストラクチャー理論である。本稿では価格形成の古典モデル（Kyle、Glosten-Milgrom、Roll）と、高頻度データの計量手法（実現ボラティリティ、マイクロストラクチャーノイズ、日中季節性、オーダーフローインバランス）を整理し、東証FLEXフル等の板データ分析の実際をまとめる。執行アルゴリズムや取引コストの実務は別稿に譲る。

## 1. なぜスプレッドが存在するのか — 情報の非対称性

マイクロストラクチャー理論の中心的な問いは「なぜ売値と買値が乖離するのか」である。答えは大きく3つ——(1) 在庫コスト（マーケットメイカーがポジションを抱えるリスク）、(2) 注文処理コスト、(3) **逆選択コスト**（情報を持つ相手と取引してしまう損失）——に分解される。理論的に最も豊かなのが逆選択の分析である。

### 1.1 Kyleモデル（1985年）

Kyleの連続オークションモデルは、情報トレーダーが私的情報をどう価格に織り込ませるかを描く。資産の真の価値を $v \sim N(p_0, \Sigma_0)$、情報トレーダー（インサイダー）の注文量を $x$、ノイズトレーダーの注文量を $u \sim N(0, \sigma_u^2)$ とする。マーケットメイカーは合計注文フロー $y = x + u$ のみを観測し、競争的（期待利潤ゼロ）に価格を付ける。

$$p = E[v \mid y] = p_0 + \lambda y$$

線形均衡では、インサイダーの最適戦略は $x = \beta (v - p_0)$ となり、価格インパクト係数は

$$\lambda = \frac{1}{2} \frac{\sqrt{\Sigma_0}}{\sigma_u}$$

**Kyleのラムダ** $\lambda$ は市場の「深さ（depth）」の逆数であり、私的情報が大きい（$\Sigma_0$ 大）ほど、またノイズ取引が薄い（$\sigma_u$ 小）ほど、1単位の注文が価格を大きく動かす。直感的には、マーケットメイカーは注文フローから情報を推測するため、情報が濃い市場ほど注文に敏感に価格を動かさざるを得ない。インサイダーは私的情報のちょうど半分だけを価格に織り込ませるように取引量を抑制する（情報の戦略的な小出し）。$\lambda$ は流動性の実証指標として、リターンを出来高（符号付き）に回帰する形で日本株でも推定される。

### 1.2 Glosten-Milgromモデル（1985年）

Glosten-Milgromは逐次取引モデルで、スプレッドそのものが逆選択から生まれることを示した。到着するトレーダーが確率 $\mu$ で情報トレーダー、$1-\mu$ でノイズトレーダーだとすると、マーケットメイカーのアスク価格は「買い注文が来た」という条件付き期待値

$$a = E[v \mid \text{買い注文}]$$

ビッドは $b = E[v \mid \text{売り注文}]$ となり、$a - b > 0$ のスプレッドが情報の非対称性のみから発生する。買い注文はベイズ更新により「価値が高い」というシグナルになるからだ。取引が進むにつれ価格は真の価値に収束する（価格発見）。このモデルは「約定の符号系列から情報を抽出できる」という後述のオーダーフロー分析の理論的基礎でもある。派生としてEasley-O'Hara系のPIN（Probability of Informed Trading、1996年）があり、注文到着の不均衡から情報取引確率を推定する。

### 1.3 Rollのスプレッド推定（1984年）

取引価格しか観測できない場合でも、スプレッドは推定できる。真の価値 $m_t$ がランダムウォークに従い、観測価格が $p_t = m_t + \frac{s}{2} q_t$（$q_t = \pm 1$ は売買方向、実効スプレッド $s$）だとすると、価格変化の1次自己共分散は

$$\text{Cov}(\Delta p_t, \Delta p_{t-1}) = -\frac{s^2}{4}
\quad \Rightarrow \quad
s = 2\sqrt{-\text{Cov}(\Delta p_t, \Delta p_{t-1})}$$

直感は**ビッド・アスク・バウンス**——約定がビッドとアスクの間を往復するため、真の価値が動かなくても価格変化に負の自己相関が生じる——である。共分散が正になる場合（推定不能）も実データでは頻発する点に注意。日本株では日次データからの流動性推計や、ティックデータが手に入らない過去期間の分析に使われる。

### 1.4 スプレッドの分解

実効スプレッドは実現スプレッドと価格インパクトに分解できる。約定価格 $p_t$、約定時仲値 $m_t$、約定から一定時間後（例：5分後）の仲値 $m_{t+\Delta}$ とすると

$$\underbrace{2 q_t (p_t - m_t)}_{\text{実効スプレッド}} = \underbrace{2 q_t (p_t - m_{t+\Delta})}_{\text{実現スプレッド}} + \underbrace{2 q_t (m_{t+\Delta} - m_t)}_{\text{価格インパクト（逆選択成分）}}$$

価格インパクトが大きいほど、流動性供給者は情報トレーダーに「抜かれて」おり、実現スプレッド（流動性供給の粗利益）は小さくなる。Glosten-Harris（1988年）やHuang-Stoll（1997年）の回帰モデルでも同様の分解が行われる。東証がティックサイズ（呼値単位）を段階的に縮小した際（TOPIX100銘柄、2014年）の効果検証にもこの枠組みが用いられた。

## 2. 高頻度データの計量手法

### 2.1 実現ボラティリティとマイクロストラクチャーノイズ

日中リターン $r_{t,i}$（例：5分刻み）の2乗和

$$RV_t = \sum_{i=1}^{n} r_{t,i}^2$$

を**実現ボラティリティ（RV）**と呼び、サンプリング間隔を細かくすると積分ボラティリティ $\int_0^1 \sigma^2(s)\,ds$ の一致推定量になる（Andersen-Bollerslev以降の理論、2000年前後）。ところが実際に間隔を1秒、1ティックと細かくするとRVは発散気味に増大する。観測価格 $p_t = p_t^* + \varepsilon_t$ にマイクロストラクチャーノイズ $\varepsilon_t$（ビッド・アスク・バウンス、離散呼値など）が乗っているためで、$E[RV] \approx \int \sigma^2 + 2n E[\varepsilon^2]$ とノイズ項が $n$ に比例して膨らむ。

対処法は主に3つ。

| 手法 | 考え方 |
|---|---|
| スパースサンプリング | 5分足程度に間引く（実務の定番。シグネチャプロットでノイズが効かない間隔を選ぶ） |
| 前置平均（pre-averaging）・二段階推定（TSRV） | 複数スケールのRVを組み合わせてノイズ分散を打ち消す |
| 実現カーネル（realized kernel） | 自己共分散に重みを付けて加算しノイズにロバスト化 |

東証の現物株は前場（9:00–11:30）と後場（12:30–15:00、2024年11月の取引時間延長後は15:30まで）に分かれるため、昼休みをまたぐリターンの扱い（除外するか、別成分として扱うか）と、寄付・引けの板寄せ（コール・オークション）区間をザラバ（連続取引）と区別する処理が日本固有の実務上の論点になる。ジャンプ成分を分離するBipower Variation（$BV_t = \frac{\pi}{2}\sum |r_{t,i}||r_{t,i-1}|$）との差分でジャンプ検出を行う手法も標準的である。

### 2.2 日中の U 字型季節性

出来高・ボラティリティ・スプレッドはいずれも日中で強い決定論的パターンを持つ。典型は**U字型**——寄付直後に最大（オーバーナイトの情報消化）、昼にかけて減衰、引けにかけて再上昇（インデックス連動資金のクロージング需要、MOC的な執行）——である。東証は昼休みがあるため、正確には「前場のU字＋後場のU字」を接いだ**W字型**に近く、後場寄り（12:30）にも小さなピークが立つ。引け直前の出来高集中は、TOPIX連動パッシブ資金がクロージング・オークションで執行される構造要因が大きい。日中パターンを除去（デシーズナライズ）しないと、ボラティリティ予測モデルや異常検知は時刻効果を「シグナル」と誤認するため、時刻 $\tau$ ごとの平均的な分散比率 $\phi(\tau)$ で正規化する前処理が必須となる。

### 2.3 オーダーフローインバランスと短期リターン予測

高頻度の世界で最も頑健な実証事実の一つが、**オーダーフローインバランス（OFI）と同時点・短期先リターンの正の関係**である。約定ベースでは、期間内の買い成行と売り成行の差

$$OFI_t = \sum_{i \in t} q_i \, v_i \qquad (q_i = \pm 1,\ v_i\text{は数量})$$

板ベースでは、最良気配の数量変化（ビッド増・アスク減を正とする）を集計するCont-Kukanov-Stoikov（2014年）流の定義がある。線形回帰 $r_t = \alpha + \beta \, OFI_t + \epsilon_t$ の $\beta$ は理論上Kyleのラムダに対応し、実証的には価格インパクトは注文量の平方根に近い凹関数（スクエアルート則）になることが知られる。予測可能性は数秒〜数分の地平線に限られ、スプレッドを超える収益化は困難——つまり「統計的に有意だが経済的にはHFTの速度がないと獲れない」——という点が重要である。約定方向の推定にはLee-Ready法（仲値との比較＋ティックルール）が古典だが、板データがあれば直接判定できる。

## 3. 東証の板データ — FLEX フルと板情報分析

東証は相場情報をFLEX（Flexible Exchange Information System）系のフィードで配信しており、概ね次の階層がある（2025年時点）。

| フィード | 内容 |
|---|---|
| FLEX スタンダード | 上下8本程度の気配値段・数量、約定情報 |
| FLEX フル | **全気配（フルデプス）**の価格・数量と更新情報、寄前気配、板寄せ情報 |
| FLEX ヒストリカル | 過去データの提供（JPXデータクラウド経由等で研究・検証用に入手可能） |

FLEXフルは「価格レベルごとの集計板」であり、米国のITCH系のような注文単位（order-by-order）のフィードではない点が特徴である。すなわち個々の注文IDは追跡できず、各価格の合計数量の増減として板を再構成する。また東証固有の要素として、寄付前の**寄前気配（更新値段・マッチング状況）**、特別気配・連続約定気配（急変時に気配を段階的に切り上げる制度）、板寄せによる寄り・引けの約定が板データ上に現れるため、ザラバのみを対象とする分析ではこれらの区間の識別が前処理の要になる。arrowhead（2010年稼働、以降数次にわたり更新）の高速化により、注文イベントはミリ秒〜マイクロ秒粒度で発生し、1銘柄・1日で数十万〜数百万イベントに達することも珍しくない。

板から作る代表的な特徴量は次の通り。

- **板の厚み（デプス）**: 最良気配または上位 $k$ 本の数量合計。約定を伴わない「見せ玉」的な変動も含むため、更新の持続時間で重み付けする工夫がある。
- **板のインバランス**: $I = \dfrac{Q^{bid} - Q^{ask}}{Q^{bid} + Q^{ask}}$。$I > 0$（買い板が厚い）は直後の上昇と正の相関を持つ、というのが内外の実証で共通する発見である。
- **気配の傾き（スロープ）**: 価格を最良気配からの距離、数量を累積デプスとして回帰した傾き。板が「深く緩やか」なら流動性が高く、価格インパクトが小さい。Kyleのラムダの板版の推定量と解釈できる。
- **マイクロプライス**: $p^{micro} = \dfrac{Q^{ask} p^{bid} + Q^{bid} p^{ask}}{Q^{bid} + Q^{ask}}$。数量で重み付けした仲値で、単純仲値より短期の価格予測力が高い。

分析上の注意として、板の上位以外のデプスは「その価格まで届けば約定できる量」を保証しない（取消が速い）こと、呼値単位の違い（TOPIX100銘柄は細かい刻み）が板の形状を機械的に変えること、そして観測されるOFIとリターンの関係は因果ではなく均衡の同時決定である（板が薄いから動くのか、動くから板が引くのか）ことが挙げられる。バックテストでこれらを無視すると、実際には獲れない「板の裏の流動性」を前提にした過大な成績が出やすい。
