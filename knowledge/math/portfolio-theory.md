# ポートフォリオ理論とCAPM

Markowitz（1952年）の平均分散最適化は「分散投資でリスクを減らす」という直感を数理化し、その均衡帰結としてCAPMが導かれた。本稿では効率的フロンティアの導出、シャープレシオ、ベータの意味を整理し、日本株実務におけるTOPIXベータの推定作法と、平均分散法の最大の弱点である推定誤差問題・ショートセル制約の扱いをまとめる。

## 1. 平均分散最適化の数理

$n$ 銘柄の期待リターンベクトルを $\boldsymbol{\mu} \in \mathbb{R}^n$、分散共分散行列を $\Sigma$（正定値）、ウェイトを $\mathbf{w}$ とする。ポートフォリオの期待リターンと分散は

$$\mu_p = \mathbf{w}^\top \boldsymbol{\mu}, \qquad \sigma_p^2 = \mathbf{w}^\top \Sigma \mathbf{w}$$

である。分散の式を展開すると $\sigma_p^2 = \sum_i \sum_j w_i w_j \sigma_{ij}$ となり、$n$ が大きいとき項数 $n^2$ のうち $n$ 個の分散項に対して $n(n-1)$ 個の**共分散項**が支配的になる。分散投資の効果は個別リスクではなく銘柄間の相関構造で決まる——これがMarkowitzの核心的洞察である。

目標リターン $\bar{\mu}$ を達成する最小分散ポートフォリオは、次の制約付き最小化問題の解である。

$$\min_{\mathbf{w}} \ \tfrac{1}{2}\mathbf{w}^\top \Sigma \mathbf{w} \quad \text{s.t.} \quad \mathbf{w}^\top \boldsymbol{\mu} = \bar{\mu}, \quad \mathbf{w}^\top \mathbf{1} = 1$$

ラグランジュ関数 $L = \tfrac{1}{2}\mathbf{w}^\top \Sigma \mathbf{w} - \lambda(\mathbf{w}^\top \boldsymbol{\mu} - \bar{\mu}) - \gamma(\mathbf{w}^\top \mathbf{1} - 1)$ の一階条件 $\partial L / \partial \mathbf{w} = \Sigma \mathbf{w} - \lambda \boldsymbol{\mu} - \gamma \mathbf{1} = \mathbf{0}$ より

$$\mathbf{w}^* = \Sigma^{-1}(\lambda \boldsymbol{\mu} + \gamma \mathbf{1})$$

を得る。スカラー $A = \mathbf{1}^\top \Sigma^{-1} \boldsymbol{\mu}$, $B = \boldsymbol{\mu}^\top \Sigma^{-1} \boldsymbol{\mu}$, $C = \mathbf{1}^\top \Sigma^{-1} \mathbf{1}$, $D = BC - A^2 > 0$ とおくと、2つの制約から $\lambda = (C\bar{\mu} - A)/D$, $\gamma = (B - A\bar{\mu})/D$ が定まり、最小分散は

$$\sigma_p^2(\bar{\mu}) = \frac{C\bar{\mu}^2 - 2A\bar{\mu} + B}{D}$$

という $\bar{\mu}$ の2次関数になる。すなわち $(\sigma_p, \mu_p)$ 平面で**双曲線**を描き、その上半分（大域的最小分散点 $\mu_{gmv} = A/C$ より上）が**効率的フロンティア**である。同じリスクならより高い期待リターン、同じリターンならより低いリスクの組合せは存在しない、という意味で「効率的」と呼ぶ。

## 2. 無リスク資産・接点ポートフォリオ・シャープレシオ

無リスク利子率 $r_f$ で貸借できる資産を加えると、投資機会集合は $(\sigma, \mu)$ 平面上で点 $(0, r_f)$ から効率的フロンティアに引いた**接線（資本市場線, CML）**に拡大する。接点ポートフォリオは

$$\mathbf{w}_{tan} \propto \Sigma^{-1}(\boldsymbol{\mu} - r_f \mathbf{1})$$

で与えられ、これは**シャープレシオ**

$$SR = \frac{\mu_p - r_f}{\sigma_p}$$

を最大化するポートフォリオに一致する。シャープレシオはリスク1単位あたりの超過リターンであり、年率化は日次なら $\sqrt{250}$ 倍（分子は250倍、分母は $\sqrt{250}$ 倍）が慣行である。日本では長らく $r_f \approx 0$（ゼロ金利・マイナス金利）が続いたため超過リターンと生リターンの差が小さかったが、日銀のマイナス金利解除（2024年3月）以降は短期金利が正に転じており、$r_f$ の取り方（無担保コール翌日物、短期国債利回りなど）を明示する必要がある（2025年時点）。

全投資家が同じ $\boldsymbol{\mu}, \Sigma$ を見るなら、誰もが「接点ポートフォリオ＋無リスク資産」の組合せだけを保有する（**トービンの分離定理**）。市場が清算されるためには接点ポートフォリオ＝時価総額加重の市場ポートフォリオでなければならない——これがCAPMへの橋渡しである。

## 3. CAPMとベータ

Sharpe（1964年）らのCAPM（資本資産価格モデル）は、均衡において個別資産 $i$ の期待超過リターンが

$$E[R_i] - r_f = \beta_i \left( E[R_m] - r_f \right), \qquad \beta_i = \frac{\mathrm{Cov}(R_i, R_m)}{\mathrm{Var}(R_m)}$$

と市場ベータに比例することを主張する。直感は次のとおり。個別リスクのうち分散投資で消せる部分（固有リスク）に対価は支払われず、消せない部分——市場ポートフォリオとの共分散——だけがリスクプレミアムを生む。ベータは「市場が1%動いたとき当該銘柄が平均何%動くか」の感応度であり、回帰式

$$R_{i,t} - r_f = \alpha_i + \beta_i (R_{m,t} - r_f) + \varepsilon_{i,t}$$

のOLS推定で得られる。切片 $\alpha_i$（ジェンセンのアルファ）はCAPMが正しければゼロであり、実務ではファンドや戦略の超過収益の指標として使われる。総リスクは $\sigma_i^2 = \beta_i^2 \sigma_m^2 + \sigma_\varepsilon^2$ とシステマティック部分と固有部分に分解される。

## 4. 日本株でのベータ推定の実務 — TOPIXベータ

日本株のベータ推定では、市場ポートフォリオの代理として**TOPIX（配当込み）**を使うのが標準である。日経平均は株価平均型（除数修正方式）でファーストリテイリングなど値がさ株の寄与が大きく、市場ポートフォリオの代理としては歪みが大きい。なおTOPIX自体も2022〜2025年にかけて流通株式時価総額基準による構成銘柄の段階的見直しが行われた点には留意する（2025年時点）。

実務上の標準的な設定と論点は以下のとおり。

| 論点 | 標準的な選択 | 補足 |
|---|---|---|
| リターン頻度 | 月次60ヶ月 or 週次2〜3年 | Bloomberg等は週次2年がデフォルトの一つ |
| 市場代理 | TOPIX配当込み | 日経平均は値がさ株バイアスあり |
| 無リスク金利 | 短期国債・コールレート | 低金利期は省略しても影響軽微だった |
| 非同時性バイアス | Dimsonベータ（ラグ項追加） | 流動性の低い新興株で過小推定を補正 |
| 平滑化 | Blume調整: $\hat{\beta}_{adj} = \tfrac{1}{3} + \tfrac{2}{3}\hat{\beta}$ | ベータの1への平均回帰を織り込む |

日本市場固有の注意点として、(1) 東証グロース市場の小型株は売買が薄く日次リターンにゼロが多いため、日次ベータは過小推定されやすい（Dimson補正やより低頻度のデータで対処）、(2) 銀行・輸出株など業種によって金利・為替感応度が強く、単一ベータでは説明力が低い局面がある、(3) 2013年以降の日銀ETF買入れ（2025年時点で新規買入れは停止）は指数の変動特性自体に影響したとの議論がある、などが挙げられる。

## 5. 推定誤差問題とショートセル制約

平均分散最適化の実務上の最大の敵は**推定誤差**である。最適解 $\mathbf{w}^* \propto \Sigma^{-1}(\boldsymbol{\mu} - r_f\mathbf{1})$ は入力に対して極めて敏感で、特に期待リターン $\boldsymbol{\mu}$ のわずかな違いがウェイトを激変させる。Michaud（1989年）はこれを「**推定誤差の最大化装置（error maximizer）**」と呼んだ。期待リターンの標本推定の標準誤差は $\sigma/\sqrt{T}$ であり、年率ボラティリティ20%の銘柄で期待リターンを±2%の精度で知るには理論上100年分のデータが必要になる——構造変化を考えれば事実上不可能である。共分散行列も $n$ が標本期間 $T$ に比べ大きいと標本共分散行列は退化し、逆行列が不安定になる。

対処法の系譜は次のとおり。

- **ショートセル制約（$w_i \geq 0$）**: 解析解は失われ2次計画法（QP）で解くが、Jagannathan and Ma（2003年）が示したとおり、非負制約は共分散行列を縮小推定することと数学的に等価であり、推定誤差を抑える正則化として機能する。日本の実務では、信用取引の空売りには金利・逆日歩のコストや残高規制があり、公募投信では実質的にロングオンリーが基本のため、この制約は現実的でもある。
- **縮小推定（shrinkage）**: Ledoit–Wolf型の共分散縮小、Blume調整のようなベータ縮小。
- **Black–Littermanモデル（1992年）**: 市場均衡（CAPM）から逆算したインプライド期待リターンを事前分布とし、投資家のビュー（見解）をベイズ更新で混ぜることで、極端なウェイトを回避する。
- **リスクベース配分**: 期待リターンを推定しない最小分散、リスクパリティ、等ウェイト（$1/n$）。DeMiguel et al.（2009年）は多くの最適化手法が単純な等ウェイトに勝てないことを示し、推定誤差の深刻さを象徴する結果として知られる。

CAPM自体も実証的には完全には支持されず、低ベータ銘柄のリターンが理論値より高い「ベータのフラット化（低ボラティリティ・アノマリー）」は日本株でも報告されている。実務ではCAPMを「唯一の真実」ではなく、資本コスト推定やパフォーマンス評価の共通言語・出発点として使い、サイズ・バリュー等を加えたマルチファクターモデルで補完するのが標準である。
