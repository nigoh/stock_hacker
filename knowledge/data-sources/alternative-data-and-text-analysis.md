# オルタナティブデータとテキスト分析

株価・財務諸表以外の情報源——開示書類や決算説明会のテキスト、ニュース・SNSのセンチメント、POSデータ・衛星画像・求人情報などの消費・企業活動データ——を体系化する。日本語NLP特有の課題と極性辞書・LLMの使い分け、日本でのデータ入手経路、月次売上を開示する小売・外食企業のモニタリング手法まで、日本株での実務を前提に整理する。

## 全体像：オルタナティブデータの分類

「オルタナティブデータ」とは、取引所の価格データや財務諸表という伝統的データの外側にある情報の総称である。日本株の文脈では大きく三層に分けると整理しやすい。

1. **テキスト（一次開示）**：TDnet適時開示、EDINETの有価証券報告書、決算説明会の書き起こし
2. **テキスト（二次情報）**：ニュース、アナリストレポート、SNS・掲示板
3. **非テキスト（実体経済の足跡）**：POS・クレジットカード消費、衛星画像、求人、アプリダウンロード、月次売上

上に行くほど法定・準法定の情報で信頼性が高く、下に行くほど「決算発表前に業績を先回りする」ナウキャスティング的な使い方になる。

## テキストの三大源泉と日本での入手経路

| 源泉 | 入手経路（2025年時点） | 特徴 |
|---|---|---|
| 適時開示（決算短信・業績修正等） | TDnet（閲覧無料、公式APIなし。スクレイピングや民間再配信で取得） | 速報性が最高。PDF中心で機械可読性が低い |
| 有価証券報告書・四半期報告書 | EDINET API（金融庁、無料、XBRL） | 「事業等のリスク」「MD&A」等の定性記述が宝庫 |
| 決算説明会書き起こし | ログミーファイナンス（無料公開分あり）、SCRIPTS Asia等の有料サービス | 経営者の生の言葉。Q&Aセッションに情報価値 |

米国のSEC EDGARやearnings callトランスクリプト（Seeking Alpha等）に比べ、日本は書き起こしの網羅率が低く、決算短信もPDF＋一部XBRLという構成のため、**前処理コストが高い**のが実務上の最大の違いである。決算短信サマリーはXBRL化されているが、定性情報（業績予想の修正理由など）はPDF本文からの抽出が必要になる。

## 日本語NLP特有の課題

英語圏の手法をそのまま持ち込めない理由が三つある。

- **分かち書きが必要**：日本語は単語境界がなく、MeCab・Sudachi・GiNZA等の形態素解析器でトークン化する。「増収増益」を1語と見るか4形態素と見るかで特徴量が変わり、金融用語辞書（NEologd等）の整備が精度を左右する。
- **極性辞書の不足**：英語には金融特化のLoughran-McDonald辞書（2011年）があるが、日本語では高村らの単語感情極性対応表（2006年）などの汎用辞書が中心で、金融文脈では誤判定が多い（例：「損失」を含む「損失計上の反動」はポジティブ）。東京大学和泉研究室などが金融極性辞書を研究してきたが、標準として定着した公開辞書は乏しい。
- **開示文体の定型性**：日本企業の開示は「〜となりました」調の定型文が多く、情報は定型からの**逸脱**（リスク記述の増加、業績予想の文言変化）に宿る。前年同期の文書との差分検出が有効な所以である。

辞書ベースの古典的なセンチメントスコアは、ポジティブ語数 $P$、ネガティブ語数 $N$ に対して

$$S = \frac{P - N}{P + N}$$

と定義するのが基本形（$S \in [-1, 1]$）。単語重要度には TF-IDF $w_{t,d} = \mathrm{tf}_{t,d} \cdot \log \frac{|D|}{\mathrm{df}_t}$ を用い、頻出定型語の影響を抑える。2020年代以降はBERT系日本語モデル（東北大BERT等）や、辞書整備を不要にするLLMによる直接分類・要約が主流になりつつある。LLM活用では（1）決算短信からの業績修正理由の構造化抽出、（2）説明会Q&Aのトーン評価、（3）リスク記述の前年差分要約、が実務的な三大用途だが、出力の再現性（温度設定・プロンプト固定）とハルシネーション検証が不可欠である。

## ニュース・SNSセンチメント

- **日経テレコン**：日経4紙＋一般紙の記事アーカイブ。企業名の記事件数・論調の時系列化が可能（法人契約が中心で個人にはコスト高）。日経系ではQUICKがニュースセンチメント指数を機関投資家向けに提供してきた。
- **みんかぶ・Yahoo!ファイナンス掲示板**：個人投資家の注目度の代理変数。掲示板投稿数の急増は出来高・ボラティリティ上昇と同時的で、順張りシグナルというより**過熱の検知**に向く。
- **X（旧Twitter）**：2023年のAPI有料化以降、大量取得のコストが大幅に上がった点に注意（2025年時点）。日本語ツイートのセンチメントと株価の関係は実証研究が多数あるが、ボット・煽り投稿の除去が精度の前提となる。

SNS由来のシグナルは概して減衰が速く（数時間〜数日）、小型株ほど効きやすい一方、流動性が低く執行コストで利益が消えやすいという構造的なトレードオフがある。

## 消費・企業活動データ

| データ | 主な提供元（2025年時点） | 使い方の例 |
|---|---|---|
| POS・ID-POS | インテージSRI+、True Data | 食品・日用品メーカーの売上ナウキャスト |
| クレジットカード消費 | ナウキャスト×JCB「JCB消費NOW」 | 外食・小売・旅行の需要トレンド |
| 衛星画像 | Orbital Insight等（海外勢中心） | 駐車場の車両数、石油タンク在庫、工場稼働 |
| 求人情報 | 求人サイトのスクレイピング、HRog等 | 出店・採用拡大＝成長シグナル、急減＝業績懸念 |
| アプリDL・利用状況 | Sensor Tower（data.ai統合後）、App Tweak等 | ゲーム株のヒット検知（日本市場で特に有効） |

日本で特に実用性が高いのは**ゲーム株×アプリランキング**である。スマホゲームは売上のセルランキング（App Store/Google Play）との相関が高く、四半期決算前にヒット/失速をかなりの精度で推定できるため、個人投資家にも参入余地がある数少ない領域といえる。

## 月次売上モニタリング：日本固有の定点観測

日本の小売・外食には**月次売上（既存店・全店の前年同月比）を自主開示する慣行**があり、ファーストリテイリング（国内ユニクロ）、ニトリHD、ABCマート、しまむら、マクドナルドHD、ゼンショーHDなど多数が毎月上旬に公表する。これは米国で月次同店売上の開示が2000年代に縮小したのと対照的で、日本株のアルタナ分析における最重要の定点観測となっている。

実務の型は以下の通り。

1. **既存店売上高前年比**を主指標とし、客数×客単価に分解して要因を見る
2. 天候・曜日構成・うるう年・消費税率変更（2019年10月の10%引き上げ等）の歪みを補正する
3. 四半期累計の月次実績と会社計画の進捗率から、決算での上振れ/下振れを事前推定する

月次開示日の株価反応を事象研究で測る場合、異常リターンは $AR_{i,t} = R_{i,t} - E[R_{i,t}]$（$E[R_{i,t}]$ はマーケットモデル等による期待リターン）で定義し、開示前後の累積異常リターン $CAR = \sum_t AR_{i,t}$ を見る。月次サプライズ後にもドリフトが観察されるとの実証報告があり、決算のPEAD（決算後株価ドリフト）の月次版として研究されてきた。集計サイトとしてはIRバンク等が月次データを整理しており、個人でも追跡しやすい。

## 実証研究と実務上の留意点

日本語テキストと株価の研究は2010年代から蓄積があり、日銀・内閣府も景気ウォッチャー調査のコメントや新聞記事のテキスト分析で景況感指数を構築する試みを公表してきた。学術面では人工知能学会の金融情報学研究会（SIG-FIN）が日本語金融テキストマイニング研究の集積地である。ただし実務では次の罠に注意する。

- **ルックアヘッドバイアス**：テキストの「公表時刻」でポイントインタイム管理をする（TDnetは開示時刻が分単位で記録される）
- **多重検定**：語彙・特徴量が数万次元に及ぶため、イン・サンプルで有意なシグナルの大半は偽陽性である
- **データの短命性**：有効なアルタナシグナルは利用者が増えると減衰する。データ購入コスト（機関向けは年数百万円規模も珍しくない）と期待超過収益の比較が常に必要
