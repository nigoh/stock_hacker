# 日本株データ取得APIの徹底カタログ

日本株（東証上場株式）のデータをプログラムで取得するための API を、公式・公的／証券会社／データベンダー／海外サードパーティ／Pythonライブラリまで横断して網羅する実務カタログ。
各ソースを鮮度・コスト・カバレッジ・認証・機械可読性・規約の軸で比較し、用途別の選び方を示す。数値は2026年時点で、制度・料金は変わるため重要判断前に一次情報の再確認を推奨する。

関連: 概論と取得実務は [`data-apis-and-tools.md`](data-apis-and-tools.md)、発注・自動売買の観点は [`brokerage-apis-and-automated-trading.md`](brokerage-apis-and-automated-trading.md)、オルタナデータは [`alternative-data-and-text-analysis.md`](alternative-data-and-text-analysis.md)。

## 選び方の6軸

データソースは次の6軸で評価すると迷わない。

1. **鮮度**（リアルタイム／数十分遅延／12週間遅延／EOD）
2. **コスト**（無料／口座付帯／月額／法人見積）
3. **日本株カバレッジ**（東証銘柄が実際に取れるか。海外APIは過大評価しやすい）
4. **認証**（不要／APIキー／OAuth／ローカルゲートウェイ常駐）
5. **機械可読性**（REST/JSON／CSV／Excel-RSS／XBRL／画面のみ）
6. **規約**（再配信可否・自動取得の許容・口座条件）

重要な構造的制約として、**「鮮度」「機械処理可否」「無料」は同時に満たせない**（トリレンマ）。無料枠は「過去を正確に機械処理する」用途に最適化され、「現在を正確に機械処理する」用途は有料 API か証券口座の閲覧に委ねられている。詳細は [`data-apis-and-tools.md`](data-apis-and-tools.md) の「無料でリアルタイムに近い株価を得ることの限界」節。

## 1. 公式・公的 API（一次情報）

| API | 取得できるデータ | 鮮度 | 料金 | 認証 | 形式 |
|---|---|---|---|---|---|
| **J-Quants API**（JPX総研） | 日足四本値・財務・決算予定・配当・投資部門別・信用残・空売り・指数/TOPIX・先物/オプション等 | Free=12週遅延／有料=翌営業日等。分足/TickはLight以上アドオン | Free ¥0 / Light ¥1,650 / Standard ¥3,300 / Premium ¥16,500（月額） | **V2: APIキー（`x-api-key`・無期限）** | JSON（有料はCSV一括DLも） |
| **EDINET API v2**（金融庁） | 有報・四半期/半期・大量保有・臨時報告等の法定開示 | 提出後ほぼ即時 | 無料 | APIキー（無料登録・Subscription-Key） | XBRL(ZIP)・PDF・CSV・英文 |
| **e-Stat API**（総務省） | 政府統計全般（労働力・CPI・家計・法人企業統計等） | 各統計の公表に追随 | 無料 | アプリケーションID（appId、無料） | XML/JSON/CSV |
| **日銀 時系列統計データ** | 金利・為替・短観DI・マネーストック・資金循環等 約20万系列 | 営業日8:50頃更新 | 無料 | **登録不要**（API機能は2026/2/18提供開始） | JSON/CSV |
| **JPX 公式統計** | 投資部門別売買・空売り集計・裁定残高・信用残 等 | 日次/週次 | 無料 | 不要 | Excel(.xls)/CSV（**公式APIなし**、ファイルDLをパース） |
| **TDnet（適時開示）** | 全上場会社の適時開示（決算短信等） | リアルタイム | 有料（TDnet APIサービス 基本¥70,000〜/月）／J-Quantsアドオン | 有料契約 | XBRL/PDF（**無料の公式APIなし**・スクレイピング禁止） |

**J-Quants API（事実上の標準）** — V2 詳細・プラン別エンドポイント・レート制限・5桁コード・調整の扱いは [`data-apis-and-tools.md`](data-apis-and-tools.md) の J-Quants 節を参照。要点のみ:
- **2025/12/22 に V2 へ刷新**。認証が APIキー方式（`x-api-key`・無期限）に変更、V1 のリフレッシュトークン方式は廃止。エンドポイントは `/v2/equities/bars/daily`（日足）・`/equities/master`（銘柄一覧）等。レスポンスは `data` 配列＋`pagination_key`、四本値カラムは短縮形（`O`/`AdjC` 等）。
- レート制限（req/分）: Free 5 / Light 60 / Standard 120 / Premium 500。
- **本リポジトリは V2 に対応済み**（`stocklib.jquants`、環境変数 `JQUANTS_API_KEY`）。

**EDINET API v2** — 本リポジトリに接続実装済み（`stocklib.edinet`、要 `EDINET_API_KEY`）。有報等が XBRL/CSV で機械可読なのが最大の利点。ベース `https://api.edinet-fsa.go.jp/api/v2/`、書類一覧 `documents.json` → 書類取得 `documents/{docID}`（type=1 XBRL / 2 PDF / 5 CSV）。

**日銀 時系列統計** — 2026年2月に API 機能が新設され、従来の CSV 手動 DL からプログラム取得に道が開けた（登録不要）。金利・短観 DI・マネーストック等のマクロ背景に有用。

**JPX 公式統計** — 投資部門別売買・空売り・裁定残は公式 API がなく Excel/CSV の DL をパースする。同種データを機械可読で欲しければ J-Quants（有料）が正規ルート。

## 2. 証券会社 API（データ取得の観点）

個人が口座付帯で使える証券会社 API。発注機能が主眼のものが多いが、株価・板・ヒストリカルの取得可否で評価する。

| 証券会社 / API | 取得できるデータ | 鮮度 | 料金 | 接続方式 | Python | データ取得評価 |
|---|---|---|---|---|:---:|---|
| **立花証券 e支店API** | リアルタイム株価・板・ティック・**日足20年ヒストリカル**・銘柄マスタ・ニュース | リアルタイム | **完全無料・条件なし** | HTTPS+JSON／WebSocket。**常駐アプリ不要・クラウド完結可** | ○ | **データ取得では最有力**（無料・条件緩・長期日足） |
| **kabuステーションAPI**（三菱UFJ eスマート証券／旧auカブコム） | 現在値・四本値・板気配（Pro以上でフル板）・時価PUSH・ランキング | 真のリアルタイム（PUSH） | 無料（Professionalプラン条件あり） | **Windows常駐アプリ必須**（localhost REST+WebSocket） | ○ | RT監視・自動売買向き。ヒストリカルは弱い |
| **Interactive Brokers（TWS API／Client Portal API）** | 東証L1気配・L2板・ティック・日/分足ヒストリカル・財務（別購読） | リアルタイム（購読）／10-20分遅延（無料） | 口座無料。TSE L1（非プロ）無料／L2 約¥3,600/月 | TWS/IB Gateway常駐＋API、またはWeb API | ○（ibapi, ib_async） | 海外経由で東証をPython取得。ヒストリカルはL1購読必須 |
| **楽天証券 マーケットスピードII RSS** | 現在値・四本値・板・出来高・信用残・時系列 | リアルタイム（一部指数10-20分遅延） | 無料（要MS2申請） | Excelアドイン（RSS関数）。Windows+Excel+MS2常駐 | ✕（Excel経由の間接） | Excel手動には強力。Python自動化に不向き |
| **SBIネオトレード証券 ネオトレAPI for Excel** | 四本値・出来高・ランキング・発注 | リアルタイム | 要確認 | Excelアドイン | 間接 | SBI証券本体とは別法人。Excel前提 |
| **マネックス証券** | 口座残高連携API（B2B）のみ。**市場データAPIなし** | — | — | OAuth2.0（B2B） | ✕ | データ取得には使えない |
| **松井証券** | 公式データ取得API**なし**（ツールで目視） | — | — | GUIツールのみ | ✕ | データ取得には使えない |
| **SBI証券（本体）** | 公式APIは**先物・オプションのみ**。現物はHYPER SBI 2で日足20年CSV手動出力 | ツールはRT | 無料 | 先物OPは外部ツール／現物はGUI+手動CSV | 現物✕ | 現物のプログラム取得は不可 |
| **GMOクリック証券** | 株式の公式データ取得API**なし**（旧WebサービスAPIは2009年終了） | — | — | なし | ✕ | データ取得には使えない |
| **moomoo証券／futu OpenAPI** | 米国/香港/中国A株の相場・板・ヒストリカル。**日本株の相場データ権限は公式に「未対応」** | US/HK/A株はRT | API無料（相場は市場別ライセンス） | OpenD ローカルゲートウェイ必須。Python `moomoo-api` | ○（ただし日本株は×） | **日本株データ取得には実質不可**（下記） |

**立花証券 e支店API（データ取得の隠れた本命）** — 「個人のための無料の日本株API」を掲げ、**無料・口座条件が緩く・クラウド完結（常駐アプリ不要）・リアルタイム＋20年日足**を1本で賄える。難点は口座がe支店に限られること、独自認証・SJIS の学習コスト、対象が国内株現物/信用のみな点。データの再配信は規約で禁止。

**kabuステーションAPI** — 真のリアルタイム板・ティックを PUSH で取れ、日本株の個人自動売買では事実上の標準。ただし **Windows 常駐アプリの起動が必須**（早朝に自動ログアウト）で、クラウド単体では動かない。ヒストリカル収集用途には不向き。

**Interactive Brokers** — 海外ブローカー経由で東証データを Python 取得する現実的選択肢。**非プロは TSE L1 が無料**でリアルタイム、L2（板の深さ）は約¥3,600/月（2026年時点）。`reqHistoricalData` は L1 のリアルタイム購読が前提で、遅延のみの口座ではヒストリカルを取れない点、ローカルゲートウェイ常駐が要る点に注意。

**moomoo証券／futu OpenAPI（日本株には未対応）** — moomoo/futu の OpenAPI は米国株の無料 API トレードが差別化点で、**公式の権限表（authority ページ、日英とも）で日本市場の相場データ権限が「未対応（Unsupported）」と明記**されている（v10.8〜10.9、2026年時点）。API の市場定義に日本枠はあるが、板・四本値・ティックを引く経路は確認できない。OpenD ローカルゲートウェイ必須。**日本株データ取得目的では実質不可**で、日本株なら J-Quants／立花／yfinance が現実的。

## 4. 海外・サードパーティ API の日本株カバレッジ

海外系 API は日本株カバレッジを過大評価しやすい。**実際に東証銘柄が取れるか**を最重要視した早見表（2026年時点）。

| サービス | 日本株 | データ種別 | 鮮度 | 無料枠 | 料金 |
|---|:---:|---|---|---|---|
| **Twelve Data** | ○ | 株価・指数（東証=XJPX） | 有料でRT/分足 | 8/分・800/日 | $29〜/月 |
| **EODHD** | ○ | EOD・ファンダ・一部分足（TSE） | EOD中心（日本RTは限定） | 20call/日 | $19.99〜99.99/月 |
| **Stooq** | ○ | 日足/時間足/5分足（`.jp` 例 `7203.JP`） | EOD中心 | 無料（CSV直DL） | — |
| **Alpha Vantage** | △ | OHLCV（主要銘柄のみ・信頼性低） | 遅延 | 25call/日 | $49.99〜/月 |
| **Finnhub** | △ | 価格・財務（TSE、国際株は有料限定） | 有料でRT | 米国株のみ | $11.99〜/月 |
| **Marketstack** | △ | EOD・intraday（XTKS） | EOD中心 | 100call/月 | $9.99〜/月 |
| **FMP** | △ | 価格・財務（`6231.T` 等、日本は薄い） | EOD中心 | 制限大 | $22〜/月 |
| **Nasdaq Data Link**（旧Quandl） | △ | 日本EODは有料プレミアムDBのみ | EOD | 実質なし | DB別課金 |
| **Tiingo** | ✕ | 米・中ADR中心 | EOD | あり | $10〜/月 |
| **Polygon.io** | ✕ | **米国株専用** | RT（米） | あり | $29〜/月 |

**要点**: 海外 API で日本株を本命ソースにするなら **Twelve Data / EODHD / Stooq** が現実的。Polygon・Tiingo は日本株非対応、Alpha Vantage・Finnhub・Marketstack・FMP は限定的で銘柄単位の実測が要る。無料で日本株 EOD を機械取得するなら **Stooq**（pandas-datareader のコネクタが現役）が使いやすい。

## 5. 国内情報サービス・Pythonライブラリ

**国内情報サービス**:
- **バフェットコード API** ◎（日本株の財務・指標特化。個人 Premium ¥10,800/月、Sheets `BCODE` 関数中心）。
- **会社四季報／四季報AI API**（ロゼッタが2024年に外部提供開始。個別見積）。
- **株探（かぶたん）** ✕（公式APIなし。掲載情報の機械的取得は規約で明確に禁止）。

**Pythonライブラリ**:
- **jquants-api-client**（公式・◎）: `pip install jquants-api-client`。**V2 は APIキー認証（`JQUANTS_API_KEY`）**。整形済みの OHLCV・財務・銘柄一覧を返す。日本株の本命ライブラリ。
- **yfinance**（◎）: 完全無料・`.T` サフィックス・約15-20分遅延。非公式ゆえ調整の不備・仕様変更リスク（本リポジトリの既定ソース）。
- **pandas-datareader**（△）: Yahoo リーダーは廃止。日本株は **Stooq コネクタ**経由が実用。
- **investpy**（✕・機能停止）: 依存先 Investing.com の Cloudflare 保護変更で 403 停止。後継 investiny も将来性不透明。**新規採用は非推奨**。
- **blpapi / LSEG Data Library / fds.sdk.***（各社公式）: 席・契約が前提（プロ向け）。

## 6. 用途別の推奨と本リポジトリの実装状況

**用途別の第一候補（2026年時点）**:

| 用途 | 第一候補 |
|---|---|
| 直近の株価で分析（大多数） | **yfinance**（本リポジトリ既定・切替不要） |
| 過去データで学習・バックテスト・全銘柄 | **J-Quants Free**（12週遅延・調整済み・全銘柄） |
| 遅延なしの日次運用 | J-Quants 有料プラン ／ 立花 e支店API |
| リアルタイム板・自動売買 | kabuステーションAPI（Win常駐）／ 立花 e支店API ／ IB |
| 業績・法定開示の一次情報 | **EDINET API**（本リポジトリ実装済み）／ TDnet |
| マクロ背景 | 日銀時系列API ／ e-Stat API |
| 海外から東証を機械取得 | Interactive Brokers（非プロ L1 無料）／ Twelve Data ／ EODHD |

**本リポジトリの接続実装状況**:
- **実装済み**: yfinance（既定、`stocklib.data`）／ J-Quants V2（`stocklib.jquants`、`JQUANTS_API_KEY`、`--source jquants` で opt-in）／ EDINET v2（`stocklib.edinet`、`EDINET_API_KEY`）。
- **未実装（本カタログで整理・将来の候補）**: 証券会社API（立花・kabuステ・IB 等）、データベンダー、海外サードパーティ、日銀/e-Stat/JPX統計。証券会社 API の多くは口座・ローカルゲートウェイ・OS 制約があり、環境非依存の自動テストが難しい点に留意。
