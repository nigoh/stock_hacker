# TDnet適時開示の実務的な読み方

東証の適時開示情報閲覧サービス（TDnet）は日本株の材料が最初に出る場所だが、掲載31日で消える・全文検索がない等の構造的制約がある。
本稿は開示種別ごとの株価反応の違い、引け後に集中する開示タイミングと価格発見、「開示の型」からの異常検知、EDINET（法定開示）との役割分担を実務目線で整理する。
制度の条文レベルの解説は [`../regulation-tax/disclosure-and-insider-rules.md`](../regulation-tax/disclosure-and-insider-rules.md)、API・取得手段の比較は [`market-data-apis-catalog.md`](market-data-apis-catalog.md) に譲る。

## TDnetの構造と、閲覧サービスの制約

TDnet（Timely Disclosure network、適時開示情報伝達システム）は、上場会社が作成した適時開示資料を取引所が受け付け、報道機関・情報ベンダー・一般公衆へ同時に配信する仕組みである。ここで区別すべきは次の三層で、実務上の使い勝手はまったく異なる。

| 層 | 実体 | 鮮度 | 機械可読性 | コスト（2026年時点） |
|---|---|---|---|---|
| 配信（ベンダー向け） | TDnet APIサービス／情報ベンダー経由 | リアルタイム | ○（XBRL/PDF） | 有料（基本 ¥70,000〜/月の水準） |
| 閲覧（一般公衆向け） | 適時開示情報閲覧サービス（Web） | ほぼリアルタイム | △（画面＋PDF） | 無料 |
| 過去分の検索 | TDnetDBS（過去約5年を検索）等の有料DB、各社IRサイト | 過去 | △ | 有料または手作業 |

個人が無料で触れるのは中段の閲覧サービスだけで、ここに三つの制約がある（2026年時点）。

1. **掲載期間が短い**——開示日を含めて**31日分**（土日祝を含む）しか掲載されない。1か月より前の開示は閲覧サービスからは消える。
2. **検索性が低い**——日付・会社名・コード・開示種別といった粗い絞り込みが中心で、本文の全文横断検索はできない。「過去3年の『下方修正』を全文検索する」といった使い方は想定されていない。
3. **一括取得の正規手段がない**——無料の公式APIは提供されていない。機械取得の正規ルートは有料の TDnet API か、J-Quants の TDnet アドオン等の再配信サービスである。

この結果、**「その日のうちに自分で保存しないと、後から遡れない」**という運用上の帰結が生じる。過去の開示を検証に使いたければ、(a) 有料DB・有料APIを契約する、(b) 個社ごとに各社IRサイトの「開示資料」ページを辿る（掲載方針は会社によりばらつく）、(c) 法定開示分に限り EDINET で遡る、のいずれかになる。イベントスタディでポイント・イン・タイムの開示時刻を厳密に扱いたい場合、この制約が最初の壁になる。

## 開示種別ごとの株価インパクトの違い

適時開示は一括りにできない。以下は日本株で観察されてきた傾向の整理であり、個別事例では反対方向にも動くため、断定的な期待値として扱わない。

| 開示種別 | 媒体 | 反応の一般的な傾向 | 読むときの勘所 |
|---|---|---|---|
| 決算短信 | TDnet | 反応の大きさは「実績」より**同時に出る新年度・通期予想**に左右されやすい | 実績サプライズとガイダンス・サプライズを分けて測る |
| 業績予想の修正 | TDnet | 単独で飛んでくるため反応が鋭い。方向・幅・要因で差 | 本業（営業利益）由来か、為替差益・特別損益由来かを区別 |
| 配当予想の修正 | TDnet | 増配・累進配当への言及は還元姿勢の変化として読まれやすい | 業績修正と同時か単独か。記念配当・特別配当の一過性 |
| 自己株式取得 | TDnet | 取得枠の**発行済株式総数比**と取得期間が注目されやすい | 枠は上限であって実行義務ではない。実際の取得は月次で開示 |
| 公募増資・第三者割当 | TDnet | 希薄化が意識される。割当先・行使価額修正条項の有無が論点 | 希薄化率 $d = \dfrac{N_{\text{new}}}{N_{\text{old}} + N_{\text{new}}}$ を必ず計算する |
| 業務・資本提携、M&A | TDnet | 買い手・売り手、対価、のれんの規模で評価が割れる | 「検討開始」と「決定」は別物。報道先行時の会社側コメントに注意 |
| 大量保有報告書（5%ルール） | **EDINET** | 保有目的の記載（純投資／重要提案行為等）で受け止めが変わる | TDnetではなくEDINET側。5営業日以内提出のため事後的 |
| 不祥事・特別損失・訂正報告 | TDnet | 影響額の確定度合いと、追加開示の有無で長引きやすい | 第一報は「調査中」が多い。第三者委員会設置は長期化の目印 |

制度上の閾値も押さえておく。業績予想の修正は、直近予想との乖離が売上高で±10%、各段階利益で±30%以上見込まれた時点で開示が求められる（東証ルール、2025年時点）。この閾値の存在が「修正が離散的なイベントとして飛んでくる」という日本株固有の構造を作っている（詳細は [`../fundamental/earnings-guidance-and-consensus.md`](../fundamental/earnings-guidance-and-consensus.md)）。

## 開示タイミングと価格発見

適時開示は「決定・発生後**直ちに**」が原則なので、理屈の上では場中でも出る。しかし実務では、価格形成の混乱を避ける観点から**引け後に集中する慣行**が定着している。

- **引け後**：東証の後場終了は2024年11月5日から15:30（2026年時点）。決算短信の多くは15:30以降、とりわけ15:30〜16:30と、開示ラッシュ日の17時前後に集中する。決算期の集中日（3月期本決算なら5月上旬〜中旬、四半期なら各期末の翌月）は、同時刻に数百件が並び、人手での読み分けが物理的に追いつかない。
- **場中開示**：報道が先行した場合や、発生事実（災害・訴訟・システム障害等）は場中に出ることがある。この場合、当該銘柄には特別気配が表示され、板寄せで価格が飛ぶことがある。
- **金曜引け後・連休前**：織り込みに使える時間が長くなるため、悪材料が金曜引け後や連休前に出やすいという見方が語られてきた。ただし体系的な傾向として断定できるほど頑健な結論ではなく、決算期日程の都合という説明も成り立つ。
- **PTS夜間取引**：東証の立会終了後も PTS（私設取引システム）の夜間取引は動いており、引け後開示への反応がここで先に出る。ただし PTS の板は薄く、翌日の東証寄り付きが同じ方向・同じ幅で始まる保証はない。夜間の値動きを「翌日の答え」と見なさない（[`../market-structure/pts-night-trading-and-fragmentation.md`](../market-structure/pts-night-trading-and-fragmentation.md)）。

分析上の含意は単純で、**開示時刻のタイムスタンプを分単位で保持する**ことに尽きる。「開示日」だけで日次リターンに紐付けると、15:30前の開示と20:00の開示を同一視することになり、イベントスタディのイベント窓がずれる。TDnet は開示時刻を分単位で記録しているので、取得時にこれを落とさない。

## 決算短信サマリーはXBRLで機械可読

決算短信のうち**サマリー情報と財務諸表はXBRLで提供**され、業績予想の修正・配当予想の修正、コーポレート・ガバナンス報告書もXBRLデータが提供される（2026年時点）。加えて、2024年4月1日以後開始する事業年度からは決算短信の目次以降のページのHTMLデータも提供されている。

つまり「売上高・各段階利益・EPS・通期予想」といった数値部分は、PDFを読まずに構造化データとして取れる。一方で、業績予想の修正**理由**や定性的な説明はPDF本文側にあり、そこは機械可読でない。この非対称性が、日本株のテキスト分析における前処理コストの高さの正体である（[`alternative-data-and-text-analysis.md`](alternative-data-and-text-analysis.md)）。XBRLの構造・解析方法・拡張タクソノミの落とし穴は [`xbrl-and-scraping-practice.md`](xbrl-and-scraping-practice.md) を参照。

## 「開示の型」から異常を見つける

日本企業の開示は文体・構成の定型性が高い。裏を返せば、**情報は定型からの逸脱に宿る**。読み手のチェックリストとして機能するのは次のような点である。

- **定型文の変化**：「順調に推移」「堅調」といった常用句が、前年同期の同じ資料から入れ替わっている箇所。前年同期・前四半期の同種資料との**差分**を取ると浮き上がる。
- **注記の追加**：継続企業の前提に関する注記（GC注記）や「継続企業の前提に関する重要事象等」の記載は、財務健全性に関する重い信号として扱われる（[`../fundamental/credit-risk-and-delisting.md`](../fundamental/credit-risk-and-delisting.md)）。
- **区分の変更**：セグメント区分の変更・統合は事業ポートフォリオの再定義を意味するが、不振事業を大きな区分に埋没させる効果も持つ。変更年度は前年同期比の連続性が切れる。
- **予想開示形式の変更**：ピンポイント予想からレンジ予想・非開示への切り替え、あるいは予想の「未定」化は、経営側の不確実性認識の変化を示すことがある。
- **訂正の頻度と種類**：決算短信の訂正、過年度決算の訂正（訂正報告書）が続く企業は、開示体制そのものを疑う材料になる（[`../fundamental/earnings-quality-and-accounting-fraud.md`](../fundamental/earnings-quality-and-accounting-fraud.md)）。
- **時刻の異常**：常時17時に出す会社が突然20時台・翌早朝に出した、決算発表日を延期した——といったメタ情報も観察対象になる。

いずれも「異常の候補を機械的に洗い出し、人間が原資料で確認する」使い方が現実的で、単独で売買判断に直結させる性質のものではない。

## 適時開示（取引所ルール）とEDINET（法定開示）の役割分担

両者は代替ではなく補完である。混同すると「どこを探せばよいか」で迷う。

| 観点 | 適時開示（TDnet） | 法定開示（EDINET） |
|---|---|---|
| 根拠 | 東証の有価証券上場規程（取引所ルール） | 金融商品取引法 |
| 主な書類 | 決算短信、業績・配当予想の修正、決定事実・発生事実 | 有価証券報告書、半期報告書、臨時報告書、大量保有報告書、公開買付届出書 |
| 速報性 | 高い（決定・発生後直ちに） | 提出期限内（有報は事業年度末後3か月以内） |
| 監査 | 決算短信は監査対象外 | 有報は監査済み |
| 違反の効果 | 取引所の措置（改善報告書・公表措置・上場契約違約金等） | 課徴金・刑事罰 |
| 保存性 | 閲覧サービスは31日 | 過去分が長期に検索可能・API あり |

使い分けの型は「**速報は TDnet、確認と遡及は EDINET**」である。大量保有報告書やTOB関連は最初から EDINET 側にしかない点にも注意する。EDINET は無料APIを持ち機械取得できるため（要APIキー、2025年時点）、遡及的な検証を組む場合の基盤は EDINET 側になる。

## 速報性を追うことの限界と、公平性の制度

「開示を誰より速く読む」ことに投資妙味があるように見えるが、個人がここで優位を取るのは構造的に難しい。

- **配信経路の差**：ベンダー向けのリアルタイム配信は有料契約で、機械可読形式のまま低遅延で届く。無料の閲覧サービスを人間が目視する経路とは、そもそも土俵が違う。
- **反応速度の差**：定型的な数値（売上・利益・予想）はXBRLから即座に抽出でき、閾値判定は機械が行う。数百件が同時刻に並ぶ日に、人間が全件を読み分けることは想定されていない。
- **「公表」の意味**：インサイダー取引規制における「公表」は、TDnet掲載で即時に成立する（他に2以上の報道機関への公開から12時間経過という12時間ルールがある）。つまりTDnetに出た瞬間から、その情報は誰でも使ってよい情報になる。速さの勝負はこの瞬間から始まる。

公平性の側では、**フェア・ディスクロージャー・ルール（FDルール）**が2018年4月に施行され、上場会社等が未公表の重要情報をアナリスト・機関投資家等へ選択的に伝達した場合、意図的な伝達なら同時に、意図的でない伝達なら速やかに公表する義務が課された。施行後は決算期前の沈黙期間（サイレント期間）を設ける実務が定着している。制度は情報の「入口」の公平を担保するものであって、**取得後の処理速度の差を埋めるものではない**点は理解しておきたい。

この非対称性を踏まえると、個人の分析設計としては「初動の速さ」ではなく、**開示後に残る調整過程**を対象にするほうが整合的である。決算発表後の株価ドリフト（PEAD）は初動に情報が織り込みきれない現象として長く研究されてきたが、周知に伴う減衰も指摘されており、将来も同様に観察されるかは断定できない。イベント設計・執行コストを含めた検証の枠組みは [`../strategies/event-driven-japan.md`](../strategies/event-driven-japan.md) を参照。
