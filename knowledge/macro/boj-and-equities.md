# 日銀の金融政策と株式市場

日本銀行は1999年のゼロ金利政策以降、四半世紀にわたり非伝統的金融政策を展開し、2024年3月にマイナス金利・YCC（イールドカーブ・コントロール）を解除して「金利ある世界」への正常化に踏み出した。本稿では政策枠組みの変遷、政策が株価に波及する経路、日銀が保有する巨額のETFの出口問題、そして金利と株式バリュエーションの理論的関係を整理する。

## 1. 政策枠組みの変遷

| 期間 | 枠組み | 主な内容 |
|---|---|---|
| 1999–2000 | ゼロ金利政策 | 無担保コール翌日物金利を実質0%に誘導 |
| 2001–2006 | 量的緩和（QE） | 操作目標を日銀当座預金残高に変更。世界初の本格的QE |
| 2010–2013 | 包括緩和 | 資産買入等基金を創設。**ETF・J-REITの買入を開始（2010年）** |
| 2013–2016 | 量的・質的金融緩和（QQE） | 黒田総裁下の「異次元緩和」。マネタリーベース2倍、国債・ETF買入を大幅拡大 |
| 2016.1– | マイナス金利付きQQE | 日銀当座預金の政策金利残高に**−0.1%**を適用（三層構造） |
| 2016.9– | YCC（長短金利操作） | 10年国債利回りを0%程度に誘導。変動許容幅は±0.1%→±0.25%（2021年）→±0.5%（2022年12月）→事実上±1%（2023年） |
| 2024.3 | 正常化開始 | マイナス金利・YCC・ETF新規買入を終了。政策金利0〜0.1%へ |
| 2024.7〜2025 | 利上げ局面 | 0.25%（2024年7月）、0.5%（2025年1月）へ引き上げ。国債買入の減額（QT）も進行（いずれも実施時点の事実） |

日本市場固有の重要イベントとして、**2024年8月初旬の急落（8月5日の日経平均は過去最大の下落幅約4,451円）**がある。2024年7月末の利上げと米景気懸念が重なり、低金利の円で調達して高金利資産に投資する**円キャリートレードの巻き戻し**が急激な円高・株安を引き起こした。日銀の政策変更が為替経路を通じて株式市場を大きく揺らすことを示した典型例である。

## 2. 政策が株価に効く経路

1. **金利・割引率経路**：長期金利の低下は株式の理論価値を直接押し上げる（後述の数式参照）。YCC下では10年金利が人為的に抑制され、株式のバリュエーション（特にグロース株）を支えた。
2. **為替経路**：日米金利差の拡大は円安をもたらす。TOPIXは輸出企業の比重が高く、円安は自動車・機械などの円換算利益を押し上げる。逆に利上げ観測→円高は株安要因になりやすい。2022〜2024年の1ドル150円前後の円安局面（当時）は企業業績の上振れと株高の一因となった。
3. **需給経路（ETF買入）**：日銀自身が株式市場の買い手となる直接的経路。「日銀プレイ」（前場が大きく下落すると後場の日銀買入を見込んで押し目買いが入る現象）という日本市場特有の需給パターンを生んだ。
4. **期待・シグナル経路**：金融政策のスタンス変更は将来のインフレ・成長期待を変え、リスクプレミアムに作用する。2013年4月の「異次元緩和」発表時は、内容以上に「デフレ脱却への本気度」のシグナルとして株価が急騰した。
5. **銀行収益経路**：マイナス金利は銀行の利ざやを圧迫し銀行株の逆風となったが、2024年以降の利上げ局面では逆に銀行株が主導セクターとなった。金融政策の方向は東証33業種のセクターローテーションを規定する主要因である。

## 3. 日銀ETF保有の出口問題

- **規模**：日銀のETF保有は簿価約37兆円、時価では約70兆円超（2024〜2025年時点の概数）。**日銀は東証プライム市場全体の時価総額の約7%を保有する事実上の最大株主**とされる。
- **買入の歴史**：2010年に年4,500億円で開始し、QQE下で年3兆円→6兆円（2016年）→コロナ対応で上限12兆円（2020年）まで拡大。当初は日経平均連動型中心だったため**値がさ株（ファーストリテイリング等）の浮動株比率低下・価格形成の歪み**が問題視され、2018年以降TOPIX連動型中心に変更、2021年からはTOPIX型のみとなった。2024年3月に新規買入を終了。
- **出口の論点**（2025年時点で本格的売却は未着手）：
  - 市場で売却すれば需給悪化が避けられない規模であり、過去の銀行保有株の売却（2002年〜、年数千億円ペースで長期分割）が参照事例とされる。単純計算で完了まで数十年かかりうるとの試算が多い。
  - 分配金（信託報酬控除後）は日銀の収益となっており、年1兆円規模の収益源を手放す論点もある。
  - 時価が簿価を大きく上回るため含み益は巨額だが、株価急落時には日銀の財務毀損リスクとなる。日銀は簿価と時価の関係で引当金ルールを設けている。
  - 政府系機関への移管、国民への割引譲渡など様々な構想が議論されているが、2025年時点で方針は確定していない。

## 4. 金利と株式バリュエーションの関係

株式の理論価格は将来キャッシュフローの割引現在価値である。定率成長配当割引モデル（ゴードン成長モデル）では

$$P = \frac{D_1}{r - g} = \frac{D_1}{r_f + \text{ERP} - g}$$

ここで $D_1$ は来期予想配当、$r_f$ は無リスク金利（実務上は10年国債利回り）、$\text{ERP}$ は株式リスクプレミアム、$g$ は配当成長率。分母に $r_f$ が入るため、**金利低下は理論株価を押し上げ、金利上昇は押し下げる**。感応度は

$$\frac{\partial P}{\partial r_f} = -\frac{D_1}{(r_f - g + \text{ERP})^2} < 0$$

であり、分母 $r-g$ が小さい（＝成長期待が高い）銘柄ほど金利変化に対する価格変化率が大きい。これがYCC解除・利上げ局面で**グロース株（デュレーションの長い株式）がバリュー株に対して相対的に不利**になる理論的背景である。

日本固有の含意として、YCC下では $r_f$ が0%近傍に固定されていたため、**益回り（PERの逆数）と長期金利の差＝イールドスプレッド**が極端に厚く、「株式に代替投資先がない」状態が続いた。例えばPER15倍なら益回りは $1/15 \approx 6.7\%$ で、10年金利0%との差は6.7%ポイントとなり、歴史的にも国際的にも大きなリスクプレミアムを許容していた。2024年以降、10年金利が1%台に上昇するにつれ（実施時点）、このスプレッドの縮小がバリュエーションの上値を抑える要因として意識されるようになった。

もっとも、日本の2024〜2025年の利上げは「デフレ脱却・賃金と物価の好循環の確認」を前提とする点で、景気過熱を抑える引き締めとは性格が異なる。**名目成長率の回復を伴う「良い金利上昇」であれば、分母の $r_f$ 上昇を分子の利益成長が上回りうる**ため、利上げ＝株安と単純に結論づけることはできない。

## 5. 実務上のチェックポイント

- 金融政策決定会合（年8回）と総裁会見、展望レポート（年4回）の日程は日本株のイベントリスクとして必ず把握する。
- 10年国債利回り、日米金利差、ドル円は日銀政策の市場への伝達を測る最重要指標。
- セクター別感応度：利上げ→銀行・保険にプラス、不動産・REIT・高PERグロースにマイナス、円高→輸出株にマイナス・内需株に相対的プラス、という基本パターンを押さえる。
