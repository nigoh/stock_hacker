# 金利・国債市場と日本株の感応度分析

日本国債（JGB）市場は日本株のバリュエーションとセクターローテーションを規定する「土台」である。本稿ではJGB市場の構造（発行・入札、イールドカーブ、日銀保有と流動性）を整理したうえで、金利変動が株式に波及する経路を株式デュレーションの概念で定量化し、銀行・保険・不動産・グロース株といった金利敏感セクターの感応度、カーブ形状と銀行株の関係、株債相関のレジーム変化までを扱う。政策決定そのものの解説は「日銀の金融政策と株式市場」に譲る。

## 1. JGB市場の構造

### 発行と入札
- 国債は財務省が**価格競争入札**（コンベンショナル方式が基本、40年債等はダッチ方式）で発行する。年限は2年・5年・10年・20年・30年・40年、物価連動債（10年）、変動利付債など。カレンダーベース市中発行額は年170兆円前後（2024年度計画時点の概数）。
- 入札結果の**テール**（平均落札価格と最低落札価格の差）と**応札倍率**は需給の温度計であり、テール流れ（札割れ的な弱い結果）は長期金利急騰→株式市場のリスクオフに波及することがある。
- プライマリー・ディーラー制度（国債市場特別参加者、2004年導入）の下、大手証券・銀行が応札義務を負う。

### イールドカーブと日銀保有
- 日銀は異次元緩和・YCCを通じて国債を大量に買い入れ、**発行残高の5割超を保有**（2023〜2025年時点の概数）するに至った。この結果、(1) 特定銘柄の市中流動性枯渇（チーペット銘柄を日銀が吸収し先物と現物の裁定が機能不全になった2022年6月の事例）、(2) ビッド・アスク・スプレッド拡大、(3) YCC上限近傍でのカーブの歪み（10年だけ凹む「ゆがみ」）といった**市場機能の低下**が生じた。日銀の債券市場サーベイでも機能度DIが大幅マイナスを記録した（2022〜2023年時点）。
- 2024年3月のYCC撤廃後は買入減額（QT）が進み、金利形成は市場に回帰しつつあるが、日銀保有の規模自体は長期にわたり残存する。
- 主要な観測点は**10年金利**（住宅ローン固定金利や株式割引率の基準）、**2年金利**（利上げ織り込み）、**超長期（20〜40年）金利**（生保・年金の需給、財政プレミアムの反映）。

## 2. 金利が株式に波及する経路と株式デュレーション

株価は将来キャッシュフローの割引現在価値であり、債券アナロジーで**株式デュレーション**を定義できる。ゴードン成長モデル $P = D_1/(r-g)$ を割引率 $r$ で微分すると

$$D_{eq} \equiv -\frac{1}{P}\frac{\partial P}{\partial r} = \frac{1}{r-g}$$

すなわち**株式の実効デュレーションは $1/(r-g)$**。直感的には、キャッシュフローの重心が遠い将来にあるほど割引率変化の影響が大きい。例えば $r=7\%, g=2\%$ の成熟企業なら $D_{eq}=1/0.05=20$年、$r=7\%, g=5.5\%$ の高成長企業なら $1/0.015\approx67$年となり、**金利が同じ50bp上昇しても理論価格の下落率は約3倍以上異なる**。高PER銘柄ほど（PER $\approx 1/(r-g)$ に対応するため）デュレーションが長い、というのが「金利上昇でグロース株が売られる」ことの定量的表現である。

ただし名目金利の上昇が**インフレ・名目成長期待の上昇**（$g$ の上昇）を伴う場合、$r-g$ は必ずしも拡大しない。金利上昇の株式への影響は「実質金利の上昇か、期待インフレの上昇か」の分解が不可欠であり、日本では物価連動国債から逆算する**ブレーク・イーブン・インフレ率（BEI）**が分解の手がかりになる。

## 3. 金利敏感セクターの分析

| セクター（東証33業種） | 金利上昇の影響 | メカニズム |
|---|---|---|
| 銀行業 | ＋（特に短期金利） | 預貸金利ざや（NIM）拡大。預金金利の追随は貸出より遅く、政策金利上昇がほぼ直接収益化。日銀当座預金の付利収入も増加 |
| 保険業 | ＋（特に超長期金利） | 生保は負債デュレーション＞資産デュレーションの「デュレーション・ギャップ」を抱え、超長期金利上昇は逆ざや解消・EV改善に寄与 |
| 不動産業・J-REIT | −（長期金利） | 借入コスト上昇と、キャップレート（還元利回り）上昇による保有不動産価値の低下。J-REITは分配金利回りと10年金利のスプレッドで評価される |
| 高PERグロース（情報・通信、グロース市場銘柄等） | − | 前述の長い株式デュレーション。マザーズ／グロース市場指数は米実質金利との逆相関が強かった（2020〜2022年時点の観察） |
| 電気・ガス、陸運等のディフェンシブ | − | 有利子負債が重く、配当利回りの相対魅力が国債利回り上昇で低下する「債券代替（bond proxy）」性 |

- **銀行株とカーブ形状**：伝統的な説明は「短期調達・長期運用ゆえスティープ化がプラス」だが、日本の大手行は貸出の多くが短プラ・TIBOR連動の変動金利であり、実際には**短期政策金利の引き上げそのもの**の利益感応度が大きい（メガバンク各行は利上げ25bpあたりの資金利益増加額を決算資料で開示している。2024〜2025年時点）。一方、**地銀は有価証券運用と固定貸出の比重が高く、長期金利・スティープ化への感応度が相対的に高い**うえ、保有債券の含み損（金利上昇時）が経営体力の論点になる。2023〜2025年の「金利ある世界」への移行局面でTOPIX銀行業指数が市場を大きくアウトパフォームしたのは、この収益構造の転換を織り込んだ動きである（実施時点の事実）。
- **ベアフラット化**（短期金利上昇・長期金利横ばい）は銀行にとって預金コスト上昇が先行するため見かけほどプラスでない、**ブルスティープ化**（短期低下主導）は緩和期待でグロース株に追い風、といったカーブの動き方とセクターの対応を区別することが実務上重要である。

## 4. 株債相関のレジーム変化

株式と債券のリターン相関は固定的でなく、**支配的なショックの種類**で符号が変わる。

- **成長ショック主導のレジーム**：景気悪化→株安・債券高（金利低下）となり、**株債は負の相関**。債券が株式のヘッジとして機能し、伝統的な60/40ポートフォリオやリスクパリティが有効。デフレ期の日本や2000〜2020年頃の米国が典型。
- **インフレ・金融政策ショック主導のレジーム**：インフレ懸念→金利上昇と株安が同時進行し、**株債は正の相関**（両方下落）。2022年の世界的な同時安が典型で、日本でも2022〜2024年のYCC修正観測局面では「金利上昇＝債券安」と株安（特にグロース株安）が連動した。
- 日本固有の事情として、YCC期は長期金利がほぼ固定されていたため国内の株債相関は情報量が乏しく、日本株は**米国金利**（特に米実質金利）への感応度の方が高かった。YCC撤廃後は国内金利の変動が復活し、国内要因での相関分析が再び意味を持つようになっている（2024年以降時点）。
- 金利上昇はまた、円キャリー取引や日米金利差を通じて**為替経路**でも株式に波及するため、感応度分析では「金利→割引率」の直接効果と「金利差→円高→輸出株安」の間接効果を分離して考える必要がある。

## 5. 実務チェックリスト

- 10年金利・2年金利・BEI・スワップスプレッドを定点観測し、金利変動を「実質か期待インフレか」「短期主導か長期主導か」に分解する。
- 国債入札（特に10年・超長期）の結果とテールは長期金利のイベントリスク。
- 個別銘柄では有利子負債比率、固定・変動の借入構成、PER（デュレーションの代理変数）で金利感応度を推定する。
