# コモディティ価格と日本株

日本はエネルギー自給率が1割強（2023年度時点、経済産業省ベース）にとどまる世界有数の資源輸入国であり、原油・天然ガス・金属・穀物の国際価格は交易条件・企業コスト・為替を経由して日本株に広範な影響を与える。本稿では、原油高が持つ「国全体には逆風、資源関連セクターには追い風」という二面性を軸に、セクター別のコモディティ感応度、金価格と円の関係、商品市況データの入手先までを体系的に整理する。米国株・米金利を扱うglobal-markets文書とは、コモディティという実物経路で差別化する。

## 1. 資源輸入国・日本の構造と交易条件

日本の鉱物性燃料（原油・LNG・石炭）輸入額は年間20〜35兆円規模で変動し（2022年は資源高と円安の重複で約35兆円、財務省貿易統計）、輸入総額の2〜3割を占める。原油はほぼ100%、LNG・石炭も9割超を輸入に依存する（2020年代前半時点）。この構造ゆえ、資源価格の上昇はまず**交易条件（terms of trade）**の悪化として現れる。

$$\text{交易条件} = \frac{P_{\text{export}}}{P_{\text{import}}}$$

輸出物価 $P_{\text{export}}$ に対して輸入物価 $P_{\text{import}}$ が上昇すると、同じ輸出数量で購入できる輸入数量が減る。これは国内から海外への実質所得移転であり、GDPと国内総所得（GDI）の乖離として統計に表れる。直感的には「原油1バレル100ドルの世界では、80ドルの世界より、日本人が同じ量のガソリンを買うためにより多くの自動車を輸出しなければならない」ということである。企業段階では、日銀の企業物価指数における**輸入物価と国内企業物価の伸び率格差**が、価格転嫁しきれないコストの企業収益への食い込み（マージン圧縮）を示す代理変数となる。

重要なのは、**資源高はしばしば円安と同時進行する**点である。輸入代金決済のドル買い需要（貿易赤字化）に加え、資源高→米インフレ→米金利上昇→日米金利差拡大→円安という経路が重なる。2022年はWTI原油が一時120ドル超、ドル円が115円→151円と進み、円建て輸入コストはドル建て価格の上昇率以上に膨張した。円建てコモディティ価格は近似的に

$$\%\Delta P_{\text{JPY}} \approx \%\Delta P_{\text{USD}} + \%\Delta S_{\text{USD/JPY}}$$

と分解でき、日本企業のコスト分析では「ドル建て市況」と「為替」の寄与を分けて見るのが基本である。

## 2. 原油高の二面性

原油高は日本株全体には逆風だが、恩恵を受けるセクターが明確に存在する。この非対称性がセクターローテーションの源泉となる。

**マイナス面（マクロ経由）**
- 交易条件悪化による実質所得の流出、コストプッシュ・インフレによる消費購買力の低下。
- ガソリン・電気代上昇はCPIを押し上げるが、賃金上昇を伴わない場合は「悪いインフレ」として内需株に売り材料となる。2022年には政府のガソリン補助金（燃料油価格激変緩和事業、2022年開始）や電気・ガス代補助が導入され、CPIの読み方自体が制度でゆがむ点も日本固有の論点である。
- 世界的な原油急騰は米インフレ・米金利上昇を招き、グロース株のバリュエーション圧縮という間接経路でも日本株に波及する。

**プラス面（セクター経由）**
- **総合商社**：三菱商事・三井物産などは原油・LNG・原料炭・銅の権益（持分生産）を保有し、市況上昇が直接的に持分利益を押し上げる。2022年度は資源高で商社セクターが史上最高益を連発した。バークシャー・ハサウェイによる5大商社株取得（2020年公表、その後買い増し）は、商社＝資源インフレヘッジという見方を世界に広めた。
- **石油開発（鉱業）**：INPEXなど上流開発企業は原油価格にほぼ直結する。東証33業種の「鉱業」は構成銘柄が少なく、実質的に原油価格連動セクターである。
- **石油元売り（石油・石炭製品）**：ENEOSなどは在庫評価益（原油高局面でタイムラグ益）が出るが、これは一過性利益として市場では割り引かれる。

つまり日本株のポートフォリオ内では、原油高は「内需・輸入依存セクターから資源関連セクターへの利益移転」として作用する。指数全体への影響は、資源関連の時価総額ウェイトが米国・英国市場より小さいため、ネットでは負に出やすい。

## 3. セクター別コモディティ感応度

| セクター | 主要コモディティ | 感応の方向・メカニズム |
|---|---|---|
| 総合商社 | 原油・LNG・原料炭・銅・鉄鉱石 | 権益持分利益が市況に連動（プラス）。各社は決算で「市況前提と感応度」（例：原油1ドル/バレル変動で純利益○○億円）を開示 |
| 鉱業（石油開発） | 原油・ガス | ほぼ純粋な原油プロキシ（プラス） |
| 海運 | バルチック海運指数（BDI）、コンテナ運賃（CCFI/SCFI） | ばら積み船運賃はBDIに連動。運賃はドル建てで円安もプラス。2021〜22年のコンテナ運賃急騰で海運大手3社（日本郵船・商船三井・川崎汽船、コンテナ事業はONEに統合）は空前の利益を計上 |
| 鉄鋼 | 鉄鉱石・原料炭（コスト）、鋼材市況（売価） | 原料と製品のスプレッドが利益。中国の粗鋼生産・不動産投資が世界鋼材市況を左右するため、実質的に中国景気プロキシ |
| 非鉄金属 | 銅・アルミ・亜鉛（LME価格） | 製錬マージンと権益利益。銅は「ドクター・カッパー」と呼ばれる世界景気先行指標で、中国需要（世界銅消費の約5割、2020年代前半時点）の影響が支配的 |
| 電力・ガス | LNG・原油・石炭 | 燃料費は逆風だが、**燃料費調整制度**（電気）・原料費調整制度（ガス）で数ヶ月遅れで料金転嫁される。急騰時は転嫁が追いつかず（調整上限の存在）、2022年度は大手電力の多くが赤字化した |
| 空運 | ジェット燃料（ケロシン） | 燃料費は営業費用の2〜3割。燃油サーチャージで一部転嫁するが需要減の副作用あり |
| 食品・外食 | 小麦・大豆・トウモロコシ（シカゴ穀物）、食用油 | 輸入小麦は政府売渡制度（年2回改定、農林水産省）を経るため転嫁にラグ。飼料高は畜産・食肉コストに波及 |
| 紙パルプ・化学 | パルプ・ナフサ | ナフサ価格は国産ナフサ価格として化学品の値決め基準になる |
| タイヤ・ゴム | 天然ゴム（大阪取引所にも先物上場） | 原料コスト（マイナス） |

分析実務では、個別銘柄の株価リターンをコモディティリターンに回帰した感応度

$$r_{i,t} = \alpha + \beta_{\text{mkt}} \, r_{\text{TOPIX},t} + \beta_{c} \, r_{\text{commodity},t} + \varepsilon_{i,t}$$

の $\beta_c$（市場要因コントロール後のコモディティベータ）を推定するのが定石である。単回帰では「リスクオンで株もコモディティも上がる」共通因子を拾ってしまうため、市場ベータの同時推定が不可欠である。

## 4. 金価格と円

金と円はともに伝統的な「安全資産」とされてきたが、両者の関係には構造がある。

- ドル建て金価格は実質金利と逆相関しやすい。金は利息を生まないため、保有の機会費用は実質金利 $r = i - \pi^e$ であり、実質金利低下は金高要因となる。
- 円建て金価格 ＝ ドル建て金価格 × ドル円。2020年代の円安局面では、ドル建て金価格の上昇に円安が上乗せされ、円建て金価格（田中貴金属等の小売価格）は史上最高値の更新が続いた（2024〜2025年時点）。日本の個人投資家にとって金積立が「円資産の減価ヘッジ」として機能した典型例である。
- リスクオフ時には金高・円高が同時に起きやすく、円建て金価格では両者が相殺される場合がある点に注意。円が安全通貨として機能しにくくなったとの議論（対外純資産構造の変化）も2020年代の論点である。
- 株式市場では、金鉱株を通じたエクスポージャーは日本にはほぼ存在せず（大手金鉱山会社が上場していない）、住友金属鉱山（菱刈鉱山を保有）が部分的な金関連銘柄とされる程度。実務上は金ETF（例：1326 SPDRゴールド・シェア、1540 純金上場信託など、2025年時点で東証上場）が主な投資経路である。

## 5. 商品市況データの入手先

| データ | 入手先・銘柄 |
|---|---|
| 原油 | WTI（NYMEX/CME）、ブレント（ICE）、ドバイ原油（日本の輸入価格の実態に近い） |
| LNG | JKM（Japan Korea Marker、Platts）— 東アジアのスポットLNG指標 |
| 金属 | LME（銅・アルミ・亜鉛・ニッケル）、COMEX（金・銀・銅） |
| 穀物 | CBOT（シカゴ、小麦・大豆・トウモロコシ） |
| 海運運賃 | バルチック海運取引所のBDI、上海航運交易所のSCFI/CCFI |
| 国内商品先物 | 大阪取引所（2020年に東京商品取引所から貴金属・ゴム・農産物が移管）、金・白金・ゴム先物等 |
| 総合指数 | Bloomberg Commodity Index、S&P GSCI、CRB指数 |
| 輸入物価・企業物価 | 日銀「企業物価指数（CGPI）」の輸入物価指数（円ベース/契約通貨ベースの両方を公表） |
| 貿易統計 | 財務省貿易統計（鉱物性燃料輸入額の月次把握） |

無料での時系列取得はFRED（WTI、天然ガス等）、投資情報サイト（Investing.com等）、日銀時系列統計データ検索サイトが実用的である。分析時は、日本の輸入コストを見るなら「ドバイ原油×ドル円」または日銀輸入物価（円ベース）を使うのが筋がよい。WTIは米国内需給を反映するためアジア市場の実勢と乖離することがある。

## 6. インフレ・為替・金融政策との相互作用

コモディティ→日本株の経路は単線ではなく、インフレと為替を介したフィードバックを持つ。資源高→輸入物価上昇→CPI上昇→日銀の政策修正観測→円金利上昇・円高→輸出株に逆風、という経路は2022年以降の日銀正常化局面で現実のものとなった。逆に資源価格の急落（例：2014〜15年、2020年コロナ初期の逆オイルショック）は、商社・海運の減損リスクと同時に、交易条件改善による内需への追い風という逆向きの二面性を持つ。コモディティを見る際は、(1) ドル建て市況、(2) ドル円、(3) それを受けた日米中央銀行の反応関数、の三層で読む習慣が日本株分析では不可欠である。
