分析し、記録し、答え合わせをして、手法を醸成する。

stock_hacker は日本株の分析を一手に担う開発環境です。ナレッジベースを土台に、 分析ライブラリと CLI、Claude Code のスキル / サブエージェントを備え、 出した予想を必ず後から採点して台帳に貯めることで、 手法そのものを検証可能に保ちます。

Overview

3つの層でできている

Layer 01 · knowledge

ナレッジベース

市場制度・歴史・クオンツ数学・ファンダメンタル・テクニカル・マクロ・デリバティブ・規制税制・データソース・戦略の10分野、100文書。分析の判断枠組みをコードの外に持つ。

Layer 02 · analysis

分析ライブラリと CLI

共通ライブラリ stocklib の上に22の CLI。個別分析・スクリーニング・バックテスト・ポートフォリオ・リスク・季節性・ペア・夜間フォーキャストまで、結果は Markdown レポートで残る。

Layer 03 · agent

スキルとエージェント

Claude Code のスキル18種・スラッシュコマンド20種・サブエージェント4種。/analyze 7203 のように自然言語から分析を起動し、成果物は品質ゲートに通す。

Closed loop

予想を出しっぱなしにしない

この環境の中心にあるのは、予想を出して終わりにしない閉ループです。 機械予想は必ず翌営業日の実績で採点され、台帳に蓄積され、的中率・Brier スコア・ 較正として測定されます。良し悪しは主観ではなく記録が決めます。

01

予想

翌営業日の方向・上昇確率・予想レンジを固定ルールで機械的に生成する。

02

記録

forecasts/ledger.csv と journal/ に、根拠と反証条件つきで残す。

03

答え合わせ

翌日の実績終値で採点。方向的中・レンジ的中・Brier を自動で埋める。

04

測定

蓄積した台帳から的中率・較正曲線・銘柄別成績を集計する。

05

改善

測定結果を根拠に手法を直す。少数標本では過剰反応しない。

Quick start

3分で動かす

# 1. 取得して依存を入れる
$ git clone https://github.com/nigoh/stock_hacker.git
$ cd stock_hacker
$ pip install -r requirements.txt

# 2. 個別銘柄を分析する（7203 = トヨタ自動車）
$ python3 analysis/analyze_stock.py 7203 --period 2y --benchmark ^N225

# 3. ネットワークが使えない場合は合成データで手法デモ
$ python3 analysis/analyze_stock.py 7203 --synthetic
合成データの扱い --synthetic はネットワーク不要で全機能を動かすための合成価格データです。 これで作ったレポートは手法のデモであり実データではないことを必ず明記します。 実データが取れないときに合成データで「今日の市況」を装うことは、この環境では禁止事項です。
