# mape/knowledge/ — MAPE-K 共有ナレッジ（K）

MAPE-K セルフ改善システム（docs/mape-k.md）の「記憶」。M/A/P/E の全フェーズがここを読み書きする。
周回ごとにここが育つことで、判断が好み・実態に寄っていく。

> **注意**: これは MAPE-K 専用のメタ知識であり、リポジトリルートの `knowledge/`（日本株ナレッジベース、
> `00-index.md` で索引される90文書）とは**別物**である。混同しないこと。

| ファイル | 役割 | 主な書き手 |
|---|---|---|
| `BACKLOG.md` | 作りたいことの候補（優先度順） | A が追記、E が消化、人間が編集 |
| `PROGRESS.md` | 周回の履歴（日時・対象・結果・考察・効き目） | M/E が追記 |
| `POLICY.md` | 却下理由・好み・重点テーマ・リスク分類ルール・自律レベル | 人間が編集、A/P が読む |
| `HEALTH.md` | 健全性指標のベースラインと推移 | M が毎周回追記 |

## 機械可読の約束（スクリプトが依存する構造）

- `HEALTH.md`: 「## 指標の推移」直下の表に、M が1行/周回で追記する（列順は固定。`mape/monitor.sh` 参照）。
- `POLICY.md`: 「## リスク分類ルール」の3見出し（自動/承認/相談）配下の ``` で囲んだキーワード行、
  および「## 却下ログ」の `- pattern: …` 行を `mape/analyze.sh` / `mape/plan.sh` が読む。
- これらの見出し・表ヘッダは**リネームしない**（`mape/tests/` が構造を検証する）。人が読む散文は自由に足してよい。
