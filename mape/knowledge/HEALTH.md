# HEALTH — 株の解析の醸成 指標のベースラインと推移

Monitor（`mape/monitor.sh`）が**毎周回1行**を「指標の推移」の表に追記する（docs/mape-k.md）。
MAPE-K の主題は**日本株分析そのものの醸成**なので、指標も分析ドメインの2系統を用いる。
「N 周で 網羅 0→40%」「方向的中率 48→53%」のように、分析が育っているかを定量で示す記録。

> システム/リポジトリの健全性（pytest 等）は主題ではない。pytest は分析コードが動くことの
> **最小ガードレール**として `gate` 列に残すのみ。

## 指標の定義

### 🎯 予測精度（分析が当たっていたか）

| 指標 | 意味 | 良い方向 |
|---|---|---|
| fc_graded | 採点済みの翌営業日予想件数（`forecasts/ledger.csv`, data=real） | 大（標本） |
| fc_hit | 予想の方向的中率 %（採点済みの平均。標本 0 なら na） | 大（>50） |
| fc_brier | 予想の平均 Brier スコア（採点済み。標本 0 なら na） | 小（<0.25） |
| fc_pending | 未採点の予想件数（答え合わせ待ち） | 小（0） |
| jr_verified | 検証済みリサーチジャーナル仮説数（outcome=hit/miss/mixed, data=real） | 大（標本） |
| jr_hit | 的中（outcome=hit）した仮説数 | 参考値 |
| jr_due | 検証期日超過かつ未検証の仮説数 | 小（0） |

### 🗺️ 分析カバレッジ（分析資産をどれだけ広げ・新鮮に保てているか）

| 指標 | 意味 | 良い方向 |
|---|---|---|
| coverage | ユニバース（liquid30）のうち分析記録（台帳/ジャーナル）がある銘柄の割合 % | 大 |
| unanalyzed | ユニバースのうち分析記録がゼロの銘柄数 | 小（0） |
| know_docs | 日本株ナレッジベースの文書数（分析の土台となる知識資産の規模） | 参考値/大 |
| stale_docs | 「20XX年時点」の最新が (今年-2) 以下の陳腐化候補文書数 | 小（0） |

### 🛡️ ガードレール（主題外）

| 指標 | 意味 | 良い方向 |
|---|---|---|
| gate | `python3 -m pytest analysis/tests` の合否（分析コードが動くことの担保のみ） | pass |
