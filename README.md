# stock_hacker

日本株（東証上場株式）の分析を一手に行うためのリポジトリ。

## 構成

| ディレクトリ | 内容 |
|---|---|
| `knowledge/` | 日本株ナレッジベース。市場制度・歴史・数学/クオンツ・ファンダ/テクニカル分析・マクロ・デリバティブ・税制・データソース・投資戦略を網羅した Markdown 文書群 |
| `analysis/` | 分析コード（Python） |
| `data/` | ローカルデータ置き場（git 管理外） |

## 使い方

- ナレッジベースの入口は [`knowledge/00-index.md`](knowledge/00-index.md)。
- Claude Code で開くと `CLAUDE.md` の規約に従って知識の参照・追記・分析を行える。

## 注意

本リポジトリの内容は知識の整理・学習を目的としたものであり、投資助言ではありません。
