# 複数銘柄の相対比較

対象銘柄: $ARGUMENTS

指定された2銘柄以上の日本株について、相対パフォーマンス・リスク/リターン特性・相関構造を定量比較し、セクター文脈を踏まえた比較レポートを作成する。

## 手順

### 1. 銘柄の特定

- 引数から4桁の銘柄コードを2つ以上確認する（例: `7203 6758 9984`）。社名で指定された場合は `analysis/universe/liquid30.csv`（code,name,sector）を参照してコードに変換する。無ければ WebSearch で「<社名> 証券コード」を検索する。
- 1銘柄しか指定されていない場合は、比較対象（同業他社・ベンチマーク等）をユーザーに確認する。同業比較なら liquid30.csv の同一 sector から候補を提案してよい。
- 各銘柄が何の会社か（事業・セクター）を1行ずつ把握してから数字を見る。

### 2. 定量比較スクリプトの実行

リポジトリルートから実行する:

```bash
python3 analysis/compare.py <code1> <code2> [<code3> ...] --period 1y
```

- 比較レポートが stdout に出力され、`reports/compare-<codes>-<日付>.md` にも保存される。内容は (1) 期首=100 の相対パフォーマンス、(2) 期間/年率リターン・年率ボラ・シャープ・最大DD、(3) 日次リターン相関行列。
- 比較の論点に応じて `--period` を変える（短期の強弱なら 6mo〜1y、景気サイクルまたぎなら 2y〜5y）。
- **ネットワークが使えない場合**は `--synthetic` を付けて再実行し、最終レポートに「合成データによる比較手法のデモであり、実データではない」ことを必ず明記する。

### 3. ナレッジベースを解釈の枠組みに使う

比較結果を解釈する前に、必ず以下を読む:

- `knowledge/00-index.md` — 索引。対象銘柄・論点に関連する文書を洗い出す
- `knowledge/math/portfolio-theory.md` — 相関・分散効果・シャープレシオの解釈
- `knowledge/math/returns-and-distributions.md` — リターンの年率化・ボラティリティの前提
- `knowledge/fundamental/sector-structure-japan.md` — セクター間・セクター内比較の文脈

さらに論点に応じて追加で読む:

- パフォーマンス指標の妥当性 → `knowledge/math/performance-measurement-and-attribution.md`
- ペア間の裁定・スプレッドが論点 → `knowledge/strategies/pairs-trading-and-arbitrage.md`
- バリュエーション比較を加える場合 → `knowledge/fundamental/valuation-metrics.md`

### 4. 比較レポートの作成

`reports/compare-<codes>-<日付>.md`（手順2の生成物）を土台に加筆・再構成し、以下の章立てで完成させる:

1. **サマリー** — どの銘柄が何において優位/劣位か、3〜5行
2. **銘柄概要** — 各銘柄の事業・セクター・比較の観点（1銘柄1〜2行）
3. **相対パフォーマンス** — 期首=100 の推移。強弱の転換点があれば時期と背景を記す
4. **リスク・リターン比較** — 年率リターン/ボラ・シャープ・最大DD。リターンの高さとリスク調整後の優劣を区別する
5. **相関分析** — 相関行列の読み。高相関ペア（共通ファクター: セクター・為替感応度・市場β）と低相関ペア（分散効果）を指摘する
6. **定性比較** — バリュエーション・事業モデル・マクロ感応度の違い（データが取れる範囲で。取れなければ「データ取得不可」と明示）
7. **総合所見** — 事実と解釈を区別して記述。どちらを買うべきという結論は書かない
8. **免責** — 末尾に必ず入れる（下記）

### 5. 免責文（必須）

レポート末尾に必ず以下を入れる:

> 本レポートは情報整理・分析手法の提示を目的としたものであり、投資助言ではありません。投資判断はご自身の責任で行ってください。データには誤りや遅延が含まれる可能性があります。

## 比較の質の基準

- **相関は「期間依存・レジーム依存」であることを明記する。** 平時の低相関は市場ストレス時に上昇しがち（相関の非対称性）。1つの期間の相関行列を恒常的な性質として断定しない。
- **リターン差はリスク調整後で語る。** 年率リターンの単純比較ではなく、シャープレシオと最大DDを併記して「どちらのリターンが割に合うか」を示す。年率化は √250 換算である旨を明記する。
- **同一セクター内比較と異セクター比較を区別する。** 同業比較なら事業構造・シェア・マージンの差、異セクターなら市場β・為替/金利感応度の差が主因になりやすい。
- **期首依存性に注意する。** 期首=100 の相対パフォーマンスは開始日の選び方で見え方が変わる。可能なら複数期間（1ヶ月/3ヶ月/6ヶ月）の断面を併記する。
- **事実（データ）・解釈（分析）・不確実性（わからないこと）を明確に区別して書く。** 断定的な将来予測は書かない。具体的な数値には「〜年時点」を付記する。
