# ナレッジ文書の追加・更新

対象トピック: $ARGUMENTS

`knowledge/` 配下に日本株ナレッジ文書を追加または更新し、索引・相互リンクまで整合させる。**索引未反映のままコミットしようとすると hook がブロックする**ため、手順6までを必ず1セットで完了させること。

## 手順

### 1. 索引を読み、重複を確認する

まず `knowledge/00-index.md` を通読する（全文書の索引。約73文書）。

- 対象トピックを**既にカバーする文書があるか**確認する。完全一致でなくても、既存文書の一節として書くべき内容なら新規作成せず**既存文書の更新**にする（1ファイル = 1トピックの原則。細切れの重複文書を作らない）。
- 部分的に重なる文書があれば Read で本文も確認し、新規文書との棲み分け（何をどちらに書くか）を決めてから執筆する。
- 更新の場合は手順3をスキップし、既存文書の構成を尊重して加筆する。冒頭要約が古くなるなら要約も直す。

### 2. カテゴリを選定する

以下の10カテゴリから最も適切な1つを選ぶ。迷ったら「読者がどんな問いを持ってこの文書を探すか」で決める:

| ディレクトリ | 対象 |
|---|---|
| `market-structure/` | 市場制度・取引所・売買の仕組み・指数・投資家構成 |
| `history/` | 日本株市場の歴史・事件史 |
| `math/` | 数学・統計・確率過程・クオンツ理論・ML |
| `fundamental/` | 財務分析・バリュエーション・開示資料の読み方 |
| `technical/` | テクニカル分析・チャート・指標 |
| `macro/` | マクロ経済・金融政策・為替・金利 |
| `derivatives/` | 先物・オプション・CB・ボラティリティ |
| `regulation-tax/` | 規制・税制・NISA・開示制度・ガバナンス |
| `data-sources/` | データソース・API・ツール・自動売買 |
| `strategies/` | 投資戦略・ファクター・イベントドリブン・リスク管理 |

### 3. ファイル名を決める（新規作成時）

- 英語ケバブケース + `.md`（例: `nikkei-225-mechanics.md`、`fx-and-japanese-stocks.md`）。
- 内容が推測できる具体的な名前にする。`misc.md` や `notes-1.md` のような名前は不可。
- 既存ファイル名と紛らわしくないか `ls knowledge/<カテゴリ>/` で確認する。

### 4. 本文を執筆する（CLAUDE.md 規約に準拠）

構成の必須要件:

1. **冒頭に `# タイトル`**（日本語）。
2. **タイトル直後に3行以内の要約**。この文書が何をカバーするかを完結に述べる。
3. **本文は日本語**。見出し（`##`）で構造化し、体系的に書く。
4. **数式は LaTeX 記法**（インライン `$...$`、ブロック `$$...$$`）。例: シャープレシオは $SR = \frac{E[R_p - R_f]}{\sigma_p}$ のように定義ごと示す。
5. **末尾に `## 関連トピック` セクション**を置き、既存の関連文書への相対リンクを列挙する（手順6参照）。

内容の品質基準:

- **具体的な数値（税率・制度の閾値・手数料水準など）には必ず「〜年時点」を付記する。** 制度は変わる（例: 「譲渡益課税20.315%（2025年時点）」）。
- **投資助言ではなく知識の整理。** 断定的な将来予測・売買推奨は書かない。「〜する傾向が実証されている」「〜という解釈がある」のように事実・実証・解釈を区別する。
- 実証結果に触れる場合はデータスヌーピングやアノマリー減衰など方法論上の留意点も添える（`knowledge/math/backtesting-and-statistics.md` の水準を参考にする）。
- 日本市場固有の制度・文脈（単元株、値幅制限、決算短信、東証の要請等）を必ず織り込む。一般論の翻訳で終わらせない。
- 分量の目安は既存文書と同程度（見出し5〜10個、数十行〜100行程度）。索引の他文書を1〜2本読んでトーンを合わせる。

### 5. 00-index.md に索引を追加する（必須・hookで強制）

`knowledge/00-index.md` の該当カテゴリセクションに、**アルファベット順（ファイル名昇順）の位置**へ1行追加する:

```markdown
- [日本語タイトル](<カテゴリ>/<ファイル名>.md) — 文書の内容を2〜3文で要約した索引文。何をどこまでカバーするかが索引だけで分かるように書く。
```

- 冒頭の総文書数（「全73文書」）も更新する。
- 既存文書を更新してスコープが変わった場合も、索引の要約文を現状に合わせて直す。
- **注意: このリポジトリには knowledge/ 配下の文書追加が 00-index.md に反映されていないことを検出してブロックする hook が設定されている。** 索引への追加を忘れると作業が完了扱いにならないため、文書本体と索引は必ず同時に更新する。

### 6. 既存文書と相互リンクする

- 新規文書の `## 関連トピック` に、内容が隣接する既存文書を**相対パスの Markdown リンク**で2〜5件挙げる（例: 同カテゴリなら `[テクニカル指標と一目均衡表](indicators-and-ichimoku.md)`、他カテゴリなら `[株価の時系列モデル](../math/time-series-models.md)` のように `../<カテゴリ>/` でまたぐ）。
- **逆方向も張る**: リンク先の既存文書の `## 関連トピック` に新規文書へのリンクを追記する（`関連トピック` セクションが無い既存文書には末尾に新設してよい）。
- リンクを張ったら相対パスが正しいか確認する（`ls` で実在確認）。

### 7. 完了確認

以下をすべて満たしていることを確認して終了する:

- [ ] `knowledge/<カテゴリ>/<kebab-case>.md` が規約どおり（冒頭要約3行以内、日本語本文、LaTeX数式、「〜年時点」表記）
- [ ] `knowledge/00-index.md` に索引行を追加し、総文書数を更新した
- [ ] 新規文書 ⇄ 既存関連文書の相互リンクを張った
- [ ] 投資助言・断定的将来予測になっていない

完了報告では、作成/更新したファイルの一覧と、索引に追加した要約文を提示する。
