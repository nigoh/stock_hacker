# 個別銘柄の総合分析

対象銘柄: $ARGUMENTS

日本株1銘柄について、定量分析（スクリプト）+ 定性分析（ナレッジベース・Web情報）を統合したプロフェッショナル水準の分析レポートを作成する。

## 手順

### 1. 銘柄の特定

- 引数から4桁の銘柄コードを確認する（例: `7203`）。社名で指定された場合はコードに変換する（`analysis/universe/liquid30.csv` に主要30銘柄の code,name,sector があるのでまず参照。無ければ WebSearch で「<社名> 証券コード」を検索）。
- 企業名・セクター・事業内容を1〜2行で把握してから分析に入る。何の会社か分からないまま数字を見ない。

### 2. 定量分析スクリプトの実行

リポジトリルートから実行する:

```bash
python3 analysis/analyze_stock.py <code> --period 2y
```

- 成功すると `reports/analyze-<code>-<日付>.md` が生成され、パスが stdout に出る。この内容（リターン、SMA/RSI/MACD等のテクニカル、ボラティリティ、β、最大ドローダウン、対 ^N225 相対パフォーマンス）を分析の定量的土台にする。
- 既定で価格チャート（ローソク足+SMA+ボリンジャーバンド/出来高/RSI）の PNG が `reports/img/` に生成され、レポートに相対パス（`img/...png`）で埋め込まれる。不要なら `--no-charts`。最終レポートに再構成する際もこの画像参照を残す。
- **ネットワークが使えない場合**は `--synthetic` を付けて再実行する。このとき最終レポートに「合成データによる分析手法のデモであり、実データではない」ことを必ず明記する。
- **海外投資家視点・ドル建て評価が論点の場合は `--in-usd` を付ける。** レポートに「ドル建てパフォーマンス（海外投資家視点）」節が追加され、円建て終値を USDJPY=X で除したドル建て系列でリターン・ボラ・シャープ・最大DDを再計算し、円建てとの差（為替寄与）を併記する。主表示は円建てのままで、外需株の為替感応度や海外資金の目線を議論するときに使う。

### 3. ファンダメンタル情報の収集

- **手順2で生成されたレポートの「基本情報」節を土台にする。** analyze_stock.py が `stocklib.data.fetch_info` 経由で PER（実績/予想）・PBR・配当利回り・ROE・時価総額・52週高値/安値・ベータ等を既に出力している。同じ指標を `Ticker("<code>.T").info` から取り直すスクリプトを書かない（車輪の再発明をしない）。
- 追加の指標が必要な場合のみ、`PYTHONPATH=analysis` で `stocklib.data.fetch_info(code)` を呼んで補完する（例: `PYTHONPATH=analysis python3 -c "from stocklib.data import fetch_info; print(fetch_info('7203'))"`）。
- WebSearch / WebFetch は、直近決算・業績予想の修正・中期経営計画・株主還元方針・材料ニュースなど**定性情報の補足**に使う。数値には必ず「〜年〜月時点」を付記する。
- **`--synthetic` 実行時の「基本情報」節はコードから決定論的に導出されたダミー値**（名称も「合成データ銘柄」と表示される）。レポート冒頭の「合成データ」表示と整合させ、実在企業の指標として扱わない・引用しない。
- いずれも不可なら、定量パートをテクニカル・リスク中心に構成し、ファンダ欄は「データ取得不可」と明示する。推測で数値を書かない。

### 4. ナレッジベースを分析の枠組みに使う

分析・執筆の前に、必ず以下を読む:

- `knowledge/00-index.md` — 索引。対象銘柄に関連する文書を洗い出す
- `knowledge/fundamental/valuation-metrics.md` — PER/PBR/ROE等の解釈の枠組み
- `knowledge/technical/indicators-and-ichimoku.md` — テクニカル指標の読み方
- `knowledge/fundamental/sector-structure-japan.md` — セクター文脈の整理に使う

さらに銘柄特性に応じて追加で読む:

- 銀行・保険・証券株 → `knowledge/fundamental/analyzing-financial-sector-stocks.md`
- 配当・自社株買いが論点 → `knowledge/fundamental/dividend-policy-and-buybacks.md`
- 業績予想・コンセンサスが論点 → `knowledge/fundamental/earnings-guidance-and-consensus.md`
- β・ドローダウン等リスク指標の解釈 → `knowledge/math/portfolio-theory.md`、`knowledge/math/returns-and-distributions.md`
- 財務諸表を深く読む場合 → `knowledge/fundamental/reading-japanese-financials.md`

### 5. 統合レポートの作成

`reports/analyze-<code>-<日付>.md`（手順2の生成物）を土台に加筆・再構成し、以下の章立てで完成させる:

1. **サマリー** — 3〜5行。強気材料・弱気材料を両論併記
2. **企業概要** — 事業内容、セクター、時価総額
3. **テクニカル分析** — トレンド（SMA25/75/200の位置関係）、モメンタム（RSI/MACD）、出来高。指標は単体で断定せず複数の整合性で判断する
4. **ファンダメンタル分析** — バリュエーション、収益性、財務健全性、株主還元
5. **リスク分析** — 年率ボラティリティ、β（対 ^N225）、最大ドローダウン、銘柄固有リスク
6. **セクター文脈** — 業界構造、マクロ感応度（為替・金利）、同業比較の視点
7. **総合所見** — 事実と解釈を区別して記述
8. **免責** — 末尾に必ず入れる（下記）

### 6. 免責文（必須）

レポート末尾に必ず以下を入れる:

> 本レポートは情報整理・分析手法の提示を目的としたものであり、投資助言ではありません。投資判断はご自身の責任で行ってください。データには誤りや遅延が含まれる可能性があります。

## 分析の質の基準

knowledge/ の知見の凝縮。レポートはこの水準を満たすこと:

- **PER・PBRは比較して初めて意味を持つ。** 業種平均・自社の過去レンジ・金利水準との比較なしに「PER15倍だから割安」とは書かない。低PBRは資本コストを上回れないROEの裏返しであることが多い（PBR ≒ ROE×PER の分解で確認する）。
- **ROEはデュポン分解（利益率×回転率×レバレッジ）で質を見る。** レバレッジで嵩上げされたROEと事業収益性によるROEを区別する。
- **テクニカル指標は「複数指標の整合」と「価格・出来高との一致」で読む。** RSI30割れ単体は買いシグナルではなく、下降トレンド中は張り付くことがある。トレンド系（SMA・一目）とオシレーター系（RSI・MACD）を役割分担させる。
- **βと最大ドローダウンは別物として報告する。** βは市場感応度、最大DDは経路依存の実損リスク。年率化ボラティリティは √250 換算である旨を明記する。
- **日本株固有の文脈を落とさない。** 為替感応度（輸出株か内需株か）、東証のPBR改善要請（2023年〜）、保守的な期初ガイダンス慣行、単元株制度（100株）などが解釈に影響する。
- **事実（データ）・解釈（分析）・不確実性（わからないこと）を明確に区別して書く。** 断定的な将来予測は書かない。
- 具体的な数値（税率・制度の閾値・バリュエーション水準）には「〜年時点」を付記する。
