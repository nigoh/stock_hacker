# ジャーナルレビュー（仮説の検証と振り返り）

引数（あれば特定エントリのパス）: $ARGUMENTS

記録した仮説の「答え合わせ」を行い、当たり外れから学ぶ。判定は機械（CLI）に任せ、
このスキルの主眼は**判定結果の解釈と振り返り**にある。書式・判定基準の正は
`journal/README.md` と `analysis/stocklib/journal.py` の `judge_direction` docstring。

## 手順

### 1. 期日到来エントリの確認

```bash
python3 analysis/research_journal.py due
```

- `status: open` かつ `review_date <= 今日` のエントリが一覧される。
- 引数でパスが指定されていればそのエントリのみ対象にする（期日前でもユーザーが
  望めば検証してよいが、期日前である旨を結果に添える）。
- 期日到来がなければ `list` で全体を見せ、「期日到来なし」と報告して終了。

### 2. 検証の実行

期日が来たエントリごとに:

```bash
python3 analysis/research_journal.py verify journal/2026/<エントリ>.md
```

- 記録時スナップショットと現在値・同期間の ^N225 騰落から hit/miss/mixed が判定され、
  `## 検証結果` に判定テーブルが追記される（frontmatter は `status: reviewed` に更新）。
- yfinance への接続に失敗したら `--synthetic` で再実行**しない**こと。合成データでの
  検証は実仮説の答え合わせにならない（entry_prices が実データの場合、判定が無意味になる）。
  接続失敗時は検証を延期し、その旨を報告する。`--synthetic` を使うのは、エントリ自体が
  合成データのデモである場合だけ。

### 3. 判定の解釈

機械判定を鵜呑みにせず、1〜2行の文脈を添える:

- **hit** — 仮説どおりか、それとも「別の理由で偶然同じ方向に動いた」のか。理由まで
  当たったと言えるかを本文の ## 根拠 と突き合わせる。運による hit を実力と誤認するのが
  自信過剰バイアスの入口。
- **miss** — ## 反証条件 に書いた事象が実際に起きていたか確認する。反証条件が
  期日前に成立していたなら「もっと早く棄却できた」ことが学び。
- **mixed** — ±2%未満は「有意な動きなし」。仮説の期間設定が短すぎた/長すぎた可能性、
  そもそも検証可能性の低い仮説だった可能性を指摘する。

### 4. 振り返り（外れた仮説から学ぶ）

`knowledge/strategies/behavioral-finance-japan.md` を読み、miss/mixed のエントリについて
以下の型で振り返りを行う（結果を会話で提示し、必要ならエントリの ## 検証結果 の末尾に
「### 振り返り」として1段落追記する）:

1. **どのバイアスが仮説に混入していた可能性があるか** — 例:
   - 確証バイアス: 根拠が「都合の良いデータ」だけで構成されていなかったか
   - アンカリング: 過去の株価水準・自分の買値を参照点にしていなかったか
   - ハーディング: テーマ株の過熱・SNS の空気を根拠にしていなかったか
   - 自信過剰: 直前に hit が続いた後の仮説ほど雑になっていないか
2. **プロセスと結果を分離する** — 正しいプロセスの miss は責めない。誤ったプロセスの
   hit を成功体験にしない（結果バイアスへの対策）。
3. **次の仮説への反映を1行で** — 「決算モメンタム仮説は期日を30日に短縮する」のような
   具体的な修正。汎用的な教訓が得られたら knowledge-doc スキル（/learn）での文書化を提案する。

### 5. 完了報告

検証したエントリ数と判定の内訳（hit/miss/mixed）、`list` の最新サマリー、
振り返りの要点を会話で報告する。判定は過去の仮説の検証であり、
将来のリターンを保証するものでも投資助言でもない旨を保つ。

## 注意事項

- 検証済み（`status: reviewed`）エントリの再検証はエラーになる（後知恵での上書き防止）。
  やり直しが必要な場合は理由をユーザーに確認してから frontmatter を手動で戻す。
- 対応コマンド: `/journal-review`。新規記録は `/journal`（research-journal スキル）が担当。
